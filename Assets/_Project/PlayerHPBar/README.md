# プレイヤー頭上のHPバー

- PNG・透過・3倍書き出し（プレイヤーと同じドット密度）。Filter Mode = Point / Compression = None
- 元のドット絵で 15×6px（HP3のとき）。プレイヤーの頭（アンテナの先）から 2px 上に置く

## ファイル

| ファイル | 内容 |
|---|---|
| HPBar_3_Full / HPBar_4_Full / HPBar_5_Full | HPが満タンの完成形（最大HPが3〜5のとき） |
| HPBar_3_Damage | 被弾アニメ 7コマ（白く光る→赤と空を3回くり返して点滅→空になる）。1コマ約0.08秒、ループなし |
| HPBar_3_Low | 残り1のときの表示。最後のマスをオレンジにする（点滅はしない） |
| Parts/HPBar_N_Frame | 中身が空の枠。マスをコードで並べる場合の土台 |
| Parts/HPPip_* | 1マス分（Full・Empty・FlashWhite・FlashRed・Low）。3×2px |

## 実装のポイント

- 最大HPが変わるなら、Frame の上に Pip をコードで並べる。マスの位置は左から 2px、間隔 4px（マス3px＋すき間1px）、上から 2px
- プレイヤーの子にするが、**向きの反転（flipX やスケール −1）の影響を受けない Transform に置く**。反転するとマスが右から減って見える
- 並び順はプレイヤー・敵・エフェクトより手前（ワールド用UIのソーティングレイヤー）
- Pixel Perfect Camera を使い、位置はドットの格子に合わせる（半端な位置だとにじむ）
- 被弾した瞬間にバー全体を 1px 揺らすと、ダメージが伝わりやすい
- 上部HUDのHP表示は、頭上のバーと重複するので外してよい
