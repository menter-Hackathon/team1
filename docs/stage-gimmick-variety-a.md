# ステージのギミックの動きを増やす：A グループ（2026-11-19）

元の文書：`docs/stage-gimmick-variety.md`（動きの部品 KitMotion は 1章）。
アプリ：Chrome・VS Code・Finder・Premiere Pro・Terminal・Slack・LINE・Messages・Teams・Discord・Calendar・Mail・Zoom。
足場は `Tools/art/appbg/apps/<ラベル>.json` の `stage`（UI の部品の足場）を前提にする（Chrome・VS Code は今のステージのまま）。

## 0. 共通の決まり

- 場面③の出来事は **雑魚の時間だけ**。長さは今と同じ 12秒（始まりの予告 0.8秒をふくむ。`StagePaceTable.GateEventSeconds`）。数は強さ 1／2／3 で書く。
- 危ない物は、出来事用の AttackRunner から出す（今の Chrome・VS Code と同じ）。`ctx.CanSpawnHazard` を見る。
- 予告は 0.8秒以上（下に書いた数）。色は赤にせず、**アプリの色の印＋白いふち**（当たる瞬間だけ赤）。背景は赤を使っていないので、赤は「当たる」だけの色になる。
- ステージの決まり（StageRule）はボス戦でも動く。ボス戦では **数を半分・間を 1.3倍・1回に1つまで**、床か足場のどちらかは必ず安全にする。
- 文字は UI のまねの短い英語だけ（説明の文は出さない）。

## 2. アプリごと

### Chrome（今の出来事：オフライン。`Run/AppKits/ChromeKit.cs` の `ChromeOfflineEvent`）

**出来事に足す物「ポップアップ広告」**
- 元ネタ：急に出る広告のウィンドウと、小さい × ボタン。
- 部品：`Pop`（広告の小さいウィンドウ）＋ `HitTarget`（右上の ×）。今のサボテン・翼竜（右から左。EdgeSweep と同じ向き）はそのまま。
- 並べ方：出来事の 3秒目と 7秒目に、プレイヤーの前（進む向きに 4〜6マス、床から 2〜3マスの高さ）へ 1枚ずつ（強さ 3 は 2枚ずつ）。
- 秒：予告 0.8（点線の枠）→ 出ている 3.5。叩けば閉じる。叩かないと、閉じる時に小さい弾を 4つ輪に出す（`Pop` の ringCount 4）。
- 行動：× を叩く（ごほうび：次のサボテン 1つが消える）。逃げてもよい。
- 見た目：白っぽいウィンドウ（背景のタブと同じ灰青 `#97a0ad` のタイトルバー）、中は黄色ではなく水色の帯と「AD」。× は濃い灰色。
- サボテンの列と重なる時刻（サボテンが着く前後 0.5秒）には出さない。

**決まりの直し**：なし（上から落とす物は無い）。
**公平さ**：ボス戦には出来事が無い。広告は痛くないウィンドウで、弾は閉じる時だけ。

### Terminal（今の出来事：sudo reboot。床の全部・長い予告。`Run/AppKits/TerminalKit.cs`）

**出来事に足す物「kill -9」**
- 元ネタ：`kill -9 <PID>`。番号（PID）を持つ物だけが残る。
- 部品：`SafeSpot` ＋ `Erupt`。
- 並べ方：sudo reboot の前半（出来事の 2秒目と 6秒目）に 1回ずつ。コマンドの行が `kill -9 *` に変わる → 床の 5区画（今の `Sections = 5` と同じ分け方）のうち 1区画（強さ 1 は 2区画）に、緑の枠と `[PID]` の札＝安全 → 予告のあと、ほかの区画の床から、緑の文字の柱がせり上がる。
- 秒：SafeSpot の予告 1.6（強さ 3 は 1.3）→ Erupt：せり上がり 0.2・止まる 0.5・高さ 2マス。足場（コマンドの行）の上は当たらない。
- 行動：緑の枠へ走る、または足場へ上がる（どちらでも助かる）。
- 見た目：柱は `KILLED` の字が縦に並ぶ緑の文字の柱（`TerminalArt.Green`）。安全の枠は明るい緑の点線。赤は使わない（rm の赤い点滅と見分ける）。
- sudo reboot の本体（床の全部）は、後半に今のまま 1回。kill -9 と重ねない（3秒あける）。

**決まりの直し**：なし（床が 1区画消える rm は、下へくずれる物）。ただし kill -9 の間と、その前後 2秒は rm を出さない（今の「③ の間は出さない」を守る）。
**公平さ**：雑魚の時間だけ。安全の区画は、プレイヤーから 2区画以内に必ず 1つ。乗ると落ちる足場（RM -RF の行）だけが逃げ場にならないよう、落ちない足場（LS・CAT）の真下の区画は Erupt を低く（高さ 1.5）して、足場の上を必ず安全にする。

- @channel（床の全部の低い波）は今のまま（`FloorWave` と同じ向き）。

**公平さ**：ボス戦では、板は Pop だけ（すべる板は出さない）・15秒おき（今のまま）。出来事は雑魚の時間だけ。@channel の予告の間は、スレッドの柱を出さない。

### Discord（今：スキンの出来事。決まり `Kits/Discord/DiscordRule.cs`：足場＝ボイスチャンネルの切断）

**出来事「@everyone」**（新しく登録）

- 部品：`Bounce`（@ の玉）＋ `WallCrawl`（未読の白い印）。

- 行動：玉の高さを見て、足場（チャットの行）の上か下かを選ぶ。
- 見た目：玉はブループル `#6c78d6` の丸に白い @（`DiscordArt` の色）。バッジの赤は使わず、当たった時だけ赤。

**決まりの直し**：なし。切断は足場の上だけの判定（落ちてこない）。ただし出来事の間は、切断を出さない（足場が逃げ場になるため）。
**公平さ**：雑魚の時間だけ。玉の高さは 3つの段（床のすぐ上・足場の下の段の高さ・上の段の高さ）のどれかで、同時に 2つの段までしか使わない。

### Calendar（今：スキンの出来事。決まり `Kits/Calendar/CalendarRule.cs`：予定の締め切り＝会議室）

**出来事「ダブルブッキング」**（新しく登録）
- 元ネタ：予定が重なる。予定のブロックを横へドラッグして日をずらす。
- 部品：`EdgeSweep`（予定のブロック）＋ `HoldZone`（空いている時間）。
- 並べ方：予定のブロック（幅 2.2×高さ 1.2マス）が、左の壁から右へ、次は右から左へ、**時間の行の高さ**（床の上・下の段の足場の高さ・上の段の足場の高さの 3つ）を横切る。1回に 1つの高さ（強さ 3 は 2つの高さを同時に。残りの 1つは必ず空く）。まっすぐ（wave なし）。
- 秒：予告 1.0（壁ぎわに矢印と、その行がうすい色の帯で光る）→ 毎秒 7マス。間は 2.2／1.8／1.5秒。数 4／5／7。
- HoldZone：出来事の 4秒目に、床のまん中あたりに幅 3マスの白い点線の枠（「空き時間」）。その中に続けて 2.5秒いると ✓：次の予定の「欠席」の罰を 1回なかったことにする（無ければクールタイム全回復）。枠の高さ（床）をブロックが通る時は、ジャンプで越えれば「いる」のまま（`JumpAllowance` と同じ考え）。
- 行動：光った行から別の行へ移る。空き時間の枠に立ち続ける。
- 見た目：ブロックは `stage` の予定のブロックと同じ絵（青・緑・紫・青緑）に白いふち。足場の予定（会議室）と見分けるため、動くブロックは半透明 80％＋左に矢印。

**決まりの直し**：なし（時間の帯と会議室。落ちる物は無い）。出来事の間は、今のまま予定の時計を止める。
**公平さ**：雑魚の時間だけ。会議室が光っている足場の高さには、その予定の時刻の前後 1秒、ブロックを通さない。

### Mail（今：スキンの出来事。決まり `Kits/Mail/MailRule.cs`：新着メールの封筒が上から降りる）

**出来事「一斉送信」**（新しく登録）
- 元ネタ：全員に返信（Reply All）でメールがどっと届く。「シュッ」という送信の音。
- 部品：`EdgeSweep`（wave あり）＋ `Catch`。
- 並べ方：封筒が右の壁から左へ、**波を打ちながら**（振れ幅 1.2マス）飛ぶ。3通を 0.5秒おきに 1列で（強さ 2・3 は 4通・5通）。列は 3回。高さは、床から 1.5マス → 3.5マス → 1.5マス（強さ 3 は最後が左から）。
- 秒：予告 1.0（右の壁に矢印と封筒の印、波の通り道の最初の 1山が点線）→ 毎秒 6マス。列の間は 3秒。
- Catch：各列の最後の 1通は、白い封筒に青い帯（ふつうのメール。当たらない）。触ると、今の決まりのごほうびと同じ（クールタイム全回復）ではなく、小さく（全部の能力を 2秒進める）。
- 行動：波の谷と山を読んで、くぐるか跳ぶ。最後の白い封筒だけ取る。
- 見た目：危ない封筒は `MailArt` の迷惑メール（紫の「！」・文字化けの帯）。良い封筒は白＋青。色と帯で見分ける（決まりと同じ見分け方）。

**決まりの直し（上から降りる → 右から届く）**
- 今：`MailRule` の封筒（`MailEnvelope`）が、プレイヤーから 3〜5マスの所へ、上からゆっくり降りる（`DescendSpeed 2.5`。痛くない）。
- 直し：`Catch` にする。右上の通知（New Mail）の所から、山なりに飛んで（0.9秒）、プレイヤーから 3〜5マスの床か足場の上に着く。着いたあとは今と同じ（6秒残る・触ると開く・迷惑メールは開けると爆発の予告）。飛んでいる間は当たらない・取れない（着いてから）。
- 着く所は、今と同じレイキャスト（Ground・OneWayPlatform）で決める。動く足場（swipe）と落ちる足場（spam）には着かせない。

**公平さ**：ボス戦は決まりだけ（20秒おき。今のまま）。出来事の間は、決まりの新着メールを出さない（見た目がまざるため）。

### Zoom（今：スキンの出来事。決まり `Kits/Zoom/ZoomRule.cs`：40分で切れる。雑魚の時間は 0 でタイルが 4枚落ちる）

**出来事「入室ラッシュ」**（新しく登録）
- 元ネタ：会議が始まる時に、参加者のタイルがつぎつぎ現れる。「〜が入室しました」。
- 部品：`Pop`。
- 並べ方：ギャラリーの枠（3列×2段。足場のタイルの間の空いている所）に、タイルが奥から大きくなって出る。1度に 2枚（強さ 2・3 は 3枚）。プレイヤーのいる枠は 2回に 1回だけえらぶ。足場のタイルがある枠には出さない。

- 見た目：`stage` の足場のタイルと同じ絵（灰色のタイル＋人の形）。足場と見分けるため、危ないタイルは橙のふち `#c9a07a`（マイク切りの色）＋点滅、足場のタイルは灰色のふちのまま。

**決まりの直し（上から落ちる → 左右へ出ていく・入ってくる）**
- 今：雑魚の時間に時計が 0 になると、参加者のタイルを 4枚落とす（`ZoomRule` の「出来事の雨の写し」。影と赤い「！」の予告）。

- ボス戦の Meeting ended（ゲージが 8 戻る）は今のまま。危ない物は足さない。

**公平さ**：出来事は雑魚の時間だけ。出たり消えたりする足場（YOU・SATO）が消える時刻と、その真下の枠の Pop を重ねない（前後 1秒）。

## 3. 作る時の注意（まとめ）

- 足場の数：`CallKitUtil.FindPlatforms`・`TalkKitUtil.Platforms` は、UI の足場（4〜6枚。動く・消える物をふくむ）を全部返すようになる。出来事の中で足場をえらぶ時は、`behavior` が `static` の物だけにする（上の各アプリの「〜の上には置かない」）。
- 出来事と決まりの重なり：出来事の間は、そのアプリの決まりの危ない物を止める（Slack の板・Discord の切断・Mail の新着・Terminal の rm・Calendar の時計）。今も多くは「③ の間は出さない」。
- 部品が間に合わない時の代わり：`Orbit`（Messages）→ `Pop` を円に並べて順に出す。`WallCrawl`（Discord）→ はぶく（Bounce だけ）。`Conveyor`（Premiere）→ はぶく（FloorWave だけ）。`HoldZone`（Calendar）→ はぶく（EdgeSweep だけ）。
- 予告の色：アプリの色＋白いふち。赤は当たった時だけ。VS Code の波線だけは元ネタが赤なので、橙がかった赤にして、床の細い線にとどめる。
