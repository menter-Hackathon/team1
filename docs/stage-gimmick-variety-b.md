# ステージのギミックの動きを増やす：グループ B（13アプリ。2026-11-19）

元の文書：`docs/stage-gimmick-variety.md`（動きの部品 `KitMotion` は 1章）。ここは 2章の「アプリごとの案」のうち、
ChatGPT・Claude・Gemini・Notion・メモ・Excel・PowerPoint・Word・Keynote・Safari・Firefox・Arc・Cursor の分。

## 0. 共通の決まり（13個とも）

- **場面③の出来事**は `StageEvents.Register(label, stage => new XxxEvent(stage))` で 1つずつ（`PaceEvent` を継ぐ。お手本は `Kits/Teams/TeamsBreakoutEvent.cs`）。
  雑魚の時間だけ（ボス戦・ラスボスのステージでは呼ばれない）。`SpawnsOwnZako = false`（雑魚は StagePacer が出す。撃つ雑魚は出ない）。長さ 10〜14秒（`MaxSeconds`）。
- **座標**：マス。部屋は x −10〜+10、床 y 0、画面の上 y 11.5。UI の足場（`Tools/art/appbg/apps/<ラベル>.json` の `stage`）は、
  フォルダの場所の 2枚が上の面 y 3（x −4.7〜−2.3 と +2.3〜+4.7 を含む）、上の段が y 4.3〜5。ジャンプは約 3.2。
- **ステージの番号で数を変える**（factory が受け取る 1〜3）：下の「数」は 2ステージ目の値。1ステージ目は −1（最低 1）、3ステージ目は +1。速さは変えない。
- **予告**は 0.8秒以上（出来事の 1発目は 1.0秒）。予告の色は赤＋アプリの色の印。良い物（Catch・HitTarget・HoldZone）は赤を使わず、白いふち＋アプリの色。
- **逃げ場**：どの出来事も「床にいても、足場にいても、必ず 1つは安全な場所がある」ように並べる（下の各「公平さ」）。同時に画面にある危ない物は 3個まで。
- **ごほうび**は小さく・同じ物にそろえる：`能力のクールタイムを全部戻す`（＝ステージのボタンの refill と同じ）か `出来事の残りの危ない物を消す`。失敗の罰は「危ない物が 1回多く出る」まで（ダメージを直接は与えない）。
- 出来事が出した物は全部 `Track` して、`End`・ボスの登場で消す。

主な部品の割りふり（同じ部品が 3アプリを超えないように）：

## 1. ChatGPT：「ストリーミング」

**出来事**
- 元ネタ：答えの文字が左から 1行ずつ流れて出てくる。下に「■ Stop generating」。
- 部品：`EdgeSweep`（side=L、wave あり）＋ `HitTarget`。
- 並べ方：文字の行（横 3×縦 0.5 の灰色の棒。先頭に緑の丸）が、左の端から右へ波打って横切る。高さは 3つの段を順に：y 0.7（床）→ y 3.6（下の足場の上）→ y 5.6（上の足場の上）→ くり返し。
  1回に count 2（gap 0.5秒）、speed 7、wave ±0.5。次の段まで 2.2秒。全部で 5回（約 12秒）。
- 予告：左の端に、その高さの矢印＋点滅するカーソル「▌」（0.8秒。1発目 1.0秒）。
- HitTarget：3秒たったら、入力欄の足場（x 0、y 1.3）の右に「■ Stop」の的（life 5秒）。叩くと、まだ出ていない行が全部止まる（出来事が早く終わる）＋ 画面の行が消える。叩かなくても罰はない（最後まで流れるだけ）。
- 見た目：`ChatGptArt` の緑（#10A37F）と灰色の棒。背景の会話の行と同じ形なので「答えが流れてきた」と分かる。行が通ったあとに、うすい残像を 0.3秒。

**ステージの決まりの直し**
- `ChatGptRule` の「長い答え」（`ZoneStrike.StrikeSweep`。床から天井までの柱 5本）は、上から落ちる物ではないので **そのまま**。
  見た目だけ：柱を「下から上へ文字が積み上がる」向きに描く（予告の間、下から灰色の行が 1行ずつ増える）。当たりは今のまま。

**公平さ**
- 雑魚の時間：行は 1つの段だけ。ほかの 2つの段は必ず安全。同じ段が 2回続かない。
- ボス戦：出来事は出ない。「長い答え」は今のまま（ボスが考える 3秒の間に叩けば止まる）。

## 2. Claude：「アーティファクト」

**出来事**
- 元ネタ：会話の横に Artifacts のパネルが開く。考えている間のオレンジの印。
- 部品：`Pop` ＋ `HoldZone`。
- 並べ方：クリーム色のパネル（横 3×縦 2）が、奥から大きくなって **その場に開く**。場所は決めた 6か所（床の左・中・右＝x −6／0／+6、y 1；足場の上＝x −3.5／+3.5、y 4；上の段 x 0、y 6）から、プレイヤーに近い 1つ＋離れた 1つの 2枚ずつ。
  warn 0.9秒、life 1.2秒、次の組まで 2.4秒。全部で 4組（約 11秒）。ring はなし（弾はばらまかない）。
- 予告：出る場所に、オレンジの点線の枠＋まん中に小さいスパーク（回る）。
- HoldZone：2組目のあと、床の x −1.5〜+1.5 にオレンジの光る帯「考える時間」。中に 2秒いると、残りのパネルが出ない＋クールタイムを全部戻す。出ると数え直し。
  帯の上にはパネルを出さない（立っている間は安全。雑魚だけが相手）。
- 見た目：`ClaudeArt.ArtifactPanel`（能力のパネルと同じ絵）と `ClaudeArt.Spark`。開くときに横へ広がる（Artifacts の開き方）。

**ステージの決まりの直し**
- `ClaudeRule` は世界に何も出さない（使用量のメーターだけ）。`ClaudeArtifactAttack` は能力で、その場に開く型（`SpawnInPlace`）。**直しなし**。

**公平さ**
- 雑魚の時間：同時に 2枚まで。プレイヤーに近い 1枚は「今いる所」ではなく、決めた 6か所のうち近い所（少し動けばよけられる）。
- ボス戦：出ない。

## 3. Gemini：「ふたご星」

**出来事**
- 元ネタ：Gemini＝ふたご座。青とピンクの 2つの星。答えの案がいくつも並ぶ。
- 部品：`Orbit` ＋ `Catch`。
- 並べ方：部屋のまん中（x 0、y 4.5。動く返事のカードのあたり）を中心に、青い星とピンクの星（それぞれ直径 1）が向かい合って回る。count 2、radius 4.5、1周 5秒（最初は時計回り）。6秒たったら 0.5秒止まって逆回り。duration 12秒。
  星のうしろに、うすい尾（0.4秒の残像）。半径 4.5 なので、床（y 0）と足場（y 3）の両方を通る。
- 予告：回る道すじを、うすい点線の円で 1.0秒見せる。星の出る場所に小さい 4つ角の星。逆回りの前に、星が白く点滅（0.5秒）。
- Catch：4秒・8秒に、中心から小さい 4つ角のきらめきが、ゆっくり外へ流れる（speed 2。向きは星と 90度ずれた方）。取ると、クールタイムを全部戻す（1回目）／星が 3秒止まる（2回目）。
- 見た目：`GeminiArt.Star4`、青 #4285F4・紫 #9B72CB・ピンク #D96570。

**ステージの決まりの直し**
- `GeminiImageAttack`（ボスの第2形態。絵が **画面の上から** プレイヤーの位置へ落ちる）→ **その場に生成される**向きにする。
  `FallingObject.Spawn(…arena.yMax…)` を `FallingObject.SpawnInPlace(owner, _frame, 位置, Time.time + TelegraphTime)` に変える（Claude のパネルと同じ呼び方）。
  位置はプレイヤーの足元の床・足場の上（絵の下の辺を合わせる）。予告は額ぶちの点線の枠＋中にモザイクが下から 1段ずつ埋まる（「生成中」）。着地後 3秒、足場として残るのは今のまま。
- `GeminiRule` の星の札は置く物（落ちない）。**直しなし**。

**公平さ**
- 雑魚の時間：星は 2個が向かい合うので、いつも半周分のすき間がある。中心の近く（半径 3 より内）はずっと安全。
- ボス戦：出来事は出ない。画像生成は枚数・間隔は今のまま（2枚・0.6秒）。上から来ない分、ボスの弾と重なっても見分けやすい。

## 4. Notion：「ドラッグ＆ドロップ」

**出来事**
- 元ネタ：ブロックの左の「⋮⋮」をつかんで、横から引っぱって入れる。トグル「▶」でたたむ。
- 部品：`EdgeSweep`（side=Both、wave なし）＋ `HitTarget`。
- 並べ方：白いブロック（横 4×縦 1。左に「⋮⋮」）が、左右の端から **まっすぐ・ゆっくり** 横切る（speed 5）。段は 3つ（y 0.5／3.5／5.5）。
  1回に 1個、左右を交互、段は「プレイヤーが今いる段」。2.0秒おきに 6個（約 12秒）。画面に同時に 2個まで。
- 予告：出る端に、青い線（ドロップの位置の線。Notion の青 #2F80ED）＋「⋮⋮」（0.9秒）。
- HitTarget：4個目の予告と同時に、まん中の上の段（x 0、y 5.8）にトグル「▶」（life 4秒）。叩くと「▼→▶」と回って、画面のブロックが全部たたまれて消える＋残りが出ない。叩かないと、5・6個目は 2個同時（上下の別の段）。
- 見た目：`NotionArt` の白・黒・`NotionKit.ArtBlock`。ブロックのうしろに、うすい青い影（ドラッグ中の影）。

**ステージの決まりの直し**
- `NotionBlockStack`（ボスの技。ブロック 3個が **画面の上から** プレイヤーの位置へ落ちて積まれる）→ **横から引っぱって入れる**。
  当たりは `FallingObject.SpawnInPlace`（出現）にして、位置は「プレイヤーの x、高さは 1個目＝床の上、2個目＝その 1つ上、3個目＝さらに上」（階段のように積む）。
  予告の 0.8秒の間、ボスのいる側の端から、うすいブロックの影がその位置まですべってくる（見た目だけ）。着地後 4秒、足場として残るのは今のまま。
- `NotionRule`（足場のトグル）は落ちる物ではない。**直しなし**。UI の足場の「トグルの行」2枚を開閉する（`stage` の JSON と合わせ済み）。

**公平さ**
- 雑魚の時間：ブロックは遅い（5マス/秒）。段を 1つ変えればよけられる。トグルは「叩けば楽になる」だけで、罰は 2個同時が 1回。
- ボス戦：出来事は出ない。ブロックを積む技は、上から来ないので、浮いているボスの下にいても見える。数・間隔は今のまま。

## 5. メモ：「チェックリスト」

**出来事**
- 元ネタ：チェックリストの丸「○」を順に押して「✓」にする。
- 部品：`HitTarget`（3つを順に）＋ `Pop`。
- 並べ方：黄色い丸「○」の的が 1つずつ出る。場所は UI の足場の上：チェックの行 1（x −3.5、y 3.8）→ チェックの行 2（x +3.5、y 3.8）→ チェックの行 3（x +7.5、y 5.6）。
  それぞれ life 3.5秒。叩くと「✓」になって次が出る。3つ全部でごほうび：クールタイムを全部戻す＋ `NotesRule` のチェックリストの 1行分に数える（できれば）。
- 時間切れ（叩けなかった）：その的の場所に、インクのしみ（`Pop`。直径 2.5、warn 0.8秒、life 1.0秒）が出て、次の的へ進む。
- 間に：的が出ている間、2.5秒おきに、プレイヤーから 3マス以上離れた床に、小さいしみ（`Pop`。直径 1.5、warn 0.8秒）を 1つ。全部で約 12秒。
- 予告：的は白いふち＋黄色（赤は使わない）。次の的の場所へ、点線がすっと伸びる（どこへ行くか分かる）。しみは赤い点線の丸。
- 見た目：`NotesArt` の黄色 #FFD60A・紙の色。しみは濃い灰色（真っ黒にしない。#555 くらい。敵と見分ける）。

**ステージの決まりの直し**
- `NotesRule` は世界に何も出さない。`NotesQuickMemo`（ボスの技）は部屋の **下の隅から** せり出す型で、もう上からではない。**直しなし**。

**公平さ**
- 雑魚の時間：危ない物は小さいしみだけ（同時に 1つ）。的は足場の上なので、UI の足場を使う練習になる。
- ボス戦：出ない。

## 6. Excel：「棒グラフ」

**出来事**
- 元ネタ：表を選ぶと棒グラフができる。選んだセルの緑の枠。
- 部品：`Erupt` ＋ `SafeSpot`。
- 並べ方：床を、セルの幅（2.1マス＝背景の 1列）で 9列に分ける。1回ごとに：緑の枠のセル（`SafeSpot`。幅 2.1）が 1列だけ点滅 → 1.2秒後、それ以外の列から、緑の棒が **床からせり上がる**。
  棒の高さは列ごとにちがう（1.5／2.5／3.5 を、グラフらしく並べる）。左の列から右へ 0.08秒ずつずらして上がる（rise 0.25秒、hold 0.6秒、引っこむ 0.3秒）。
  全部で 3回（1回 3.8秒。約 12秒）。安全の列は毎回変わる（前の列から 2〜3列となり。プレイヤーから 6マス以内）。
- 高さ 2.5 までの棒の列は、下の足場（y 3）の上が安全。高さ 3.5 の棒は足場にも届く（予告の割れ目が太い）。
- 予告：安全の列＝緑の枠＋右下の小さい四角（フィルハンドル）。危ない列＝床に光る割れ目＋列の上に、うすい棒の形（高さが分かる）。
- 見た目：`ExcelArt` の緑 #217346。棒の上に数字（「12」「48」など）。3回目だけ、棒が上がったあとに、棒の上をつなぐ折れ線が 0.3秒光る（飾り）。

**ステージの決まりの直し**
- `ExcelRule` は世界に何も出さない。**直しなし**。
- （できれば）`ExcelAutofillAttack`（ボスの技）の予告に `Conveyor` を足す案：オートフィルの伸びる向きへ、床が 2秒流れる（speed 2）。今日は後回しでよい。

**公平さ**
- 雑魚の時間：安全の列は必ず 1つ＋低い棒の列の足場の上。1回目は棒を全部 2.5 以下にする（足場に乗ればよい、と分かる）。
- ボス戦：出ない。

## 7. PowerPoint：「バウンド」

**出来事**
- 元ネタ：アニメーションの「バウンド」（図形が跳ねながら入ってくる）。
- 部品：`Bounce`。
- 並べ方：図形（丸・星・矢印。直径 1.4）が、画面の **左上か右上の角の外** から斜め下へ入って、床と壁で跳ね返りながら進み、4回跳ねて消える。speed 8、bounces 4。
  跳ねる高さは 1回ごとに低くなる（3.5 → 2.5 → 1.8 → 1.2。本物のバウンドと同じ）。
  1個目は左上から、2.5秒後に 2個目は右上から、…と交互に 4個（約 13秒）。同時に 2個まで。
- 予告：入る角に矢印＋最初に落ちる床の場所に赤い印（1.0秒）。跳ねるたびに、次に落ちる場所へ小さい印（0.3秒前）。
- してほしいこと：高く跳ねている間に下をくぐる。低くなったらジャンプで越える。上の足場（y 5）にいれば、3回目からは届かない。
- 見た目：`PowerPointArt` のオレンジ（#ED7D31・#FFC000）。図形のうしろに、アニメーションの軌跡の点線（緑の ▶ から赤の ■ へ）を一瞬。跳ねた所に星の小さい効果。

**ステージの決まりの直し**
- `PowerPointRule.DropSlide()`（レーザーポインターの点に、スライド 3×2 が **上から落ちる**。`FallingObject.Spawn`）→ **横から「スライドイン」**。
  `EdgeSweep`（side＝プレイヤーから遠い方の端、y＝点の高さ、speed 14、count 1、wave なし）。スライドは画面を横切って反対の端へ抜ける。
  予告は今の 0.8秒の輪のまま＋入る端に矢印。点の高さに来るので、「点が自分に重なったら、しゃがむのではなく段を変える」。
- 落ちたスライドが 2秒足場になる所は、やめる（UI の足場が増えたので、いらない）。残したいときは、`FallingObject.SpawnInPlace` で点の所に出して、見た目だけ横からすべらせる。
- 間隔（雑魚の時間 12秒・ボス戦 18秒）と「危ない物が無いときだけ」は今のまま。

**公平さ**
- 雑魚の時間：図形は同時に 2個まで。入る角はプレイヤーから遠い方から始める。
- ボス戦：出来事は出ない。スライドインは横 1本だけ（高さは点で分かる）。ボスの技の最中は出さない（今の `HazardCount == 0` のまま）。

## 8. Word：「スペルチェックの波」

**出来事**
- 元ネタ：まちがった字の下の、赤い波線。
- 部品：`FloorWave`。
- 並べ方：赤い波線（高さ 0.9）が、床の端から走ってくる。speed 9。
  1本目：左から。2本目（2.2秒後）：右から。3本目：左から、すぐあと（0.7秒）にもう 1本（2回続けてジャンプ）。4本目：左右から同時（まん中で出会って消える。足場に乗るか、出会う前に 1本を越える）。全部で約 12秒。
- 予告：出る端の床に、赤い「ABC」＋波線が小さくふるえる（0.9秒）。左右同時のときは、両方の端＋まん中の床に「×」。
- してほしいこと：ジャンプで越える。または UI の足場（文字の行）に乗る。**波を近接・能力で叩くと「直す」**（`WordRule` の直しと同じ数え方。3つ直すとクールタイムが戻る、に数える）。
- 見た目：`WordSpellWave` の赤い波線と同じ絵（床を走る版）。通ったあとの床に、青い二重線（文法の線）が 0.3秒残る（飾り）。

**ステージの決まりの直し**
- `WordRule` の波線は、床に置く物（落ちない）。**直しなし**。出来事の間は、決まりの波線を新しく出さない（床が波だらけにならないように）。

**公平さ**
- 雑魚の時間：波は低い（0.9）。ふつうのジャンプで越えられる。足場の上はずっと安全。
- ボス戦：出ない。決まりの波線は今のまま（ボス戦は同時に 1つ）。

## 9. Keynote：「マジックムーブ」

**出来事**
- 元ネタ：マジックムーブ（前のスライドの物が、次のスライドの場所へすっと動く）。発表のスポットライトと拍手。
- 部品：`Diagonal` ＋ `HoldZone`。

**ステージの決まりの直し**

**公平さ**

## 10. Safari：「コンパス」

**出来事**
- 元ネタ：Safari の印のコンパス。赤と白の針が回る。
- 部品：`Orbit`（針の形）＋ `Catch`。
- 並べ方：部屋のまん中（x 0、y 4）に、コンパスの軸。そこから **針（長い棒）** が 2本、反対向きに伸びて回る。
  `Orbit` を「同じ角度に 3個ずつ並べる」（radius 2／4／6 の 3個で 1本の針。count 3×2本。1個は直径 1）。1周 7秒（ゆっくり）、duration 12秒。半分（6秒）で逆回り。
  針は床（y 0）まで届く：床にいるときは、針が来たら足場へ上がるか、針の進む向きへ一緒に歩く。
- 予告：軸に、方位の印（N・E・S・W）と、針の通る円（半径 6）をうすい点線で 1.0秒。針は、出る前に細い線で 1.0秒見せる。逆回りの前に、軸が 0.5秒点滅。

**ステージの決まりの直し**
- `SafariRule` は世界に何も出さない。**直しなし**。

**公平さ**
- 雑魚の時間：針は 2本だけで、間は 180度あいている。ゆっくり（床の上で約 5マス/秒）なので、歩いて逃げられる。軸の近く（半径 1.5 より内）は安全。

## 11. Firefox：「しっぽの炎」

**出来事**
- 元ネタ：地球に巻きつく狐のしっぽ（炎）。追跡者（トラッカー）のブロック。
- 部品：`WallCrawl` ＋ `HitTarget`。
- 並べ方：オレンジの炎（横 2.5×縦 1.2 のかたまり＋うしろに 3マスの尾）が、部屋のふちを **ぐるっと 1周** する。左下の角から時計回り（床を右へ → 右の壁を上へ → 天井を左へ → 左の壁を下へ）。speed 9（1周 約 7秒）。
  3秒後に、2つ目が右上の角から、同じ時計回りで出る（向かい側を走る）。それぞれ 1周半で消える（約 13秒）。
- 予告：出る角に炎の印＋進む向きの矢印がふちに沿って流れる（1.0秒）。炎の 3マス前のふちが、うすくオレンジに光る（来る場所が分かる）。
- してほしいこと：床を走ってくるときは、足場へ上がる（炎の高さは 1.2。下の足場 y 3 は安全）。壁ぎわに立たない。
- HitTarget：5秒たったら、まん中の上（x 0、y 6）に紫の盾の的「追跡者をブロック」（life 4秒）。叩くと、炎が 2つとも消える＋ `FirefoxRule` の拡張機能のかけらを 1つ進める（できなければ、クールタイムを全部戻す）。叩かなくても罰はない。
- 見た目：`FirefoxArt` のオレンジ #FF7139・黄 #FFBD4F・紫 #7542E5。`FirefoxTailFlame`（ボスの技）と同じ炎の絵。赤は使わない（オレンジ〜黄）。

**ステージの決まりの直し**
- `FirefoxRule`（拡張機能のかけらが **画面の上から落ちて** 床・足場で止まる。`FirefoxPiece.Setup(new Vector2(x, area.yMax − 0.5f)…)`）→ **横から跳ねて入ってくる**。
  `Catch`（道すじ＝`Bounce`）：左右の端（プレイヤーから遠い方）の高さ 4 から入って、床で 2回跳ねて止まる。止まってからの残る時間（6秒）・取り方は今のまま。
  良い物なので予告はいらないが、入る端に紫の小さい矢印を 0.5秒。

**公平さ**
- 雑魚の時間：炎は同時に 2つ、いつも向かい側。床を通るのは 1つずつ（2秒ちょっと）。足場の上と、部屋のまん中の空中は、ずっと安全。
- ボス戦：出来事は出ない。かけらは危なくないので、向きを変えても公平さは同じ。
