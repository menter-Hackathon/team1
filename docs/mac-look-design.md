# 見た目を全部 Mac に揃える（Mac らしさの決まりと、直す物の一覧）

- 書いた日：2026-11-19
- 書いた人：Claude（Fable 5.2。アートディレクション）。まさぴ〜の依頼「それぞれのデザインを全部 mac に揃えてください」。
- 実装：Opus 5.5 の実装担当が 3〜4人で並行して行う（5章）。
- 締め切り：開発 2026-11-20（今は 11-19）。
- 対象：**ゲームの中の見た目だけ**（技・能力・当たった絵・通知・ボスのウィンドウ・ステージの部品・ステージの間のデスクトップ）。
  - **当たり判定・秒数・ダメージ・ゲージ・出る位置は変えない。** 絵の大きさも、判定に合わせた今の大きさのまま。
  - タイトル・能力えらび・HUD・リザルト・ゲームオーバー・図鑑は、デザイン担当の画面イメージに合わせた物。**勝手に変えない。** Windows っぽい所は【要相談】（6章）。
- 元の仕様：[スキルの見た目](app-skill-visuals-design.md)。スキン×枠・当たった絵・重なる順番・赤いふち／白いふちの決まりは、そのまま。
  - **食い違う所は、この文書が正しい**（ポップアップの右上の ×＝2-3、隅の通知の場所＝1-5、`Not Responding`、通知の地の色＝1-6）。元の仕様は書き換えていない。
- 細部（色の16進・ドットの数・文字列）は、すべて【仮】。
- この仕様は、ビルドしたゲームの画像（`visuals_*.png`・`sv_*.png`・`shots_sv/`）とコードを読んで書いた。Unity では動かしていない。

## 0. 考え方

### 0-1. 直す物と、残す物

- **直す＝OS の部品**：ウィンドウの枠とボタン・ダイアログ・通知・メニューバー・Dock・カーソル・待ちの印・キーの表記・「応答なし」などの言い方・閉じるときの動く向き。
- **残す＝アプリの中身**：どの OS でも同じ見た目の物。昨日作った「見ただけでアプリが分かる」の元なので、消さない。
  - Chrome のタブ（× は右。Mac の Chrome も同じ）・`Aw, Snap!`・404・タブの読み込みの輪。
  - VS Code の行番号・波線・デバッグの操作バー。Excel のセル・グラフ・シートのタブ・動く点線。
  - Steam の実績のパネル・ライブラリのタイル。コントローラーの A B X Y（【要相談 9】）。
  - Zoom のタイル・名札・退出のボタン。Slack・LINE の吹き出し。AI のカード。プレーヤー。Premiere のタイムライン。
- **ゲームの決まりの印は、Mac にしない**：予告の赤い「！」の三角・赤いふち・白いふち・点線の枠。UI のまねではなく「危ない」の印。
  - ダイアログの**中**の注意のアイコンだけ、Mac の黄色い三角にする（1-3）。
- ウイルス（黒と赤）は今のまま。

### 0-2. この Mac の設定【仮】

- **ライトモード**（デスクトップの画面のメニューバーが、今すでに明るい）。
  - 暗い見た目にするのは、中身が暗いアプリだけ：VS Code・Terminal・Premiere Pro・Steam・Spotify・ChatGPT。
- **言葉**：戦いの中の飾りの字は、今までどおり英語（Mac の英語の言い方）。日本語にするかは【要相談 7】。
- **ロゴは描かない**（今までの決まり）。リンゴのマークは使わない。代わりの印は 1-5。

## 1. Mac らしさの決まり（共通の部品 `MacUi`）

- 置き場【仮】：`Assets/Scripts/Visual/Skins/MacUi.cs`（新しいファイル。担当1 が最初に作る）。
- **ウィンドウ・ダイアログ・通知・信号機・待ちの印・キーは、必ず `MacUi` で描く。** 自分のファイルに色やドットを書かない。
  - 今は、信号機の色が 4か所、待ちの輪が 3種類、「！」の三角が 3つ、四角を置く道具が 4つ、別々にある。
- 今ある Mac らしい値は、そのまま使う（`GenericFxFalling`・`FinderFxWindow`・`FxArt.BeachBall`・`DevArt.Key`）。
- 大きさは、ゲームの世界の絵のドット（1マス＝18ドット）。OnGUI の画面（デスクトップ・Spotlight・Premiere の窓・再起動）は、仮想の画面 640×360 のドットで、同じ数を使う。

### 1-2. ウィンドウ `MacUi.Window`

| 部品 | 決まり |
|---|---|
| 角 | 丸い。2ドット欠く（幅 80ドット以上は 3ドット）。四角い角は使わない |
| ふち | 1ドット。立体の3重のふち（ベベル）は使わない |
| 影 | 下へ 2ドットずらした黒 30%（ウィンドウと同じ形）。**敵の物は、影を判定の外・下にだけ出す** |
| タイトルバー | 高さ 7ドット（ウィンドウの高さが 20ドットより小さいときは 5ドット） |
| 信号機 | **左上**。丸 3つ。直径 3ドット（3×3。4つの角のドットは 5割すかして丸く見せる）。左のふちから 3ドット、間は 1ドット（x＝3・7・11）。縦はタイトルバーのまん中 |
| 小さいウィンドウ（幅 30ドットより小さい） | 信号機は 1ドットの点 3つ（x＝2・4・6） |
| 題名 | **まん中**。字が入らないので、灰色 `#8E8E93` の棒（高さ 2ドット、幅はウィンドウの 3割）。幅 80ドット以上は字（Press Start 2P、高さ 0.4マス） |
| 右上 | **何も置かない。× は置かない** |
| ツールバー（あれば） | タイトルバーの下に 5ドットの帯。アプリの色を入れるなら、ここ |

- **閉じる動き**：左上の赤い丸が 0.05秒へこむ（1ドット暗く）→ ウィンドウが**まん中へ**縮みながら消える（0.1秒）。右上へ向かって縮む動きは、やめる。
  - 「右へすべって消える」は通知だけ（1-4）。
  - 余裕があれば：下へ細く吸い込まれる（Dock へしまう動き。Generic のワープと同じ形）。
- **出る動き**：0 → 115% → 100%（0.1秒）。今のまま。
- **大きさの合わせ方**：54×36 の絵を、判定に合わせて縦横べつべつに伸ばすと、信号機がつぶれる。**判定のマス×18 のドットで絵を作る**（伸ばさない）。キャッシュの鍵に大きさを入れる。

### 1-3. ダイアログ `MacUi.Alert`

- 並び：**左にアプリのアイコン**（16ドット。`PixelIcon`）→ 右に**太字の題名**（1行）→ その下に本文（灰色の棒 1〜2本。字は入れない）→ **右下にボタンを右寄せ**。
- ボタン：高さ 7ドット、角を 1ドット欠く。**いちばん右が既定のボタン（青 `#0A84FF`）**。その左に白いボタン。
  - 並びは「（やめる側）（進む側＝青）」。Windows の「OK／キャンセル」の並び（進む側が左）にしない。
  - ボタンの字は、入るときだけ（幅 20ドット以上）。入らなければ棒。字は下の表の物だけ。
- 注意のダイアログ：アプリのアイコンの右下に、**黄色い三角**（`#FFD60A`、黒い「！」。8ドット）を重ねる。赤丸に白い × のアイコン（Windows のエラー）は、OS のダイアログでは使わない。
  - VS Code の赤丸 × は、VS Code の中身なので残す。
- タイトルバー：信号機 3つ（赤だけ色つき、黄と緑は `#C7C7CC`）。題名は無し。
- 大きさの目安：落ちてくる物・窓の枠は判定どおり（54×36）。
- **ダウンのダイアログは、幅 9マスまで**（2倍にしない。Press Start 2P は字の幅＝字の高さなので、0.4マスの字は 20字で 8マス）。題名は 18字まで。長ければ2行に分ける。

### 1-4. 通知 `MacUi.Banner`

- 形：角の丸い板（角を 3ドット欠く）。ふちは無し（影だけ。敵の攻撃の物は赤いふち）。地は 1-1 の「通知の地」（明るい）。アプリの色のふちは、やめる。
- 中：左にアプリのアイコン（16ドット、左と上下から 5ドット）→ 右に題名 1行（太字、`#1C1C1E`。黒いふちどりは付けない）。右上に、うすい灰色の小さい棒（時刻の代わり。7×1ドット）。
- **隅の通知の場所**：画面の**右上**。右の端から 0.35マス、**上の端から 2.3マス下**（HUD の「STAGE」とボスのゲージの下）。
  - 動き：右からすべり込む（0.15秒）→ 1.6秒 → 右へ出ていく（0.2秒）。秒数は今のまま。
  - 大きさは今のまま（5.5×1.5マス＝99×27ドット。字が長ければ横に伸ばす）。
  - プレイヤー・ボスが後ろに重なっている間は 4割まですかす（今のまま）。
  - HUD・Spotlight の検索バー・Premiere の窓・Terminal のコマンドの帯は OnGUI なので、いつもゲームの世界の絵（通知）より手前に出る。**順番では勝てない。場所でよける**（上の 2.3マスは、HUD の下・検索バーの右の外）。通知が出るのは「とどめ」の後だけなので、技の表示とは同時に出ない。
- 題名の字は今のまま（`Page restored`・`Build succeeded`・`Saved` など）。
- 小さい通知（攻撃の板。22×9・27×11）：同じ形で、角を 2ドット欠く。アイコンは 5〜7ドットの角の丸い四角。

### 1-6. 待ちの印 `MacUi.BeachBall`・`MacUi.Spinner`

### 1-7. キーの表記 `MacUi.Key`

- キーの形：9×9ドットの角の丸い四角（地 `#E5E5EA`、下に影 `#A0A0A5` 1ドット、字 `#1C1C1E`）。`DevArt.Key` を移す。
- 記号はドット絵（フォントに無い）：`⌘`（今の `CmdRows`）・`⌥`・`⇧`・`⌃`・`⏎`（`FinderSkinArt.Return6`）・`⎋`・`⌫`。足すのは使う物だけ。
- 並べる順：`⌃ ⌥ ⇧ ⌘` → 字（`⌘X`、`⌥⌘⎋`）。
- **`Ctrl`・`Alt`・`Win`・`Enter`・`Del` の字は書かない。** `Enter` は `return` か `⏎`。

### 1-8. 字（フォントの代わりの形）

- Mac の字（San Francisco）は使えない。今のフォントのまま：英字は Press Start 2P、日本語は DotGothic16。
- Mac らしく見せる決まり：
  - **題名は太字 1行、本文は灰色の棒**（字で説明しない。今までの決まりとも合う）。
  - **文の形**（先頭だけ大文字。`Save?`・`Force Quit`）。全部大文字にしない（`NOT RESPONDING`・`SAVE?` はやめる）。
    - `K.Text`（3×5 の字。大文字だけ）は、Mac の部品の字に使わない。`MacUi.Label`（`WorldText`。Press Start 2P、高さ 0.4マス以上）を使う。入らなければ棒。
    - グラフの数字・`#REF!`・`HIT!`・`LOADING` などアプリの中身の字は、今のままでよい。
  - 引用のかぎ（“ ”）と `…` はフォントに無い。使わない（`Reopen`・`Report` と書く）。
- アプリの名前を字で出すとき：英数字だけの名前はそのまま（12字まで）。日本語の名前（ミュージックなど）は、字を出さずアイコンだけ。

### 1-9. 強制終了・「予期しない理由で終了しました」（Mac の言い方）

| Windows・どの OS か分からない言い方 | Mac の言い方【仮】 | 見た目 |
|---|---|---|
| `Not Responding`（題名だけの板） | **強制終了のウィンドウ**：題名（まん中）`Force Quit`、行に「アプリのアイコン＋赤い字 `Not Responding`」、右下に青いボタン（棒） | `MacUi.ForceQuit`。行はうすい青の選択。上に待ちカーソル。幅 9マスまで |
| `Crashed`・クラッシュの板 | **終了のダイアログ**：左にアプリのアイコン、題名 `quit unexpectedly.`（アプリ名は字で書かない。アイコンで分かる）、右下にボタン `Ignore` `Reopen`（`Reopen` が青） | `MacUi.Alert`。アイコンに黄色い三角。幅 9マスまで |
| `OK`／`Cancel`（OK が左） | `Cancel` `OK`（**OK が右で青**） | |
| `Yes`／`No` で保存を聞く | `Don't Save` `Cancel` `Save`（`Save` が右で青）。せまければ右の2つ | |
| 砂時計・青い輪 | 待ちカーソル（虹色の輪） | 1-6 |
| `System Rebooting...`（字） | 黒い画面・まん中に印・細い進みのバー。字は無し | 2章 12 |
| `[ OK ]`（Linux の起動の行） | zsh のジョブの行：`[1] + done`・`[1] + killed` | 2章 14 |
| `$ `（プロンプト） | `% `（zsh。Mac の今のシェル） | 2章 15 |
| `C:\…`・`.EXE`・`.TXT` | `~/Desktop/…`・`.app` | 【要相談 2】 |
| `Enter`・`Ctrl` | `return`・`⌘` | |

- キーの飾り：強制終了のウィンドウの下に、キー 3つ `⌥ ⌘ ⎋`（Mac の強制終了のショートカット）を並べてよい（優先度 C）。

### 1-10. `MacUi` の形（実装担当への約束）【仮】

描き方が4つあるので、入口を3つに分ける。**色と数は 1つの場所（`MacUi` の定数）に置く。**

```
// 色・数（全員が読む。担当1 が最初の 30分で入れる。中身が空でもビルドが通ること）
MacUi.Red … MacUi.Light5、MacUi.LightR/LightY/LightG、MacUi.TitleH = 7、MacUi.LightD = 3
enum MacLook { Light, Dark }

// (a) 絵を作る（ドットの格子に置く。BrowserDevGrid と K の char[,] のどちらからも使える）
MacUi.StampLights(Action<int,int,Color32> put, int x, int yTop, bool active = true)   // 信号機
MacUi.StampTitleBar(Action<int,int,Color32> put, int w, MacLook look, bool titleBar)   // タイトルバー＋題名の棒
Sprite MacUi.WindowSprite(int w, int h, MacLook look, Color32? edge = null, int toolbarH = 0)
```

4. 最後に：自動の撮影（ビルドしたゲーム）で、Chrome・VS Code・Excel・Slack・Steam・Finder・Terminal・デスクトップの画面を撮って、まさぴ〜に見せる。

### 5-3. 優先度

| 優先度 | 物 |
|---|---|
| **A**（発表で必ず映る） | `MacUi`。隅の通知を右上へ（1）。ボスのウィンドウ（2・3）。Chrome のポップアップと閉じる動き（13〜15・22）。ダウンのダイアログ（5・18・23）。ウィンドウの足場（26）。デスクトップの画面の矢印とウィンドウ（39・40） |

### 5-4. 確かめること（実装担当）

- 直す前と後で、当たり判定の位置・大きさ・秒数が同じこと。
- 画面のどこにも：右上の ×・オレンジの閉じるボタン・立体の3重のふち・四角い信号機・砂時計・`NOT RESPONDING`・`[ OK ]`・`$ ` が残っていないこと（戦いの画面とデスクトップの画面。メニューの画面は【要相談】なので除く）。
- 隅の通知が、HUD・ボスのゲージ・Spotlight の検索バーに重ならないこと。1280×720・1100×620・1440×900 の3つで。
- 信号機が、どのウィンドウでも「丸 3つ・左上・同じ間」に見えること（伸ばしてつぶれていない）。
- 敵のウィンドウは赤いふち、足場になったら灰色のふちになること（今の決まり）。
- 再起動の演出（Terminal）で、ボスのウィンドウの赤いふちが、新しい絵でも正しい行に出ること。
- 自分の持ち場の外のファイルを変えていないこと。

## 6. 【要相談】まさぴ〜・デザイン担当に聞くこと

1. **壁紙**：ステージの壁紙（デザイン担当の絵）は、青い空・白い雲・緑の丘。Windows XP の壁紙にそっくり。アプリの色に塗り替えた後でも、Chrome のステージでは元の色がそのまま出る。Mac らしくするなら、Mac の壁紙に近い形（色の帯が重なる波・砂丘など）に描き直す。**デザイン担当の絵なので、変えていない。**
2. **メニューの画面のウィンドウ**（タイトル・能力えらび・リザルト・図鑑）：灰色の3重のふちと、右上の大きいオレンジの ×。題名が `C:\DESKTOP\INFECTED.EXE`・`SAMPLE_DATA.EXE`・`APP_DEX.EXE`・`SCAN_REPORT.TXT`。どれも Windows の形。
   - Mac にするなら：左上に信号機、題名はまん中、`~/Desktop/Infected.app`・`Scan Report.txt`。× のクリックは赤い丸に。
   - **今回、戦いの中のウィンドウだけを Mac にすると、メニューのウィンドウと形が食い違う。** そろえるかどうかを決めてほしい。
3. **ゲームオーバーの画面**：濃い紫に `:(` と「PCがウイルスに完全に感染しました」。Windows の青い画面の形。「最後に戦ったウィンドウ：Steam.exe」の `.exe` も。Mac にするなら：黒い画面に「問題が起きたため、コンピュータを再起動しました」の形と、`Steam.app`。
4. **HUD**：能力の枠（立体のふち・選ぶとオレンジ）と相棒の箱。Mac にするなら、角の丸い枠・Dock の形。場所は今のまま。
5. **タイトルの `PRESS Z / ENTER`**：Mac のキーは `return`。`PRESS Z / RETURN` か `Z / ⏎` にするか。
6. **通知の地の色**：Mac のライトモードに合わせて、明るい地・黒い字にした（1-4）。Chrome のステージ（白い雲）で読みにくければ、暗い地（今の色）に戻す。`MacUi` の定数1つで切り替えられる。
7. **ダイアログの字を日本語にするか**：デスクトップの画面のメニューバーは日本語。戦いの中の字は英語（`quit unexpectedly.`・`Force Quit`）。日本語（「予期しない理由で終了しました」・「強制終了」）は DotGothic16 で 12ドット以上（0.67マス）が要る。「予期しない理由で終了しました」は 14字で 9.4マスになり、幅 9マスに入らないので2行になる。
8. **Terminal の `[ OK ]`**：Linux の起動の行なので、zsh の `[1] + done`・`[1] + killed` に変える案にした（2章 8）。`[ OK ]` は昨日の見た目の目玉なので、残したければ残す。
9. **コントローラーの A B X Y**（Game の小弾・ボムの印）：Xbox の色と並び。Mac でも同じコントローラーを使うので「アプリの中身」として残した。気になるなら、字を消して色の丸だけにする。
10. **実在の UI の言い方**：`quit unexpectedly.`・`Force Quit`・`Not Responding`・虹色の待ちカーソルは、Mac の本物とほぼ同じ（元の仕様の【要相談 4】と同じ話）。
11. **リンゴの代わりの印**：メニューバーの左と再起動の画面に、プレイヤーの顔の小さい絵を置く案（1-5・2章 12）。ウイルスの顔にするか、何も置かないか。
