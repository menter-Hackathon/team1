# ステージのギミックの動きを増やす：C の12アプリ（2026-11-19）

`docs/stage-gimmick-variety.md` の 2章のつづき。Unity・Blender・Minecraft・QuickTime・GitHub Desktop・Xcode・Steam・ミュージック・Spotify・Figma・Photoshop・Illustrator。
どれも【仮】。コードはまだ書いていない（設計だけ）。

## 0. 共通の決まり

- **座標**：マス。部屋のまん中が x＝0、床の上が y＝0。部屋の幅は x −10〜+10。
- **UI の足場**（`Tools/art/appbg/apps/<ラベル>.json` の `stage`）：どのアプリも、ほぼ同じ場所にある。
  - 左右の低い足場：x −3.5 と x ＋3.5、高さ 3
  - まん中の足場：x 0 付近、高さ 5（動く・消える物が多い）
  - 左右の端の足場：x −8 と x ＋8、高さ 4.5〜5
  - 叩けるボタン：床の近く
- **出来事は場面③（雑魚の時間）だけ**。ボス戦には出ない（`StageEvent` の今の決まりのまま）。だから「公平さ」の欄は、①出来事の中の逃げ場、②ステージの決まり（StageRule）を直す所のボス戦での扱い、を書く。
- **強さ**（`Begin` の strength 1・2・3）：とくに書かなければ、数は「弱い／ふつう／強い」の順。速さは変えない（予告の長さも変えない）。
- **予告**：0.8 秒以上（部品の決まりは 0.6 秒以上だが、出来事は雑魚もいるので長め）。赤は「当たる物」だけ。良い物・叩く的・立つ場所は、アプリの色（赤にしない）。
- **出来事の間は、そのアプリのステージの決まりの危ない物を止める**（Unity の物体・GitHub の合流の柱）。重なると読めない。`ctx.CanSpawnHazard` が false になるようにするか、出来事の側から止める入口を作る（実装の担当に相談）。
- **雑魚**：どの出来事も `SpawnsOwnZako＝false`（雑魚は StagePacer が出す）。`extraZako＝0`。
- **終わり**：`End()` で出した物を全部消す（部品に owner を渡すか、出来事が自分で覚えておく）。
- **使う部品の重なり**（主に使う物。3アプリまで）：

| 主な部品 | アプリ |
|---|---|
| Diagonal | Unity・Figma |
| Conveyor ＋ Pop | Blender |
| Erupt | Minecraft |
| EdgeSweep（行って戻る） | QuickTime |
| FloorWave | GitHub Desktop・ミュージック |
| HoldZone | Xcode |
| Orbit | Steam（的を運ぶ）・Illustrator（当たる物） |
| Bounce | Spotify |
| WallCrawl ＋ SafeSpot | Photoshop |

## 1. Unity：「Play Mode」

**元ネタ**：再生ボタンを押すと、Scene の物が動き出す。移動のギズモ（赤・緑・青の矢印）。床の格子。

**出来事（14 秒）**
1. 0.0 秒：上のツールバーの再生ボタンが青く光る（飾り。Pop の予告の印だけを借りる）。背景の色を少し青く（Play Mode の色。うすい板 10％）。
2. 1.0 秒〜：**Diagonal（主）**＝ギズモの矢印。部屋の上の左右の角・左右の壁のまん中（高さ 4）の4か所から順番に、プレイヤーへ予告の線（0.8 秒）→ 矢印が飛ぶ（速さ 9）。
   - 2.2 秒おき。数は 4／5／6 本。spread 0（1本ずつ）。強さ 3 だけ、最後の1回は左右の角から同時に 2本。
   - 色：x の矢印（うすい赤 `#E2463E`…当たる物なので赤でよい）、y（緑）、z（青）を順番に。形は UnityArt の矢印（無ければ細長い三角）。
3. 4.0 秒と 9.0 秒：**Erupt**＝床の格子からプリミティブ（立方体・カプセル）がせり上がる。
   - 場所：プレイヤーの今の x（幅 1.6）と、そこから ±4 の片方（幅 1.6）。合わせて 2本／2本／3本。
   - 予告 1.0 秒（床の格子が白く光る割れ目）→ 0.25 秒で上がる（高さ 2.2）→ 0.8 秒止まる → 引っこむ。
   - 足場の上には出さない（床だけ）。
4. 13.0 秒：再生ボタンが元に戻る。板が消える。

**してほしい行動**：線を見て横へ動く・足場へ上がる。足元が光ったら離れる（上がった柱は、矢印の盾にもなる。Erupt の物が矢印を止めるなら、なお良い。止めなくてもよい）。

**ステージの決まりの直し**：無し。UnityRule の 3D の物体は、重さで落ちる物なのでそのまま（リジッドボディらしい）。出来事の間だけ止める。

**公平さ**：矢印は1本ずつ（同時は強さ 3 の最後だけ）。Erupt と矢印の予告が同じ時に始まらないように、Erupt は矢印の合間（矢印の 2.2 秒おきの、まん中）に置く。ボス戦は今のまま（物体は同時に 4つまで）。

## 2. Blender：「G・S」

**元ネタ**：`G`（つかんで動かす）と `S`（大きさを変える）。床の格子、オレンジの選択の色 `#FF9F0A`。

**出来事（16 秒）**
1. 0.0 秒：画面の左下に小さく `G` のキーの札（飾り。0.6 秒）。
2. 0.8 秒〜7.0 秒：**Conveyor（主）**＝床が流れる。
   - x −9〜+9 の床ぜんぶ。速さ 2.5 マス/秒（プレイヤーの歩きより十分おそい）。向きは最初に右、3.5 秒で左へ変わる（変わる 0.8 秒前に矢印が点滅して止まる）。
   - 予告 0.8 秒：床にオレンジの矢印が流れる。Default Cube（BlenderRule の立方体）と雑魚も運ばれる（運べないなら、立方体は動かさなくてよい）。
   - 足場の上は流れない（足場に乗れば休める）。
3. 7.5 秒：`S` のキーの札。
4. 8.0 秒〜15.0 秒：**Pop**＝大きくなる物。
   - 2.3 秒おきに 3回。1回に 2か所／2か所／3か所。場所：プレイヤーの今の場所と、足場の上のどれか1つ（低い足場かまん中の足場）。強さ 3 はもう1つ床の上。
   - 予告 1.0 秒：オレンジの小さい点線の四角（幅 0.5）が、当たる大きさ（幅 2.2）の点線へ広がる。→ 立方体・球・サル頭の代わりの丸（BlenderArt の物）が奥から大きくなって出る → 0.7 秒で消える。ring（弾をばらまく）は使わない。
5. 15.5 秒：終わり。

**してほしい行動**：前半は流れに合わせて歩く・足場で休む（流されながら雑魚を倒す）。後半は点線が広がる前に出る。足場の上も安全ではないので、動き続ける。

**ステージの決まりの直し**：BlenderRule の立方体が戻るとき（今：オレンジの枠 1.0 秒 → `Kit3D.Faller` を床のすぐ上に置く）を、**Pop の出方**（奥から大きくなる。`S` で大きくした見た目）にする。当たらないのは今のまま。見た目だけの直し。

**公平さ**：Conveyor は押すだけで当たらない。壁へ押しつけても何も起きない。Pop は同じ時に最大 3か所で、部屋の半分以上はいつも空いている。ボス戦は今のまま（立方体だけ）。

## 3. Minecraft：「夜の襲撃」

**元ネタ**：夜になると地面から出てくる敵、飛んでくる矢。土・草のブロック。

**出来事（15 秒）**
1. 0.0 秒：空が夜になる（MinecraftRule の昼と夜を、出来事の間だけ夜に固定できるなら固定。できなければ今の時計のまま）。
2. 1.0 秒〜：**Erupt（主）**＝土から出る緑の四角い物（本物の顔は描かない。緑 `#5DB85D` の柱＋暗い四角い目が2つ）。
   - 2.5 秒おきに 5回。1回に 2本／2本／3本。幅 1。高さ 2.4。
   - 場所：1本はプレイヤーの今の x。ほかは、床の x −8〜+8 を 2マスおきの枠にして、まだ使っていない枠から。
   - 予告 1.0 秒：床の土がぽろぽろはねる（茶色 `#8B5A2B` の小さい四角）＋赤い割れ目。→ 0.2 秒で上がる → 0.9 秒止まる（止まっている間、白く点滅）→ 引っこむ。
   - 強さ 3：止まった後、引っこむ時に左右へ低い FloorWave を出さない（やりすぎ）。代わりに本数だけ増やす。
3. 5.0 秒と 10.0 秒：**EdgeSweep**＝矢。
   - 左（1回目）・右（2回目）の端から。高さは 1.0（床の上。ジャンプで越える）と 3.8（低い足場の上に立つ人の高さ）の 2本を、0.5 秒ずらして。速さ 11。wave 0（まっすぐ）。
   - 予告 0.8 秒：端に矢印の印と、うすい線。矢は白い棒＋灰色の矢じり。
   - 強さ 1 は床の高さの 1本だけ。
4. 14.0 秒：終わり（空は時計に戻る）。

**してほしい行動**：足元の土がはねたら離れる。矢は跳ぶ・足場に上がる／下りる（足場にいれば床の矢は当たらないが、足場の高さの矢が後から来る）。

**ステージの決まりの直し**：無し（MinecraftRule は昼と夜だけ）。ボスの技「落ちる砂」は重さで落ちる物なので、そのまま。

**公平さ**：Erupt は床だけ（草ブロック・板・葉の足場からは出ない）。矢と Erupt の予告は、同じ 0.5 秒の中に重ねない（矢の回は Erupt を 1回休む）。ボス戦は今のまま。

## 4. QuickTime Player：「巻き戻し」

**元ネタ**：早送り `▶▶` と巻き戻し `◀◀`。動画が逆に流れる。フィルムのコマ。

**出来事（14 秒）**
1. 0.0 秒：画面のまん中の上に `▶▶ 2x` の札（1.0 秒。QuickTimeRule の札と同じ絵）。
2. 1.0 秒〜5.5 秒：**EdgeSweep（主）・行き**。左の端から右へ、フィルムのコマ（灰色の四角に白い枠。黄 `#FFD60A` は使わない＝プレイヤーの色）。
   - 3本／4本／5本を 1.1 秒おきに。高さは毎回ちがう（0.8・3.8・2.2・5.6・0.8 の順。床・低い足場・その間・まん中の足場）。速さ 8。wave 0。
   - 予告 0.8 秒：左の端に矢印＋高さの線。
   - **通ったあとに、うすい残像の線（白 20％）を残す**（戻ってくる道の印。EdgeSweep に無ければ、出来事が細い線を置く）。
3. 6.0 秒：画面が 0.3 秒止まる見た目（札が `⏸`）→ `◀◀` の札（1.0 秒）。残像の線が、**最後に通った物から順に**赤く点滅する。
4. 7.0 秒〜12.5 秒：**EdgeSweep・戻り**。右の端から左へ、**同じ高さを逆の順番で**。速さ 10（巻き戻しは少し速い）。1.0 秒おき。予告は残像の線の点滅（0.8 秒以上）。
5. 13.0 秒：札が `▶ 1x` に戻る。線が消える。

**してほしい行動**：行きで「どの高さを通ったか」を見ておく。戻りは同じ道を逆から来るので、先に安全な高さへ動く（覚えると楽になる）。

**ステージの決まりの直し**：無し（QuickTimeRule は速さの札だけ。落とす物は無い）。

**公平さ**：同じ時に画面にいるコマは 2つまで（間を 1.0 秒以上あける）。床の高さと低い足場の高さが続けて来ないように、順番を決め打ちにする。ボス戦は今のまま（札だけ）。

## 5. GitHub Desktop：「マージの衝突」

**元ネタ**：衝突の印 `<<<<<<<`・`=======`・`>>>>>>>`。`Resolve` のボタン。差分の緑とピンクの行。

**出来事（15 秒）**
1. 0.0 秒：上の帯に `Merge conflict`（飾り。1.0 秒）。背景のブランチの線（GitHubBranchLines）の2本が近づく。
2. 1.0 秒〜：**FloorWave（主）**＝左から `<<<<<<<`（青）、右から `>>>>>>>`（紫）の低い壁が走る。
   - 3回／4回／5回。3.0 秒おき。1回目は左だけ、2回目は右だけ、3回目からは**両方から同時**（まん中 x＝0 でぶつかって消える。ぶつかった所に `=======` の字が 0.4 秒）。
   - 速さ 7。高さ 0.9（ジャンプで越える）。予告 1.0 秒：出てくる側の壁の下に赤い矢印＋床にうすい赤い線。
   - 壁の絵：GitHubMergeColumn の字（`<<<<<<<`）を横に寝かせた帯。
3. 6.0 秒：**HitTarget**＝`Resolve` のボタン（青 `#5b8fd0` の角丸。字 `Resolve`）。
   - 場所：まん中の足場のすぐ上（x 0、高さ 6.2）。life 6 秒。動かない。
   - 叩く：残りの波が全部消えて、出来事が 2秒早く終わる。緑のチェックの印と `Merged` の字（0.6 秒）。
   - 叩かない（時間切れ）：最後に、両方から波がもう1回（罰は軽く）。
4. 14.0 秒：終わり。ブランチの線が元の間に戻る。

**してほしい行動**：波を跳ぶ（足場に乗っていれば当たらない＝足場を使う理由）。余裕があれば、まん中の足場へ上がって `Resolve` を叩く。

**ステージの決まりの直し**：無しでよい。合流の柱（GitHubMergeColumn）は床から天井までの柱で、上から落ちる物ではない。出来事の間だけ止める（波と柱が重なると逃げ場が無い）。

**公平さ**：まん中の足場は「取り消し線の行」（乗ると落ちる）なので、`Resolve` は左右の低い足場からのジャンプでも届く高さにする（高さ 6.2 は、まん中の足場の上からの攻撃で届く高さ。届かなければ 5.6 に下げる）。ボス戦は今のまま（柱は 15 秒おき）。

## 6. Xcode：「Build」

**元ネタ**：ビルドの進みの帯、`Build Succeeded`・`Build Failed`、行の横に出るエラーの印。

**出来事（16 秒）**
1. 0.0 秒：上のまん中の帯（XcodeStatusBar）が `Building...` になる（XcodeRule の時計は、出来事の間は止める。帯は出来事が使う）。
2. 1.0 秒〜：**HoldZone（主）**＝「ここでビルド」。
   - 場所は 3回変わる：①左の低い足場の上（x −3.5、高さ 3、幅 3）→ ②右の端の足場の下の床（x ＋7、幅 3）→ ③右の低い足場の上（x ＋3.5、高さ 3、幅 3）。
   - 1か所につき、中に **2.0 秒／2.0 秒／2.5 秒** いると 1つ完了（青い帯が左から右へ満ちる。出ると減る＝部品の決まり）。1か所の時間切れは 4.5 秒。
   - 印：青 `#6c9bd6` の点線の枠＋ハンマーの印（XcodeArt.HammerIcon）。
3. HoldZone が出ている間：**Pop**＝エラーの印（`!` の付いた丸。色はオレンジ寄りの赤。大きい面にしない）。
   - 1.8 秒おき。1回に 1か所／1か所／2か所。場所は**今の HoldZone の中か、すぐ横**（中にいる人を1回どかす）。予告 1.0 秒（点線の丸が点滅）→ 出る（幅 1.6）→ 0.5 秒で消える。ring は使わない。
   - つまり「帯が満ちるまで居たいが、印が出たら一歩どく → 戻る」。
4. 結果（14.0 秒）：
   - 2か所以上できた：帯が緑 `Build Succeeded`。**能力のクールタイムが全部戻る**＋雑魚が 1.0 秒ひるむ。
   - 1か所以下：帯が `Build Failed`。罰は無し（XcodeRule の罰と重ねない）。

**してほしい行動**：光る場所へ行って、そこに居続ける。エラーの印が足元に出たら一歩よけて、すぐ戻る。

**ステージの決まりの直し**：無し（XcodeRule は落とす物が無い）。ただし、出来事の間は XcodeRule の `Building...`（雑魚を 3体倒す）を始めない（帯が1本なので、2つの「ビルド」が重ならないように）。

**公平さ**：HoldZone の幅 3 に対して Pop は幅 1.6。中に居たまま端へ寄ればよけられる時もある。Pop は HoldZone の外の人をねらわない。ボス戦は今のまま（XcodeRule の Build）。

## 7. Steam：「実績チャレンジ」

**元ネタ**：実績の通知、トロフィー、ゲームのカプセル。黄緑 `#BEEE11`・水色 `#66C0F4`。

**出来事（15 秒）**
1. 0.0 秒：右下に通知 `Challenge: hit 3 trophies`（SteamRule の通知と同じ絵。1.5 秒）。
2. 1.0 秒〜：**Orbit ＋ HitTarget（主）**＝回るトロフィー。
   - center：部屋のまん中（x 0、高さ 3.5）。radius 3.2。3つ（120°おき）。回る速さ 50°/秒（1周 7.2 秒）。duration 12 秒。
   - 的の絵：トロフィーの印（金色ではなく水色 `#66C0F4` のふちの白い丸＋トロフィー。黄色はプレイヤーの色なので大きくしない）。当たっても痛くない。
   - 叩くたびに、右下に小さい通知（`1/3`・`2/3`）。
   - 3つ全部：`Achievement Unlocked`。SteamRule のプレイヤーの強化（与えるゲージ ×1.3・速さ ×1.15。8 秒）を入れる（今の入口を使う。同じ実績は1ステージに1回の決まりに合わせ、名前は `Trophy Hunter`）。
   - 時間切れ：何も起きない（得だけ）。
3. 的が回る輪の上を、**Orbit（当たる物）**＝`-50%` の値札（SteamArt の値札）が 1つ／2つ／2つ、逆回りで回る（速さ 40°/秒）。的を追うと、値札とすれちがう。
   - 出る時の予告 1.0 秒：輪の線（うすい水色の点線）と、値札が出る点の赤い印。
4. 13.5 秒：残った的と値札が消える。

**してほしい行動**：回ってくる的を、足場を使って叩きに行く（低い足場・まん中の足場のそばを通る）。逆回りの値札はくぐる・待つ。

**ステージの決まりの直し**：SteamRule には危ない物が無いので、無し。
（参考：ボスの技1 `SteamSaleDrop` は値札が上から落ちる。ステージの決まりではないので今回は直さないが、向きを増やすなら「半分を EdgeSweep で横から流れる値札にする」が合う。別の相談。）

**公平さ**：値札は輪の上だけを動くので、輪の外・輪のまん中はいつも安全。的は叩かなくても損をしない。ボス戦には出ない（ボスの強化の実績と重ならない）。

## 8. ミュージック：「ビートの波」

**元ネタ**：イコライザーの棒、ビート、音符。ピンク `#FB5C74`。

**出来事（14.4 秒＝24 ビート）**。時計は `MusicRule.Clock`（曲の再生位置。0.6 秒＝1ビート）に合わせる。
1. 0〜4 ビート目：前ぶれ。下の棒（MusicBeatView）が、左と右の端だけ高くはねる。床の左右の端にピンクの矢印（予告 2.4 秒。長いが、ビートを数えさせる）。
2. 4 ビート目〜：**FloorWave（主）**＝音の波。**4ビート（2.4 秒）ごとに1つ**、ビートの瞬間に端を出る。
   - 左・右・左・右…の順。4回／5回／5回。強さ 3 は、最後の1回が左右同時（まん中でぶつかって消える）。
   - 速さ 8.3（＝ 2ビートで 10マス。端からまん中まで、ちょうど 2ビート）。高さ 0.8。
   - 絵：イコライザーの棒が 3本並んだ形（MusicArt.BarColor の色。当たる物なので先頭の棒だけ赤寄りのピンク）。

## 13. まとめ：ステージの決まりを直す所

| アプリ | 今 | 直し |
|---|---|---|
| Spotify | Premium の札が上から落ちる（`SpotifyTicket`） | **Catch：左右の端から横に流れる**（高さ 3.5・波打つ） |
| Blender | 立方体が戻る時、床のすぐ上に置く（`Kit3D.Faller`） | **Pop の出方**（奥から大きくなる。見た目だけ） |
| Unity | 3D の物体が落ちる（`Kit3DFaller`） | そのまま（重さで落ちるのが自然）。出来事の間は止める |
| GitHub Desktop | 合流の柱（床から天井） | そのまま。出来事の間は止める |
| Xcode | Build の時計 | そのまま。出来事の間は `Building...` を始めない |
| Photoshop | 目が閉じる | そのまま。出来事の間は Platforms を閉じない |
| ほか 6つ | 危ない物を落とさない | 無し |

## 14. 実装の人へ：確かめてほしい所

- **部品に無いかもしれない物**：QuickTime の「通った道の残像」、Spotify の「跳ね返りの道の線」、Photoshop の「SafeSpot の外が市松になる」、GitHub・ミュージックの「両方からの FloorWave がまん中でぶつかって消える」。無ければ、出来事の側で細い線・板を置く。
- **HitTarget の高さ**：GitHub の `Resolve`（高さ 6.2）・Figma のピン（高さ 6）は、足場の上からの近接が届く高さか、ゲームの中で確かめる。届かなければ 0.6 下げる。
- **出来事の間にステージの決まりを止める入口**：今あるか分からない（`ctx.CanSpawnHazard` は出来事の間 false になる？）。無ければ、Unity・GitHub・Xcode・Photoshop だけ、出来事が始まる時と終わる時に決まりへ知らせる。
- **ミュージック**：`MusicRule.Clock` は `_t0` が要る（MusicRule の中の値）。出来事から読めるように、今のビートの番号を返す入口があるとよい。
- 数・秒は全部【仮】。遊んでから直す。
