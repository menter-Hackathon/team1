## 1. 共通で足す仕組み（技より先に作る）

### 1-1. 技の作り方
- 新しい動きは、技ごとに専用のクラスを1つ足す（`LockOnStrike` と同じ形。`AttackRunner` が `AttackData` から作り、出したあとは自分で進む）。
- 数値は `AttackData` に持たせる。形態ごとの違いは `_P1`／`_P2` のアセットに分ける（Chrome と同じ）。
- `AttackKind` は 6 から順に足す（値は変えない・欠番にしない、の決まりどおり）。

### 1-2. 場に残る物の片づけ【仮】
今は、50%では弾だけを消し、100%では出ている攻撃をすべて消す。新しい技は「場に残る物」が多いので、次の決まりを足す。

| 残る物 | 50%（形態変化） | 100%（ウイルス本体の追い出し） | 技の途中でボスが止められたとき |
|---|---|---|---|
| Spotlight の検索バー・狙いの線 | 消す | 消す | 消す（撃たない） |
| タグ（プレイヤーの頭の色の丸）・タグ付きのトゲ・スマートフォルダ | 消す | 消す | 消す |
| レーザーツールで消えた足場 | すぐ戻す | すぐ戻す | 戻す。近づいたボスはそのまま |
| 再生ヘッド・マーカー・タイムラインの帯 | 消す | 消す | 消す |
| スローの場・ボスの倍速 | 消す | 消す | 消す |
| 文字化けの床（rm -rf） | すぐ戻す | すぐ戻す | 戻す |
| Permission Denied の封印 | 解く | 解く | 解く |
| 分身（ゴーストプロセス）とその弾 | 消す | 消す | 消す |
| 降ってくる文字列 | 消す | 消す | 消す |

- 理由：100%のあと、ウイルス本体は床と足場を走って逃げる。床と足場が欠けたままだと、とどめが刺せない。
- やり直し（リトライ）は、シーンを読み込み直すので、何も残らない。
- 作り方の目安：技のクラスに「片づける」入口を1つそろえる。ボスが 50%・100% のときに、場にいる全部へ呼ぶ。

### 1-3. 「場に残る技」は重ねない【仮】
- 対象：レーザーツール・スピードデュレーション・rm -rf・chmod・fork。
- 決まり
  - このどれかが場に残っている間、ボスは**「場に残る技」を選ばない**（次の候補へ飛ばす）。自分自身もふくむ（床が文字化けの間に、もう一度 rm -rf は出さない）。
  - **文字化けの床（rm -rf）が残っている間は、文字列の雨も選ばない。** 雨は足場をすり抜けるので、床が使えないと逃げ場がなくなる。
- 理由：第2形態は技をランダムに選ぶ。「ジャンプ封印 ＋ 床が消える」「分身の弾 ＋ 床が消える」「床が消える ＋ 文字列の雨」は、見ても避けられない。
- 作り方の目安：`BossController` の技えらびに「今は使えない技は飛ばす」を1つ足す（小さい変更）。技が全部使えないときは、待ち時間をもう1回おく。

### 1-4. 画面の中の文字の出し方【仮】
- 検索バー・コマンドの行・速度のウィンドウは、OnGUI で描く（ボス部屋はカメラが固定なので、画面の決まった位置でよい）。
- 英字は Press Start 2P、日本語は DotGothic16。
- プレイヤーの頭の上の「Permission Denied」だけは、プレイヤーの位置を画面の位置に直して出す。
- OnGUI は自動の撮影に映らない（ビルドして撮る方法がある）。確かめるときに注意。

### 1-5. Finder と Premiere Pro のボスの設定を新しく作る
- 今あるのは `Boss_Chrome`・`Boss_VSCode`・`Boss_Terminal` だけ。Finder と Premiere Pro は代用ボス（対応アプリの表に無いアプリ）なので、専用の設定（`Boss_Finder`・`Boss_PremierePro`）を足す。
- 入れ方は、Terminal と同じにする（`FinalBossBuilder` のやり方）：対応アプリの表に行を足し、プレハブは今あるボスのプレハブ（浮くので Chrome のもの）、着ているウィンドウはアプリのアイコンから作り、ステージは代用ボスと同じ1画面。
- 【要確認】表に行を足すと「代用ボス」ではなくなる。そのとき、見た目（アイコンのウィンドウ）とステージの色（アイコンの色から作る）が今のまま出るかを、コードで見る。出ないなら、Terminal のように色のアセット（`Theme_Finder`・`Theme_PremierePro`）を作る。アプリ専用の能力（`Skill_App_〇〇`）が今までどおり渡ることも見る。
- 設定は 2-0・3-0・4-0 の表のとおり。
- 技が間に合わなかったら、その枠には今の複製の技（Chrome・VS Code）を残す。ボスとしては遊べる状態を保つ。

## 2. Finder

### 2-0. ボスの設定【仮】

| 項目 | 値 |
|---|---|
| 動き | 浮いて、左・中央・右（x＝-7・0・7）を毎秒3マスで移動（Chrome と同じ） |
| 出る位置 | 中央。下の端は床から 2.5マス（Chrome と同じ） |
| ゲージ | 100 |
| 待ち時間 | 第1形態 1.2秒、第2形態 0.8秒。2回攻撃するごとに移動 |
| 第1形態の技 | Spotlight・サーチ（P1）⇄ スマートフォルダマグネット（P1）。交互 |
| 第2形態の技 | Spotlight・サーチ（P2）、スマートフォルダマグネット（P2）、ウィンドウ出現（Chrome のポップアップ出現 P2 の複製。色だけ Finder）【仮】 |
| 手に入る能力 | zip圧縮（`Skill_App_Finder`） |

- 第2形態に Chrome の技の複製を1つ混ぜる理由：チームの案の技は2つ。2つだと第2形態も交互になり、単調になる。作る量はほぼ 0（今の Finder の技は Chrome か VS Code の複製。Chrome のポップアップ出現のアセットを指すだけ）。

### 2-1. Spotlight・サーチ（ボスの技）
- 【チームの案】画面上部に検索バーが出て、プレイヤーの名前を打ち始める。検索が終わると、どこにいてもプレイヤーの現在地を撃ち抜く、サーチライト型のレーザー。

**流れ（第1形態。合わせて 2.3秒）**
1. **検索バーが出る**（0.3秒）：画面の上のほう、中央。
2. **名前を打つ**（1.2秒）：`PLAYER` を1文字 0.2秒で打つ。この間、検索バーからプレイヤーへ、細い水色の線（狙い）が付いて回る。プレイヤーの足元には、水色の薄い円。
3. **検索完了＝狙いの固定**（0.5秒）：検索バーが白く光り、下に結果の行（プレイヤーの小さい絵）が1行出る。線と円が**赤に変わって、その場に止まる**。もうプレイヤーを追わない。
4. **発射**（0.3秒）：検索バーから、止まった円へ、サーチライトの光の帯。
5. **終わり**：光が消え、検索バーが上へ引っ込む（0.2秒）。

**避け方**
- 赤に変わったら、その場から動く。0.5秒あれば 3.5マス動ける。必要なのは約1.2マス。
- 打っている間（水色）は動いても意味がない。「赤になったら動く」を覚える技。

**当たったとき・数値【仮】**

| 項目 | 値 |
|---|---|
| 光の帯の判定 | 検索バーの下の端から円の中心まで。太さ 0.8マス |
| 円の判定 | 直径 1.6マス（足元。床の上） |
| 判定の時間 | 0.15秒（見た目は 0.3秒） |
| 第2形態 | 3連続。1発目のあと、「水色で追う 0.4秒 → 赤で固定 0.5秒 → 発射 0.3秒」をあと2回。名前は打ち直さず、結果の行が1行ずつ増える |

**見た目【仮】**（Mac の Spotlight 検索）
- 検索バー：横10×縦1.2マス。角の丸い濃い灰色 `#2B2B2E`（少し透ける）、ふち `#5A5A5E`。左に虫めがね `#A0A0A5`（12ドット）。文字は白 `#FFFFFF`、Press Start 2P。文字の後ろで、カーソルの縦棒が点滅。
- 追っている線・円：水色 `#5AC8FA`。線の太さ 1ドット、点線。
- 固定した線・円：赤 `#FF453A`。線の太さ 2ドット、実線。円は 0.1秒ごとに点滅。
- 光の帯：外側 `#FFF4B0`（うすい黄色、太さ 14ドット）、芯 `#FFFFFF`（6ドット）。当たった床に白い光 0.15秒。
- 文字列：`PLAYER`（0章の表）。

**割り切り**
- 斜めの判定は、回した箱1つ（`Physics2D.OverlapBox` に角度）。`LockOnStrike` のレーザーの絵の出し方を使い回す。
- 足場は貫通する（足場の下に隠れても当たる）。

**OK の条件**
- 赤に変わった瞬間に立ち止まると当たる。赤に変わってから歩くと、3回中3回とも当たらない。
- 部屋の左端・右端・足場の上の、どこにいても線が届く。
- 打っている途中でゲージを50%にすると、検索バーと線が消え、撃たれない。

### 2-2. スマートフォルダマグネット（ボスの技）
- 【チームの案】「タグ付け」の攻撃で、プレイヤーに赤や青のアイコンを付ける。そのあとボスがスマートフォルダを開くと、同じ色のタグが付いたオブジェクトやトゲが、一斉にプレイヤーへ吸い寄せられる。

**流れ（第1形態。合わせて 約3.8秒。色は赤だけ）**
1. **構え**（0.8秒）：ボスの上に、赤い丸（タグ）が浮かぶ。同時に、部屋の空中の3か所に、トゲ付きファイルの薄い枠（出る場所の予告）。
2. **タグ付け**（約1.0秒）：ボスが赤いタグの弾を3発、扇状に撃つ。同時に、枠の場所にトゲ付きファイルが3つ現れる（赤い丸付き。まだ動かない・当たらない）。
   - タグの弾は**ダメージなし**。当たると、プレイヤーの頭の上に赤い丸が付く。
3. **スマートフォルダが開く**（0.8秒）：ボスの上に、歯車の付いたフォルダが開く。
   - タグが付いていれば：赤いトゲがふるえ、プレイヤーへ赤い点線が伸びる。最後の 0.3秒で点線が止まる（狙いの固定）。
   - タグが付いていなければ：トゲは「？」のように少しゆれるだけ。
4. **吸い寄せ**（約0.8秒）：タグが付いていれば、トゲ3つが、固定した位置へまっすぐ飛ぶ（毎秒10マス）。壁・床に当たると消える。
5. **終わり**：フォルダが閉じ、タグとトゲが消える。タグが付いていなかったときは、トゲは飛ばずに消える（ボスのすきになる）。

**避け方**
- 1つ目：タグの弾を避ける（ジャンプか、足場に乗る）。付かなければ、何も飛んでこない。
- 2つ目：付いてしまったら、点線が止まったあとに動く。トゲはまっすぐ飛び、曲がらない。

**当たったとき・数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| タグの弾 | 赤 3発、扇 30°、毎秒6マス、直径 0.5、ダメージなし | 赤 3発 → 0.6秒後に青 3発 |
| タグ | 1色。技が終わるまで付く | あとから当たった色に上書き（1色だけ持つ） |
| トゲ付きファイル | 赤 3つ。0.8×0.8マス | 赤 3つ＋青 3つ |
| 出る場所 | プレイヤーから 3マス以上離れた空中（高さ 2.5〜6）。たがいに 3マス以上離す | 同じ |
| スマートフォルダ | 赤を1回 | 赤 → 0.8秒後に青。付いている色のトゲだけが飛ぶ |
| 飛んだトゲ | 毎秒10マス、まっすぐ。当たるとライフ -1 | 同じ |

**見た目【仮】**（Finder のタグと、スマートフォルダ）
- タグの色：赤 `#FF453A`、青 `#0A84FF`（macOS のタグの色）。タグの弾は丸（9ドット）に白いふち1ドット。
- プレイヤーの頭の上のタグ：丸（6ドット）。付いた瞬間に、大きい所から縮んで付く。
- トゲ付きファイル：白い書類 `#F2F2F7`（14ドット、右上が折れた形）のまわりに、灰色 `#8E8E93` のトゲ。右下にタグの丸（5ドット）。
- スマートフォルダ：Finder の青いフォルダ `#5AB0F0`（影 `#2F7FC4`）に、白い歯車。横2×縦1.6マス。開くときに、タグの色の光が中から出る。
- 文字は出さない。

**割り切り**
- 「オブジェクトやトゲ」は、トゲ付きファイルの1種類だけ。
- 吸い寄せは追いかけない（固定した位置へ直進）。
- トゲの出る場所は、ポップアップ出現の「離れた空中のランダムな位置」の選び方を使い回す。
- それでも量が多い（タグの状態・2色・フォルダの演出）。時間が足りなければ、第2形態も赤1色にする。

**OK の条件**
- タグの弾を3発とも避けると、フォルダが開いてもトゲが飛ばない。
- タグが付くと、同じ色のトゲだけが飛ぶ（第2形態で青が付いていれば、赤は動かない）。
- 点線が止まってから歩くと、トゲが横を通りすぎる。
- 技の途中で 50%・100% にすると、タグ・トゲ・フォルダが全部消える。

### 2-3. zip圧縮（プレイヤーの能力）
- 【チームの案】目の前の雑魚や敵の弾を、1つの zip ファイルにする。圧縮したあと、もう一度使うと、ほかの敵にぶつけてダメージを与える。散弾のように使える。

**使い方【仮】**
1. **1回目（圧縮）**：正面の範囲（横3×縦2マス）にいる雑魚と敵の弾を吸いこみ、zip にする。
   - 雑魚はその場で倒れる（倒した数に入る）。弾は消える。
   - zip はプレイヤーの後ろに浮いて付いてくる。
   - 範囲に何もなくても、空の zip ができる（必ず次へ進める）。
2. **2回目（発射）**：同じキーで、zip を正面へ散弾として撃つ。
   - 弾の数＝ 3 ＋ 吸いこんだ数（最大 8）。
   - 撃ったら、ここからクールタイム。
- 持っている間：時間切れはない。ダメージを受けても落とさない。枠を入れ替える・捨てると、zip は消える。ステージが変わると消える。
- 吸いこめる物：雑魚、敵の弾（タグの弾・分身の弾・降ってくる文字列もふくむ）、分身（ゴーストプロセス）。
- 吸いこめない物：ボス、ウイルス本体、落下物、柱や床の判定、光の帯、トゲ付きファイル。

**数値【仮】**

| 項目 | 値 |
|---|---|
| 圧縮の範囲 | 正面。プレイヤーの体の前の端から 横3×縦2マス（足元から） |
| 圧縮の時間 | 0.15秒（この間に入った物も吸う） |
| 散弾 | 3〜8発、扇 40°、毎秒12マス、0.6秒で消える（届く距離 約7マス）、直径 0.3 |
| 1発あたり | 雑魚にダメージ 1、ボスのゲージ +2 |
| ボスのゲージ（1回） | 空で 6、最大 16（5つ以上吸ったとき） |
| クールタイム | 3.5秒（発射してから） |

- 強さの考え方：ゲージ÷秒は 1.7（空）〜 4.6（最大）。今の能力は 3〜4（ブレークポイント 12÷3秒、ギャラリービュー 27÷8秒）。空では弱く、弾を吸えば強い。「敵の弾を消せる」守りの分、空のときを弱くしてある。
- ボス戦では雑魚が出ないので、吸うのはボスの弾。弾を出さない技の間は、空で撃つことになる（それでも +6）。

**見た目【仮】**（Finder のドラッグ選択と、zip ファイル）
- 圧縮：青い選択の四角（中 `#0A84FF` を薄く、ふち `#0A84FF` 1ドット）が正面にパッと出て、中の物が縮みながら1点に集まる。
- zip：白い書類 `#F2F2F7` に、縦のファスナー（灰色 `#8E8E93`）。大きさは3段階：空（10ドット）・1〜2個（13ドット）・3個以上（16ドット）。数字は出さない。
- 発射：zip がはじけ、小さい書類（5ドット）が扇状に飛ぶ。
- HUD の枠：zip を持っている間、枠のふちを Finder の青で光らせる（「もう一度押せる」の合図）。
- 能力のアイコン：ファスナー付きの書類。
- カードの説明とタグ（`SkillTexts`）：「目の前の敵と弾をzipにまとめ、もう一度押すと散弾にして撃つ。」「圧縮」「2回押し」。

**割り切り**
- 「2回押し」は、能力の仕組みに「構え中（クールタイムを始めない）」の状態を1つ足す必要がある【要確認】。ギャラリービューの「使えないときはクールタイムを始めない」と同じ所に入れる。
- 吸いこむ演出は、対象を消して、同じ絵を1点へ縮めるだけ。

**OK の条件**
- 何もない所で2回押すと、3発出る。ボスに全部当てるとゲージ +6。
- 雑魚2体を範囲に入れて押すと、2体とも倒れ（ボスが出るまでのゲージも進む）、次に押すと5発出る。
- ボスの弾を吸うと弾が消え、ライフが減らない。
- zip を持ったまま枠を入れ替えても、エラーが出ない。
- 発射の直後はクールタイム中で使えない。圧縮しただけではクールタイムが始まらない。

### 3-1. エフェクトアイコンの雨（ボスの技）
- 【チームの案】ステージ上部からエフェクトアイコンを降らす。

**流れ（第1形態。合わせて 約3.5秒）**
1. **並べる**（1.5秒）：画面の上の端に、アイコンを 0.3秒ごとに1つずつ、左から並べる（5つ、3.5マス間隔）。真下の床に影。
2. **待つ**（0.5秒）
3. **落とす**（約1.5秒）：左から 0.25秒おきに、真下へ落とす（毎秒10マス）。
4. **終わり**：床・足場に着いたら消える。

**避け方**：影と影の間に立つ。アイコンの間は 2.5マス空いている（体は 0.7マス）。

**数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| 数・間隔 | 5つ・3.5マス | 6つ・3マス |
| 着地 | 消える | 炎のアイコンは、着地した所に火（横1.5×縦0.8マス、1.5秒残る）。雷は消えるだけ |
| 炎と雷 | 交互に並べる | 同じ |

**見た目【仮】**：上の「エフェクトアイコンの共通の絵」。Premiere の「エフェクト」パネルから、タイムラインへ落とす動き。

**割り切り**
- Chrome の「タブ増殖」（落下物を上の端に並べて落とす）と同じ部品。絵と数値を変えるだけ。
- 第2形態の「着地した所に火」は、落下物に追撃を出す所がなければ、やめる【要確認】。

**OK の条件**：5つが左から順に落ち、影の間に立つと当たらない。足場の上に落ちたら足場で消える。

### 3-2. 再生ヘッドレーザー（ボスの技）
- 【チームの案】画面の左端から右端へ、青い「再生ヘッド」（縦の線）が一定の速さで走る。タイムラインに置かれた「エフェクトアイコン」（炎や雷のマーカー）に再生ヘッドが触れた瞬間、その場所で爆発や落雷が起きる。

**流れ（第1形態。合わせて 約4.8秒）**
1. **タイムラインが出る**（0.3秒）：画面の上の端に、目盛りの付いた細い帯。
2. **マーカーを置く**（0.8秒）：アイコンを3つ置く。置いた瞬間から、起きる範囲をうすく見せる。
   - 炎：アイコンを中心に、うすいオレンジの円（直径3マス）。
   - 雷：アイコンの位置に、うすい黄色の縦の帯（幅1.5マス、床から天井まで）。
3. **再生ヘッドが走る**（3.3秒）：左端から右端へ、毎秒6マス。
4. **触れたら発動**：マーカーが白く光り、0.25秒後に爆発・落雷（判定 0.3秒）。
5. **終わり**：再生ヘッドが右端に着いたら、帯ごと消える。

**避け方**
- 再生ヘッドの線には、当たらない（0章の表）。
- 線が近づいてきたマーカーの、うすい範囲から出る。発動は順番なので、発動が終わった場所へ戻ってよい。

**数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| マーカーの数 | 3つ（炎2・雷1） | 5つ（炎3・雷2） |
| 置く場所 | 1つ目はプレイヤーの x の ±1マス以内。残りは、たがいに 3マス以上離す。高さは床の上 1マス（雷）か、床・足場の上 1.5マス（炎） | 同じ |
| 再生ヘッド | 左 → 右を1回 | 左 → 右、右 → 左の往復（帰りも、同じマーカーがもう一度発動する） |
| 爆発 | 円、直径 3マス | 同じ |
| 落雷 | 幅 1.5マス、床から天井まで | 同じ |

- 第2形態で安全な幅：範囲を全部足しても、部屋の20マスのうち 12マスまで。すき間が必ず残るように、置く場所を選ぶ。

**見た目【仮】**（Premiere Pro のタイムライン）
- 帯：横は部屋いっぱい、縦 0.5マス。地 `#232323`、目盛り `#8A8A8A`（1マスごとに短い線、5マスごとに長い線）。
- 再生ヘッド：青 `#2D8CEB` の縦の線（太さ 2ドット、床から帯まで）。上に、同じ青の五角形のつまみ（10ドット）。線の後ろに、うすい青の尾（4ドット）。
- マーカー：上の「共通の絵」。置いた所から帯へ、細い線（1ドット、アイコンの色）を伸ばす（「タイムラインのここで起きる」の印）。
- 爆発：オレンジの円が広がる。落雷：黄色のぎざぎざの柱に白い芯。

**割り切り**
- 爆発と落雷は、今ある「指定位置の判定」（円・柱）をそのまま出す。新しく作るのは、線を動かして、マーカーに着いたら判定を出す係だけ。
- 再生ヘッドは見た目だけ（当たり判定なし）。

**OK の条件**
- 線がマーカーに重なった 0.25秒後に、そのマーカーだけが発動する。
- 線に触れてもライフが減らない。
- うすい範囲の外にいれば、3つとも当たらない。
- 第2形態で、帰りの線でももう一度発動する。

### 3-3. レーザーツール（ボスの技。Razor＝カミソリ）
- 【チームの案】ボスが巨大なカミソリ（レーザーツール）で、画面を縦にズバッと切る。切られた空間（背景や足場）が削除されて、リップル削除（後ろの地形が前に詰まる）が起きる。足場が急に消えたり、ボスとの距離が急に縮まる。

**流れ（合わせて 約1.7秒。足場は 4秒後に戻る）**
1. **予告**（0.9秒）：画面の上に、カミソリの刃のアイコンが2つ現れ、その真下に白い点線（切る線）が床まで伸びる。2本の間（切られる区間）は、うすい紫の斜線。
2. **切る**（0.15秒）：刃が上から下へ落ちる。2本の線に判定。
3. **削除と詰め**（0.3秒）：区間が黒くなって消え、左右からつぶれる動き（画面が一瞬、横にゆれる）。
   - 区間の中に中心がある足場は、消える。
   - ボスが、区間の幅（4マス）だけ、プレイヤーのほうへ一気に寄る。
4. **終わり**：ボスは次の技へ。消えた足場は、4秒後に 1秒点滅して戻る。

**避け方**
- 点線の上に立たない（線の判定は幅 0.6マス）。
- 区間の中の足場に乗っていたら、消える前に下りる（消えると床へ落ちるだけで、ダメージはない）。
- ボスが寄ってくるので、区間のむこう側で待たない。ボスはプレイヤーから 2.5マスより近くには寄らない。

**数値【仮】**

| 項目 | 値 |
|---|---|
| 区間 | 幅 4マス。ボスとプレイヤーの x の真ん中を中心にする。部屋の中に収める |
| 切る線の判定 | 幅 0.6マス、床から天井まで、0.15秒 |
| 線の位置の決まり | 予告を出す瞬間、線はプレイヤーの x から 1マス以上離す（離れるまで区間をずらす） |
| ボスの寄り | 4マス。プレイヤーの x から 2.5マスの所で止まる。部屋の外へは出ない |
| 消える足場 | 4秒（最後の 1秒は点滅して戻る予告） |
| 第2形態だけで出す | 線を3本にする案は、やらない（まず1種類で作る） |

- 寄ったあとのボスは、次の移動のときに、いつもの3か所へ戻る。
- 「場に残る技」（1-3）。足場が消えている間、スピードデュレーションは選ばない。

**見た目【仮】**（Premiere Pro のレーザーツールと、リップル削除）
- 刃：カミソリの刃の形（横 1.2×縦 0.8マス）。銀 `#D0D0D8`、影 `#8A8A94`、真ん中に穴。
- 切る線：白 `#FFFFFF` の点線（太さ 2ドット）。切る瞬間に、実線の白い光（太さ 6ドット）が上から下へ走る。
- 区間：うすい紫 `#9999FF`（3割）の斜線。削除のとき黒 `#000000` になり、左右から閉じる。
- 消えた足場の跡：点線の枠だけを残す（戻る場所が分かるように）。

**割り切り**
- 本当には地形を詰めない。「足場を消す」と「ボスが寄る」の2つで、詰まったように見せる。
- 床・壁・背景は動かさない。つぶれる動きは、区間の上に黒い帯を閉じる絵と、画面のゆれだけ。
- 足場を消す・点滅して戻すのは、今ある `BlinkingPlatform` が使えるか見る【要確認】。

**OK の条件**
- 予告の間に線から離れると、当たらない。
- 区間の中の足場が消え、4秒後に戻る。足場に乗ったまま消えても、床に落ちるだけ。
- ボスが寄ったあと、プレイヤーと重ならない（2.5マス空く）。
- 足場が消えている間に 50%・100% にすると、足場がすぐ戻る。

### 3-4. スピードデュレーション（ボスの技）
- 【チームの案】画面に「速度・デュレーション」のウィンドウが出て、プレイヤーの周囲だけ時間が 0.5倍速にされたり、逆にボスの動きだけ3倍になったりする。

**流れ（合わせて 約1.2秒。効果は 4〜5秒残る）**
1. **ウィンドウが出る**（0.8秒）：画面の上のほうに、「速度・デュレーション」の小さいウィンドウ。中の数字が 100 % から、50 %（スロー）か 300 %（倍速）へ回る。
   - スローのとき：プレイヤーの今いる場所に、うすい紫の円の枠（スローの場の予告）。
   - 倍速のとき：ボスのまわりに、早送りの印（▶▶）。
2. **効果が始まる**
   - **スローの場**：予告の円が、その場所に固定されて残る（4秒）。中にいる間、プレイヤーの横の速さが 0.5倍。出れば元に戻る。
   - **ボスの倍速**（5秒）：ボスの移動の速さが 3倍（毎秒3 → 9マス）、攻撃のあとの待ち時間が半分（0.8 → 0.4秒）。
3. **終わり**：ウィンドウは 0.4秒で閉じ、ボスはすぐ次の技へ。効果は時間で切れる。

**避け方**
- スローの場：予告の 0.8秒の間に円から出れば、遅くならない。入ってしまっても、歩けば 1秒以内に出られる。ジャンプは遅くならない。
- ボスの倍速：予告と弾の速さは変わらない。技の間が短くなるだけなので、技を見てから避けるのは同じ。

**数値【仮】**

| 項目 | 値 |
|---|---|
| スローの場 | 半径 3マスの円。出た場所から動かない。4秒 |
| スローの中 | プレイヤーの横の速さ 0.5倍。ジャンプ・落ちる速さ・攻撃はそのまま |
| ボスの倍速 | 移動 3倍、待ち時間 0.5倍。5秒。予告・弾の速さ・判定は変えない |
| 出し方 | 1回目はスローの場、2回目はボスの倍速、と交互 |
| この技のダメージ | なし |

- 「場に残る技」（1-3）。効果が残っている間は、レーザーツールを選ばない。

**見た目【仮】**（Premiere Pro の「クリップ速度・デュレーション」）
- ウィンドウ：横5×縦2.2マス。地 `#232323`、タイトルバー `#3A3A3A`、ふち `#5A5A5E`。
- 文字列：タイトル `速度・デュレーション`（DotGothic16）、中に `速度： 50 %` か `速度： 300 %`（数字だけ青 `#2D8CEB`）。
- スローの場：紫 `#9999FF`（2割）の円。ふちは点線で、ゆっくり逆回り。中に、小さい時計の印がゆっくり回る。中のプレイヤーに、紫の残像を1枚。
- ボスの倍速：ボスの後ろに、赤っぽい残像を2枚。頭の上に ▶▶（黄色 `#FFD60A`、8ドット）。

**割り切り**
- ゲーム全体の時間（`Time.timeScale`）は使わない。一時停止と画面の切り替えで、もう使っているため。
- プレイヤーの移動に、速さの倍率を1つ足すだけ【要確認】。「中の弾も遅くなる」はやらない。
- 3倍にするのは、ボスの設定の2つの値（移動の速さ・待ち時間）を、一時的に掛け算するだけ。

**OK の条件**
- 円の中では歩くのが半分の速さになり、出た瞬間に戻る。ジャンプの高さは同じ。
- 倍速の間、ボスの移動が速くなり、技の間が短くなる。予告の長さは変わらない。
- 50%・100%・時間切れで、どちらの効果も消え、プレイヤーの速さが元に戻る（戻し忘れがない）。

### 3-5. エフェクトアイコン投げ（プレイヤーの能力）
- 【チームの案】ランダムなエフェクトアイコンを投げる。

**使い方【仮】**
- 押すと、正面の斜め上（45°）へ、アイコンを1つ投げる（放物線）。体の中ほどから。
- 床・壁・相手に当たると、そのアイコンの効果が出る。
- どのアイコンかはランダム（3種類、同じ確率）。**次に投げるアイコンを、HUD の枠に出す**（投げる前に分かる）。

**数値【仮】**

| アイコン | 効果 | ボスのゲージ | 雑魚 |
|---|---|---|---|
| 共通（直撃） | 速さ 12、重力 18、大きさ 0.6 | +2 | 1 |
| 炎 | 当たった所で爆発。円、直径 3.5マス | +8 | 3 |
| 雷 | 当たった所の x に落雷。幅 1.5マス、床から高さ 12マス | +8 | 3 |
| ディゾルブ | 当たった所に紫のもや。横3×縦3マス、1.5秒残る、0.5秒ごとに当たり直す | +3 ×3回 | 1 ×3回 |

- クールタイム：3秒。
- 強さの考え方：1回で +10（炎・雷）か +11（ディゾルブ）。平均 約10÷3秒＝毎秒 3.4。ボム（+12÷3秒）と同じくらい。
- 使い分け：雷は高い所のボスに届く。炎は雑魚のかたまりに強い。ディゾルブは動かないボスに強い。

**見た目【仮】**：3-0 の「共通の絵」。投げるアイコンは 12ドットに縮める。能力のアイコンは、炎のアイコン。
- カードの説明とタグ：「エフェクトのアイコンを投げる。投げるたびに、次のエフェクトが変わる。」「投げる」「ランダム」。

**割り切り**
- 3種類とも、今あるボムの作り（弾 ＋ 当たった所の追撃）で表せる。攻撃データを3つ作り、使うたびに1つ選ぶ所だけを足す。
- HUD に次のアイコンを出すのが手間なら、手に持つ絵（プレイヤーの前に小さく浮かべる）で代える。

**OK の条件**
- 続けて10回投げると、3種類とも出る。HUD に出ていたアイコンと、投げたアイコンが同じ。
- Chrome（浮いている）と VS Code（床に立つ）の両方に、3種類ともゲージが入る。

## 4. Terminal（ラスボス）

### 4-0. ボスの設定【仮】

| 項目 | 値 |
|---|---|
| 動き | 床に立ち、瞬間移動で部屋の反対側へ（今のまま。VS Code と同じ） |
| ゲージ | 今の合計のまま（21章では 160）。前半と後半で半分ずつ |
| 待ち時間 | 第1形態 1.2秒、第2形態 0.5秒（今のまま）。2回攻撃するごとに移動 |
| 第1形態の技（再起動の前） | rm -rf（P1）、chmod（P1）、エラー弾（今ある VS Code の複製 P1） |
| 形態変化 | sudo reboot（4-4）。Terminal だけ、演出が 3.5秒 |
| 第2形態の技（カーネル・パニック） | 文字列の雨、fork、rm -rf（P2）、chmod（P2）、エラー弾（P2） |
| 手に入る能力 | なし（今のまま） |

- 今入っているほかの複製の技（ブレークポイント・赤い波線・ポップアップなど）は、新しい技が入った分だけ外す。技が間に合わなければ残す。
- ゲージの 160 は、`Boss_Terminal`（100 と入っている）ではなく、対応アプリの表の「ラスボス」の欄の、強さの範囲の最大側で決まる（ラスボスは強さがいつも最大）。変えるならそこ。

**コマンドの行（3つの技で共通の予告）【仮】**
- 画面の上のほう、中央に、ターミナルの1行（横14×縦1マス。地 `#0C0C0C`、ふち `#33FF66` 1ドット）。
- ボスが `$ ` のあとにコマンドを1文字ずつ打つ（1文字 0.05秒）。文字は緑 `#33FF66`、Press Start 2P。後ろに四角いカーソル。
- 打ち終わると行が白く光り、技が始まる。技が終わると行は消える。
- 文字は雰囲気。**どの技かは、同時に出る見た目の予告で分かるようにする**（床が赤く光る・鎖の帯が下りてくる・分身の枠が出る。chmod の所は 2026-11-18 まさぴ〜の指示で変更）。

### 4-1. sudo rm -rf /floor（ボスの技）
- 【チームの案】ボスがコマンドを打ちこむと、ステージの足場ブロックが、左から順番に文字列へ分解されて消える。

**流れ（第1形態。技は 約2.6秒。床は 5.5秒で戻る）**
- 床を、4マスずつ5つの区画に分けて考える（左から 1〜5）。
1. **コマンドを打つ**（1.0秒）：`$ sudo rm -rf /floor`。打ち始めて 0.2秒で、区画1が赤く点滅を始める。
2. **左から順に消える**：区画ごとに「赤く点滅 0.8秒 → 文字にくずれる 0.3秒 → 文字化けの床」。区画1は 1.3秒、区画2は 1.9秒、区画3は 2.5秒で文字化けになる（0.6秒ずつずれる）。
3. **ボスは次の技へ**（2.6秒から）。文字化けの床は残る。
4. **戻る**（5.5秒）：白く 0.5秒点滅して、全部いっしょに元の床に戻る。

**避け方**
- 赤く点滅した区画から出る。点滅は左から来るので、右へ歩くか、浮いた足場に乗る。
- 浮いた足場（フォルダ）は消えない。文字化けの床の真上の足場も安全。

**当たったとき・数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| 消える区画 | 左から3つ（x＝-10〜2） | 4つ。左からか右からかはランダム（点滅が始まる側で分かる） |
| 文字化けの床の判定 | 区画の幅 × 床から高さ 1.2マス。触れている間、ライフ -1（無敵が切れたら、もう一度） | 同じ |
| 残る時間 | 最後の区画が消えてから 3秒 | 同じ |
| くずれている 0.3秒 | まだ当たらない | 同じ |

- ボスは文字化けの床の上にいても、何も起きない（root なので）。
- 「場に残る技」（1-3）。床が戻るまで、chmod・fork・文字列の雨・rm -rf 自身は選ばない。床が戻るまでに出るのは、エラー弾だけ。

**見た目【仮】**（ターミナルで、ファイルが消されていく様子）
- 点滅：床の上の線（前半は緑 `#33FF66`、後半は灰色 `#C8C8C8`）が、赤 `#FF453A` と交互に点滅。区画の上に、うすい赤の帯（高さ 1.2マス。文字化けになる範囲）も一緒に点滅させる。
- くずれる：床のドットが、緑の英数字（`0 1 / # $ rm` など。6ドットの字）になって、上へばらばらに飛んで消える。
- 文字化けの床：床の絵を黒 `#000000` でかくし、その上に、赤 `#FF453A` と白 `#FFFFFF` の小さい文字（`#` `?` `%` `▒`）が、0.1秒ごとに入れ替わる帯（高さ 1.2マス）。「触ると危ない」と分かる色にする。
- 戻る：白く光り、文字が下へ集まって床になる。

**割り切り**
- 床の当たり判定は消さない。穴をあけない（0章の表）。プレイヤーは文字化けの床の上に立てるが、立つとライフが減る。
- 判定は、今ある「残り続けるダメージ床」（Area の持続）を、区画ごとに出すだけ。新しく作るのは、順番に出す係と、絵。
- 時間があれば、本当に穴にする（優先度 C。落ちたら `PitRecovery` でライフ -1、残っている床へ戻す）。

**OK の条件**
- 点滅が左から順に進み、右の2区画と、浮いた足場2枚は安全なまま。
- 文字化けの床に立つとライフが減る。足場の上では減らない。
- 5.5秒で床が戻る。50%・100% でもすぐ戻る。戻ったあと、ウイルス本体が床を走れる。

### 4-2. chmod 000 player（ボスの技）
- 【チームの案】プレイヤーの頭上に「Permission Denied」のロックがかかり、一時的にジャンプや通常攻撃が封じられる。
- **2026-11-18 まさぴ〜の指示で変更**：「鍵の弾に当たったら封印」をやめ、「**一定のエリア（アクセス禁止エリア）にいると封印**」にする。鍵の弾はなくす。封印の中身（ジャンプと近接を3秒、ダメージなし）と、封印の間のアクセス拒否の柱は、前のまま。細部はどれも【仮】。

**流れ（第1形態。避ければ 約1.2秒＝予告 0.9秒＋エリアが消える 0.3秒。封印がかかれば 約3.9秒＝予告 0.9秒＋封印 3秒）**
1. **コマンドを打つ ＝ エリアの予告**（0.9秒）：`$ chmod 000 player`。
   - 打ち始めた瞬間に、**そのときのプレイヤーの横の位置を中心に**、アクセス禁止エリアが1つ出る。**場所はここで決まり、あとは動かない**（プレイヤーを追わない）。
   - エリアは、幅5マスの縦の帯（床から天井まで）。エリアの上に開いた南京錠が浮かび、左右のふちに赤い鎖が天井から下りてくる。
   - 鎖は 0.9秒かけて床まで下りる。**鎖が床に着く瞬間が、判定の瞬間**（鎖の先の高さが、残り時間の目印）。
2. **判定**（0.9秒の瞬間に1回だけ）：南京錠がガチャンと閉まる。その瞬間に、プレイヤーがエリアの中にいたら封印。
   - 外にいたら：何も起きない。エリアは 0.3秒で砕けて消え、技は終わり（ボスのすき）。
   - 中にいたら：**ダメージなし**。エリアの南京錠がプレイヤーの頭の上へ飛んで閉まり、`Permission Denied` の文字が出る。封印 3秒。
   - 判定は1回きり。判定のあとにエリアへ入っても、何も起きない（エリアはすぐ消える）。
3. **封印の間**（3秒。前のまま）：ジャンプと近接が使えない。押すと、南京錠がゆれるだけ。
   - 移動と能力（1／2／3）は使える。
   - ボスは、アクセス拒否の柱を2回出す（予告 0.8秒の赤い柱。歩けば避けられる）。
   - **封印が切れるまで、ボスは次の技を始めない。**
4. **終わり**：南京錠が開いて消える。

**エリアの決まり【仮】**
- 形：縦の帯。**床から天井まで全部**が中。当たるかどうかは、**横の位置だけ**で決まる。
  - 浮いた足場の上にいても、ジャンプして空中にいても、帯の中なら封印される。足場に乗っても、ジャンプしても避けられない。
  - 理由：「どこが危ないか」を横の位置だけで読めるようにする。答えを「歩いて帯の外へ出る」の1つにする。
- 場所：プレイヤーの位置に合わせる（部屋を区切る形にはしない）。帯は部屋の中へ押し戻さない。壁ぎわでは、帯が壁で切れるだけ（中心はプレイヤーのまま）。
  - 理由：押し戻すと、壁ぎわで出るまでの距離が 2.5マス → 5マスに伸びて、間に合わなくなる。部屋を区切る形は、rm -rf（床を4マスずつ区切る）と見分けにくい。
- 判定の取り方：プレイヤーの体のまん中（横の位置）が、帯の中にあるか。判定の幅は、見た目より左右 0.2マスずつせまくする（見た目 5マス → 判定 4.6マス）。ふちでは、プレイヤーの得になる。
- 判定は「ある瞬間に中にいたら」。「中にいる間ずっと」にはしない。
  - 理由：ずっと判定すると、封印のかけ直しや延長が起きて、「3秒で必ず解ける」「何もできない時間を作らない」が守れない。

**避け方**
- 鎖が下りてくる帯から、歩いて出る。左右どちらでもよい（壁ぎわなら、部屋の内側へ）。
- 封印されたら、柱の予告（床の赤い印）から歩いて出る。必要なのは 約1マス、0.8秒ある。

**公平さの計算【仮】**（歩きだけで出られること。ジャンプには頼らない）
- 場所が決まってから判定まで：0.9秒（0章の決まりの 0.8秒より長い。第2形態でも短くしない）。
- 見てから動き出すまでを 0.3秒とすると、歩ける時間は 0.6秒。毎秒7マスなので、**動ける距離は 4.2マス**。
- 第1形態：帯の中心にいるので、出るのに要るのは **2.5マス（0.36秒）**。動き出しが 0.54秒おくれても間に合う。壁ぎわでも同じ 2.5マス（帯を押し戻さないから）。
- 第2形態：プレイヤーの帯の両どなりに、幅 2.5マスの安全なすき間がある（下の表）。すき間までは同じ **2.5マス**。すき間の反対側のふちまでは 5マスで、見てから歩き出した場合は 0.6秒で 4.2マスしか進まないので、歩き続けても、となりの帯には入らない。
  - ただし、帯が出たときにもう走っていたら、0.9秒で 6.3マス進み、となりの帯に入る。その場合は、**すき間（2.5〜5マス先）で止まる**か、引き返す。第2形態は「すき間で止まる」技。
  - 壁に近いと、壁側のすき間が欠ける（x が ±5 を越えると欠け始め、±7.5 より先では全部が部屋の外）。内側のすき間は、どこにいても必ず部屋の中にある（1つは必ず残る）。
- 空中にいるときも、横の速さが毎秒7マスなら同じ計算【要確認：空中の横の速さと、歩き出しの加速】。足場（幅 2.4）の上にいたら、歩いて足場から下りながら出る。
- 【要確認】安全な場所が、ボスの立っている所と重なることがある。ボスの体に触れてダメージがあるなら、第2形態の帯の置き方（下の表の「間」）を見直す。

**数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| アクセス禁止エリア | 1つ。プレイヤーの位置が中心。幅 5マス × 床から天井（11.5マス） | 3つ。プレイヤーの位置と、その左右 7.5マス（帯と帯の間は 2.5マス）。幅は同じ 5マス |
| 予告（場所が決まってから判定まで） | 0.9秒（コマンドを打つ時間と同じ） | 同じ（短くしない） |
| 判定 | 0.9秒の瞬間に1回。ダメージなし | 同じ。3つは同時 |
| 封印 | 3秒。ジャンプ・近接だけ | 同じ（長くしない） |
| アクセス拒否の柱 | プレイヤーの位置に1本（幅1.5×高さ6）。予告 0.8秒、判定 0.2秒。1.2秒おきに2回 | 3本（プレイヤーの位置と ±4マス）を2回 |
| 柱に当たったとき | ライフ -1 | 同じ |

- 第2形態の違いは、**帯の数だけ**（1 → 3）。第1形態は左右どちらへ出てもよいが、第2形態は「出すぎると、となりの帯」になり、すき間で止まる必要がある。予告・封印の長さは変えない。
- 「場に残る技」（1-3）。エリアが出ている間と、封印の間は、rm -rf と fork は選ばない（そもそも次の技を始めない）。
- 足場の上で封印されても、歩いて下りられる。

**見た目【仮】**（ターミナルの「Permission denied」。文字ではなく、鎖と南京錠で伝える）
- アクセス禁止エリア：
  - 左右のふちに、赤 `#FF453A` の鎖（幅3ドット）。天井から 0.9秒かけて床まで下りる。
  - 中は、うすい赤（15%ほど）の斜めのしま（進入禁止のしま）。しまは、ゆっくり下へ流れる。
  - 帯の上のほう（床から 7マスあたり）に、開いた南京錠（14ドット。本体は灰色 `#8E8E93`、つるは白 `#F2F2F7`、まわりに赤の光）。
  - rm -rf（床の線が赤く点滅・高さ 1.2マスの帯）と見分けられるように、**床は光らせない**。縦の鎖と南京錠が目印。
- 判定の瞬間：南京錠が閉まり、帯が白く 0.1秒光る。
  - 外にいたら：鎖と南京錠が砕けて、灰色のかけらになって落ちる（0.3秒）。
  - 中にいたら：南京錠が小さくなって、プレイヤーの頭の上へ飛ぶ。鎖は消える。
- 頭の上の南京錠：10ドット。閉まる瞬間に、白く光って画面が少しゆれる。
- 文字列：`Permission Denied`（赤 `#FF453A`、Press Start 2P、小さめ。黒いふち1ドット）。封印の間ずっと頭の上。残り 1秒で点滅（切れる予告）。
- プレイヤー：封印の間、足元に赤い鎖の輪。
- アクセス拒否の柱：赤 `#FF453A` の柱に、白い「進入禁止」の丸い印。予告は、VS Code のブレークポイントと同じ赤丸。

**割り切り**
- 柱は、今ある VS Code の「ブレークポイント」（指定位置の柱）の複製。色と絵だけ変える。
- エリアは、当たり判定の部品を置かない。判定の瞬間に、プレイヤーの横の位置と帯の範囲を比べるだけ。
- 帯は動かない・追わない・残らない。判定のあとは、絵が消えるだけ。
- 「場に残る技」の仕組み（1-3）がまだ無ければ、「封印の時間を技の長さにふくめる」だけで足りる。

**今の実装から変える所の目安**（鍵の弾の版は、もう作ってある）
- `TerminalLockBullet.cs`：使わなくなる。消す。
- `TerminalChmodAttack.cs`：手順の 1〜2（弾を浮かべる・撃つ・当たるのを待つ）を、「エリアを出す → 0.9秒待つ → プレイヤーの横の位置で判定」に入れ替える。手順の 3（封印・柱・封印が切れるまで待つ）は、そのまま。エリアの幅・数・間・判定の内寄せは、このクラスの欄に持たせる。
- エリアの絵（鎖・しま・南京錠）を出す部品を1つ足す。50%・100%・ボスが止められたときに消えるように、片づけの入口（1-2）に乗せる。
- `TerminalSealEffect.cs`：中身はそのまま。今は「当たった被弾範囲」を受け取って封印をかけるので、プレイヤーを直接受け取る入口を足す【要確認】。
- `TerminalSkillAssets.cs`：鍵の弾の数値（速さ・大きさ・寿命・数・扇の角度）をやめ、エリアの数値を入れる。柱の設定と「場に残る技」のオンは、そのまま。
- `TerminalArt`：鍵の弾の絵は、エリアの上の南京錠に使い回す。鎖としまの絵を足す。
- プレイヤーの入力を止める所（ジャンプ・近接）は、変えない。

**OK の条件**
- コマンドを打ち始めた瞬間のプレイヤーの位置に帯が出て、そのあと動かない。
- 鎖が床に着く前に帯から歩いて出ると、封印されず、柱も出ない。
- 鎖が床に着いた瞬間に帯の中にいると、足場の上でも、ジャンプ中でも、封印される。ライフは減らない。
- 判定のあとに帯へ入っても、封印されない。
- 第1形態・第2形態のどちらも、部屋のどこにいても（両方の壁ぎわ・足場の上をふくむ）、0.3秒おくれて歩き出して間に合う。
- 第2形態で、プレイヤーの帯のとなりのすき間に立つと、封印されない。走り続けて、となりの帯まで行くと、封印される。
- 封印の間、ジャンプと近接は出ない。歩ける。能力は使える。3秒で必ず解ける。
- 封印の間、ボスは柱のほかの技を出さない。
- 予告の間・封印の間に 50%・100% にすると、エリアは消え、封印はすぐ解ける。やり直しても残らない。

### 4-3. fork() &（ボスの技。第2形態だけ）
- 【チームの案】ボスが自分のプロセスを複製し、画面中に無数の分身「ゴーストプロセス」を出して、弾幕を浴びせる。

**流れ（技は 約1.5秒。分身は 約5秒で消える）**
1. **コマンドを打つ**（0.5秒）：`$ fork() &`。同時に、空中の4か所に、分身のうすい枠（出る場所の予告 0.8秒）。
2. **分身が出る**：ボスを小さく、半分すけた緑にした分身が4体。動かない。
3. **ボスは次の技へ**（1.5秒から）。
4. **分身が撃つ**：左の分身から順に、0.35秒おきに1発ずつ、プレイヤーを狙って撃つ。撃つ前の 0.5秒、その分身が白く光る（次に誰が撃つかの予告）。これを2周。
5. **終わり**：2周撃ったら、分身は文字になって消える。

**避け方**
- 弾は1発ずつ、順番に来る。光った分身を見て、歩く・ジャンプで避ける。
- 分身は**1回当てれば消える**（近接でも能力でも）。足場からなら近接が届く。ギャラリービューなら、まとめて消せる。
- 分身に触れても、ダメージはない。

**数値【仮】**

| 項目 | 値 |
|---|---|
| 分身の数 | 4体（「無数」に見せるのは、絵のちらつきと残像で） |
| 出る場所 | x＝-8・-4・4・8、高さは床から 5.5 と 7 を交互。プレイヤーとボスから 2.5マス以内の所は使わない |
| 分身の大きさ | ボスの6割 |
| 分身の弾 | 毎秒6マス、まっすぐ、直径 0.4、3秒で消える。当たるとライフ -1 |
| 撃つ回数 | 1体につき2発（合わせて最大8発、約2.8秒の間） |
| 分身を消したとき | ボスのゲージ +2（1体につき） |

- 「場に残る技」（1-3）。分身がいる間は、rm -rf と chmod を選ばない。エラー弾と文字列の雨は重なる（ラスボスの総力戦。分身の弾は、床を歩けば避けられる）。
- 重なりがきつすぎたら、分身がいる間のボスの待ち時間を 0.5 → 1.0秒にする。

**見た目【仮】**（プロセスが増える様子）
- 分身：ボスのウィンドウの絵を緑 `#33FF66` 1色にして、5割すかす。0.2秒ごとに、横に1ドットずれる（ちらつき）。後ろに、もっとうすい残像を2枚。
- 分身の弾：緑の `&` の字（8ドット）に、白い芯。
- 消えるとき：緑の文字（`0` `1`）にくずれて、上へ消える。
- 文字は、コマンドの行のほかには出さない（PID の番号なども出さない）。

**割り切り**
- 分身は、今ある「撃つ雑魚」を、浮かせて・動かなくして・絵を変えた物にする（HP 1、弾も雑魚の弾の色ちがい）。新しい敵の仕組みは作らない。
- 雑魚の数（ボスが出るまでのゲージ・雑魚を出す係）に、分身を数えないようにする【要確認】。
- 分身は被弾範囲を持つ。ギャラリービューは近い順に1本ずつ当てるので、4本が分身に、残りがボスに行く。これは「分身をまとめて消せる」見せ場として、そのままにする。

**OK の条件**
- 4体が、ボスとプレイヤーに重ならない所に出る。左から順に光って撃つ。
- 近接1回で分身が消え、ボスのゲージが +2 される。触ってもライフが減らない。
- 5秒ほどで、残った分身が全部消える。50%・100% でも消える。
- 分身がいる間、rm -rf と chmod が出ない。

### 4-4. sudo reboot（形態変化）と、カーネル・パニック（第2形態）
- 【チームの案】ボスの HP をゼロにすると「System Rebooting…」の文字が浮かび、第二形態（カーネル・パニック状態）へ突入。背景が真っ暗なエラー画面になり、無数の文字列が弾幕となって降り注ぐ総力戦。

**どこに入れるか【仮】：ゲージ50%の形態変化を、再起動の演出にする**
- 今の仕組み：ゲージ50%で第2形態（演出 1.5秒、無敵）、100%でウイルス本体が追い出され、とどめで正常化。
- 決めたこと
  - 仕組みは変えない。Terminal の 50% の演出だけを「System Rebooting…」にし、時間を 3.5秒にする。
  - **ゲージの棒の見せ方だけ変える**：Terminal は、棒が「本当の50%で満タン」に見えるようにする。再起動の演出で棒が空に戻り、色が赤になる。後半は、本当の 50〜100% を、空から満タンまでで見せる。
  - 本当の 100% になったら、いつもどおりウイルス本体が追い出され、とどめで正常化。
- 理由
  - チームの案の「倒したと思ったら再起動した」を、プレイヤーにはそのとおりに見せられる（棒が満タン → 倒れかける → 再起動）。
  - 「100%で一度だけ復活する」形にすると、新しい状態・ゲージの戻し・追い出しの流れの分かれ道を作ることになる。ラスボスの最後でこわれると、発表で一番目立つ。今ある 50% の入口を使うほうが安全。
  - とどめ（ウイルス本体を1回たたく）・リザルト・図鑑は、何も変えなくてよい。
- 注意：50% の演出は、11/17 に「文字を出さない」に変えた。Terminal の `System Rebooting…` は、チームの案に入っている演出としての、Terminal だけの例外。

**再起動の演出（3.5秒。ボスは無敵。プレイヤーは動ける。ダメージなし）**

| 時間 | 見えるもの |
|---|---|
| 0〜0.6秒 | 一瞬止まる（ヒットストップ）。ゲージの棒が満タンで白く光る。ボスのウィンドウが真っ黒になり、ノイズがはじける（倒したように見せる）。場に残っている物は全部消える・戻る（1-2） |
| 0.6〜2.6秒 | 画面全体が暗くなる（黒を8割）。中央に `System Rebooting…`（白 `#FFFFFF`、Press Start 2P。`…` の点が1つずつ増えるのをくり返す）。下に、細い進み具合の棒（白、横6マス）が左から右へ |
| 2.6〜3.5秒 | 背景がカーネル・パニックの画面に切り替わる。ゲージの棒が、右から左へくずれて空になり、赤くなる。ボスが、赤いちらつきと一緒に立ち上がる。画面が強くゆれる |

**カーネル・パニックの背景【仮】**（Mac のカーネル・パニック画面。真っ黒に、小さい文字がびっしり）
- 空・雲・丘を消して、真っ黒 `#000000`。
- 飾りの文字：暗い緑 `#0F3D1E`、5ドットの小さい字、びっしり並べて、ゆっくり上へ流す。文字列は `panic(cpu 0 caller 0x0): kernel trap`、`BSD process name: virus`、`System uptime in nanoseconds` などの、それらしい英字（個人の情報はふくめない）。
- 床の上の線・足場のふち：緑 `#33FF66` から、うすい灰色 `#C8C8C8` に変える。**赤にはしない**（赤は「危ない」の予告だけに使う。rm -rf の赤い点滅・文字化けの床・柱・雨の線が、まぎれないように）。
- ボス：ウィンドウのふちとタイトルバーを赤に（赤くしてよいのはボスの体だけ。触ると危ない物なので、決まりに合う）。0.5秒に1回、横にずれるちらつき。
- ブルースクリーンにしない理由：Mac のアプリなので、黒いパニック画面のほうが合う。黒と緑のステージから、色を作り直さなくてよい。

**文字列の雨（第2形態の技）**
- 流れ（合わせて 約3.5秒）
  1. **予告**（0.7秒）：部屋を、2マスずつ10本の列に分ける。落ちてくる列の天井に、白い四角いカーソルが点滅し、床までうすい赤の線が伸びる。
  2. **落ちる**：その列に、縦に並んだ文字列（5文字）が落ちる（毎秒9マス）。床で消える。
  3. これを3回（0.9秒おき）。落ちる列は、毎回変わる。
- 避け方：予告のない列（安全な列）へ歩く。
- 数値【仮】

| 項目 | 値 |
|---|---|
| 1回に落ちる列 | 10本のうち6本。安全な列は4本 |
| 安全な列の決まり | プレイヤーの今の列から 4マス以内に、必ず1本ある（0.7秒で 4.9マス歩ける） |
| 文字列の判定 | 幅 1.4マス × 長さ 3マス。となりの列との間は 0.6マス（体は 0.7マスなので、間には立てない） |
| 足場 | すり抜ける（足場の上でも当たる） |
| 当たったとき | ライフ -1 |

- **飾りの文字と、当たる文字の見分け**
  - 飾り：暗い緑、5ドット、背景の奥、ゆっくり上へ。
  - 当たる文字：白い芯 `#FFFFFF` に赤 `#FF453A` のふち、1文字 14ドット、手前、速く下へ。予告の線が必ず先に出る。
  - 色・大きさ・向き・予告の4つを全部変えて、まぎれないようにする。
- 割り切り：列の柱として判定する（文字1つずつに判定を付けない）。予告の出し方は、ブレークポイントの柱を天井から出す形でもよい。
- 時間があれば、文字列を「弾」として作り、zip圧縮で吸えるようにする（優先度 C）。

**OK の条件**
- 本当のゲージが 50% になった瞬間、棒が満タンに見えている。演出のあと、棒が空・赤になり、背景が黒になる。
- 演出の 3.5秒の間、ボスにゲージが入らず、プレイヤーはダメージを受けない。
- 後半で棒が満タン（本当の100%）になると、ウイルス本体が追い出され、1回当てると正常化 → リザルトへ進む。
- 文字列の雨：3回とも、予告のない列に立てば当たらない。飾りの文字には当たらない。
- Chrome・VS Code・ほかのボスの 50% の演出と棒は、今までと同じ（Terminal だけ変わる）。

## 7. まだ決まっていないこと・チームに聞くこと

- 0章の表は、どれも【仮】。とくに次の3つは、チームの案から形を変えているので、チームに見せる。

- 難しさ（ライフがどれくらい減るか）は、遊んで決める。数値はどれも、遊ぶ前の置き値。
