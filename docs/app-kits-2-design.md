# アプリのキット 2（開発・制作・ゲーム・音楽と動画・ブラウザ）：「このアプリといえば！」を技・能力・ギミックにする

- 書いた日：2026-11-19
- 書いた人：Claude（ゲームデザインの役）。まさぴ〜の依頼。
- 状態：コードもアセットも変えていない。この文書だけを足した。Unity も動かしていない。
- 対になる文書：docs/app-kits-1-design.md（チャット・仕事・AI のキット）。**決まりと共通の入口は、あちらの 0章・1章と同じ**。この文書は、足す分だけを書く。
- 対象：16アプリ（Unity・GitHub Desktop・Steam・Figma・Photoshop・Xcode・Cursor・Illustrator・Blender・Minecraft・ミュージック・Spotify・QuickTime Player・Safari・Arc・Firefox）。
  - 対象外：Chrome・VS Code・Finder・Premiere Pro・Terminal（別の担当が直す）。
- 依頼：どのステージもボスも基本が同じで味気ない。「このアプリといえば！」をボスの技・プレイヤーの能力・ステージのギミックにする。
- 凡例
  - 【仮】：この文書で決めた細部（数値・色・名前）。遊んで直してよい。**断りがなければ、数値と色はすべて【仮】。**
  - 【新規】：まだ無い入口・クラス。名前はこの文書で決めた（1章）。
  - 【要確認】：実装の前にコードを見て確かめること。
  - 【要相談】：まさぴ〜に決めてほしいこと（6章）。
- 前提（今ある決まり。変えない）
  - 長さはマス（1マス＝18ドット）、時間は秒。プレイヤーは毎秒7マス、ジャンプ 3.2マス、体は 0.7×1.0。
  - 部屋は横20マス（x＝-10〜10）、床から天井まで 11.5マス。足場は x＝±3.5、幅 2.4、高さ 3。
  - ボスの攻撃はどれもライフが1減る。被弾後の無敵 1.0秒。
  - 予告は 0.8秒以上。第2形態でも予告は短くしない。難しくするときは数と密度。
  - **逃げ場の決まり**：安全な場所は、プレイヤーから「（予告の秒数 − 0.3）× 7マス」以内に必ず1つ置く（0.3秒は、見てから動き出すまで）。区画を使う技は、プレイヤーのいる区画か、となりの区画を安全にする。
  - **危ない物の予告は赤 `#FF453A`**。アプリの色の予告（水色・オレンジなど）は「まだ安全」の意味にだけ使う。
  - 説明の文字は足さない。出す文字は、実在の UI をまねた短い英語だけ（Press Start 2P。日本語と「…」は出せないので `...`）。
  - **本物のデータを画面に出さない**（アカウント名・リポジトリ名・曲名・閲覧履歴）。名前が要る所は `PLAYER`・`main`・`Track 1` など固定の文字。
  - 音に合わせる技は、音を読まない。決まった秒数で動かす。

## 0. 先に読む：全体の形

- アプリ1つ＝**キット**1つ。キットの中身は4つ：
  1. ボスの技：第1形態 2つ、第2形態はその強い版＋もう1つ。
  2. プレイヤーの能力 1つ（そのボスを倒すと手に入る。能力えらびのカードにも出る）。
  3. **ステージの決まり（ギミック）** 1つ：雑魚の時間からボス戦まで、ステージ全体にかかる。
  4. 絵：そのアプリらしい物は、キットが自分で描く（コードの中のドット絵。1-3 の X3）。
- ③ の出来事（雨・柱床・群れ）は、**今のカテゴリの物のまま**。キットでは作らない（作る量を減らす）。
- キットが無いアプリ・作りかけのアプリは、今までどおりの代用ボス（1-1）。
- 1キットの量の上限：**新しい Custom は 1〜2個**（キット1 と同じ。共通の部品 `Kit3D`・`PathStroke`・`WallShot`・`ZoneStrike` などを呼ぶだけの小さい物は数えない）。残りは今の部品（弾・指定位置・落下物・瞬間移動・ロックオン）の攻撃データ。

## 1. 共通の入口

**土台は、キット1 の文書（docs/app-kits-1-design.md の 1章。E1〜E6）と同じ物を使う。同じ担当0 が1回だけ作る。** 名前も置き場所も、あちらに揃える。ここには「どう使うか」と「この文書のキットのために足す物（X1〜X4）」だけを書く。2つの文書で食い違ったら、キット1 の 1章が正。

### 1-1. キット1 の入口の使い方（E1〜E6）

| 入口（キット1 の文書） | この文書での使い方 |
|---|---|
| E1 `AppKit`（`Resources/Kits/Kit_〇〇.asset`。1キット＝1アセット）・`AppKits.Find`・`KitAssetBuilder`・`AppKits.Enabled` | そのまま。キットのコードは `Assets/Scripts/Kits/<Id>/`、アセットを作るコードは `Editor/Kits/<Id>KitAssets.cs`。`<Id>` は `Unity`・`GitHubDesktop`・`Steam`・`Figma`・`Photoshop`・`Xcode`・`Cursor`・`Illustrator`・`Blender`・`Minecraft`・`Music`・`Spotify`・`QuickTime`・`Safari`・`Arc`・`Firefox` |

- ボスの型：**浮く**＝Chrome 型、**ワープ**＝VS Code 型（床に立ち、瞬間移動）。キット1 と同じ言い方。
- Unity Hub は Unity と同じキットにする（`AppKit` の名前の欄に両方）【要相談⑥】。
- バンドルID（リポジトリに既にある物）：`com.unity3d.`・`com.github.GitHubClient`・`com.valvesoftware.steam`・`com.figma.Desktop`・`com.apple.dt.Xcode`・`com.todesktop.230313mzl4w4u92`（Cursor）・`com.apple.Safari`・`company.thebrowser.Browser`（Arc）・`org.mozilla.firefox`。**ほか（Photoshop・Illustrator・Blender・Minecraft・ミュージック・Spotify・QuickTime Player）は【要確認】**。分からなければ名前だけで見分ける（今の `SkinTables` に名前がある）。

### 1-2. ステージの決まり（`StageRule`）：いつ止めて、いつ消すか

- キット1 の E3 と 0-3（ギミックの公平さ）に従う。この文書のキットは、**置く物（乗れる箱・四角）**が多いので、片づけの表を足す。`StageRuleHost` がまとめてやるのが望ましい（担当0 に頼む。無ければ各 `StageRule` が `OnPhase`・`End` で自分で消す）。

| とき | 危ない物 | 置いた物（箱・四角・拾える物） | 強さの倍率 | 飾り（HUD・背景） |
|---|---|---|---|---|
| ステージの最初の 3秒 | 出さない | 出さない | — | 出す |
| ③ 出来事・④ ひと休み | 新しく出さない | そのまま | そのまま | そのまま |
| ボスの登場（`Done`） | **全部消す** | **全部消す** | そのまま | そのまま |
| ボスが動き出して 4秒 | 出さない。そのあと再開 | 同じ | — | — |
| 50%（形態変化） | 全部消す。3秒は出さない | 全部消す | そのまま | そのまま |
| 100%・やり直し（`End`） | 全部消す | 全部消す | **全部外す** | 消す |
| 次のステージ | 持ち越さない | 持ち越さない | 持ち越さない | — |

- 第2形態に入ったことは、`Tick` の中でボスの形態を見て知る【要確認：`BossController` の読める欄】。
- 公平さ（キット1 の 0-3 に足す分）
  - ギミックの危ない物：予告は**赤で 1.0秒以上**。同時に1つ。プレイヤーの 4マス以内には出さない（「プレイヤーの位置」と書いた物を除く）。
  - **罰はライフを減らさない**（キット1 と同じ）。守れなかったときは、ボス・雑魚が 8〜10秒だけ少し強くなる。
  - 置いた物でプレイヤーを閉じこめない：同時に 4つまで。足場の上と、部屋の両端 2マスには置かない。プレイヤー・ボスに重ねない。
  - ボスの「場に残る技」の間（`CustomEffect.AnyLingering`）と、ボスの技の予告の間は、新しく出さない【要確認：技の途中かを読めるか。読めなければ、ボス戦の間隔を 12秒以上に】。
- 倍率の上限と下限（`StatMods` を使う側で守る）：プレイヤーの速さ 〜1.4、与えるゲージ 〜1.6、クールタイムの進み 0.6〜1.7倍、ボスの移動 〜1.6、ボスの待ち時間 0.7〜1.5。**ボスの予告の長さと弾の速さは、どの倍率でも変えない。**
- この文書の「クールタイム ×0.7」は「待つ時間が 0.7倍になる」の意味。`StatMods` が「進み方の倍率」なら、逆数（1÷0.7）で入れる。

### 1-3. この文書のキットのために足す物（X1〜X4）

置き場所は `Assets/Scripts/Kits/Common/`。名前は【新規】。

**X1. 3D の物体 `Kit3D`**（Unity・Blender・Minecraft。**担当A が作る**）
- 当たり判定は 2D のまま。**2D のコライダー（箱・円・カプセル）を持つ親に、見た目だけの `MeshRenderer` の子**を付ける。
- `Kit3D.Spawn(形, 位置, 大きさ, 色)`：立方体・球・カプセル・円柱。標準のシェーダー（Standard）。**ドット絵にしない。** 少し回した向き（x 20°・y 30°）で置くと立体に見える。
- 明かり：平行光を1つ、最初の `Spawn` のときに作る（斜め上から。影は切る）。スプライトは明かりを受けないので、ほかの絵は変わらない。
- 重なり：3D の物体は z を手前に置く。**スプライトより手前に映る**（プレイヤーが後ろに隠れることがある）【要確認：メインのカメラで映るか。だめなら、3D だけを映す2つ目のカメラを重ねる】。HUD（OnGUI）より下。
- 数の上限：同時に 8個。越えたら古い物から消す。
- 落ちる・転がる物は `Rigidbody2D`。回る見た目は、速さに合わせて子を回すだけ。
- 予告 `Kit3D.Bracket`：出る場所に、角だけの枠と「!」（見本の動画と同じ形。色は赤）。
- 落ちる物 `Kit3D.Faller`：落ちている間だけ当たり、止まると乗れる箱になり、N秒で消える。Unity の技1・能力・決まり、Minecraft の砂が使う。**`KitBlock`（X4）には頼らず、これだけで動く**（担当A と担当D が同じファイルを作らないように）。

**X2. 道に沿った線 `PathStroke`**（Photoshop・Illustrator。**担当D が作る**）
- 点の列（折れ線・曲線を 8〜10 の区間に割った物）を受け取り、赤い細い予告の線 → 太い線の判定（区間ごとに回した箱）と絵を出す。

**X3. キットの絵を部品に付ける `KitDress`**（小さい関数1つ。担当0。空の形を最初の 30分で入れる）
- 困ること：今の部品（弾・指定位置・落下物）は、攻撃データの名前の「枠の語」で、**カテゴリのスキンの絵**が付く。Steam の値札・Minecraft の TNT のような物が、ゲームのスキンのミサイルの絵になってしまう。
- 決まり：
  - カテゴリの絵で合う技は、キット1 と同じく枠の語を入れる（コードなし）。
  - **キットの絵にしたい技**は、名前に枠の語を入れず（スキンの絵が付かない）、Custom 小から部品を呼んで、返ってきた物の絵を `KitDress.Swap(物, 絵)` で差し替える。
  - 確かめた：`Projectile.Spawn`・`AreaStrike.Spawn`・`FallingObject.Spawn` は出した物を返す。`SkinTables.FrameOf` は、枠の語が無い名前には「枠なし」を返す。**だから `Visual/Skins/` は変えなくてよい。**
  - 気をつける：攻撃データの名前に、枠の語（`breakpoint`・`redwave`・`errorwindowfall`・`bomb_blast`・`bargraph`・`paintbucket`・`gen_〇〇` など）をうっかり入れない。予告・着地の絵（影・赤い枠）は、部品の今の絵のままでよい。
- 絵は、キットのフォルダの `<Id>Art.cs` に、コードの中のドット絵（`RuntimeSprites.FromAscii`）・`WorldText`・`MacUi` で作る。絵のファイルは足さない（キット1 と同じ）。
- 当たったときの `HitFx`・とどめの通知は、カテゴリのスキンのまま。

**X4. 置く物 `KitBlock`**（乗れる・壁になる・弾を止める・N秒で消える。当たらない。**担当D が作る**。Figma の四角・Blender の Default Cube が使う）
- 持ち主は担当D だけ。`KitProp`（叩ける置物）と組み合わせられること（Default Cube は「乗れて、叩ける」）。使うのは Figma の四角と、Blender の Default Cube（優先度 B。そのころには出来ている）。
- 出す前に、その場所にプレイヤー・ボス・足場が無いことを見る。雑魚がいたら上へ押し出す（`Kit3D.Faller` が止まるときも同じ）。
- 【要確認】置いた物があるとき、歩く雑魚が引っかかって止まらないか（止まるなら、雑魚は置いた物をすり抜ける）。ワープ型のボスの行き先が、置いた物に重ならないか（重なるなら、ボスが出る所の物を消す）。

### 1-4. 能力の決まり（キット1 の 0-3 と同じ。足す分だけ）

- 能力はほかのステージ・Terminal でも使う。**ステージの決まりに頼る能力にしない**（どこでも単体で動く）。
- 2回押しは Finder の zip と同じ入口（`DefersCooldown`）。
- 隅の通知：Mac の通知は右上（`KitToast`）。Steam の実績だけは、本物と同じ右下（アプリの中の UI なので）。

## 2. キット（優先度 A）

書き方：**流れ**（秒）／**避け方**／**見た目**／**部品**／**OK**（確かめること）。「当たったとき」は、書いていなければライフ1。

### 2-1. Unity（Unity Hub も）　A・大・担当A・ワープ

- **といえば**：シーンに置く立方体・球・カプセル。Rigidbody で落ちて転がる。シェーダーが無いときのピンク。Console の赤いエラー。再生ボタン。
- **見た目の決まり**：物体は **3D のまま**（1-3 の X1。灰色がかった白 `#D8D8D8`。見本の動画と同じ）。まわりの UI はドット絵。

**技1：GameObject > 3D Object**（3D の物体が、ランダムな座標に出て落ちる）
- 流れ：赤い角の枠と「!」が 3か所に 0.9秒（高さ 5〜9マス。x はランダム、1つはプレイヤーの真上）→ 立方体・球・カプセルが出て落ちる → 床で止まり、**4秒残る**（乗れる・壁になる）→ 薄くなって消える。
- 避け方：枠の真下から出る。止まった物は当たらない。
- 当たるのは落ちている間だけ（速さが毎秒2マス以上）。球は落ちたあと 2マス転がる（転がっている間は当たる）。
- 第2形態：5か所。0.3秒ずつずらす。
- 見た目：枠は 2×2マス、角だけ、太さ 2ドット。出る瞬間に白い光 0.05秒。止まった物は少し暗く。
- 部品：`Kit3D`＋Custom（小）。落下物の影の出し方を使い回す。
- OK：枠の外にいれば当たらない。止まった物に乗れる。50% で全部消える。

**技2：Rigidbody の球**（大きい球が床を転がる）
- 流れ：ボスの前に直径 2マスの球が出る（0.3秒）→ 床に赤い矢印の帯（進む向き。0.8秒）→ 毎秒 9マスで反対の壁まで転がる → 壁で止まり、1秒で消える。

**技2：音の波**
