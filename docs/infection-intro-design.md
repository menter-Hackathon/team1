# 最初の「感染 → ゲームを起動」の流れ（設計。2026-11-20）

- 書いた人：演出デザイン（Fable）。作る人：Opus（今日中。半日より小さい）。
- この文書は設計だけ。コード・絵・音・Unity・git は、この文書では変えていない。
- 数値は全部【仮】。座標は `PixelGui.Width`（W）・`PixelGui.Height`（H）の論理ドット（左上が 0,0。W は 640 以上、H は 360 以上）。
- 時間は全部 `Time.unscaledTime`。**T** は「感染のステップが始まってからの秒」。

## 0. まとめ

### 【確定】（まさぴ〜の言葉。これだけ）

> 「最初にウイルスが入ってやばい倒さなきゃという動機づけの流れがほしい。イメージではロック解除すると→ウイルスに感染→ウイルスを退治するためにこのゲームを起動→ウイルスに対抗するためスクリーンタイムでアプリをスキャン→相棒を選ぶ」

1. ロック解除 → ウイルスに感染。
2. 退治するために、このゲームを起動する。
3. スクリーンタイムでアプリをスキャン → 相棒を選ぶ。（ここは今の流れのまま）

### 【提案】（ここから下は全部）

- ロック解除とデスクトップの待ちの間に、**感染のステップ（6.0 秒）** を1つ足す。
- 流れ：きれいなデスクトップ → 「ダウンロード」のフォルダが紫になる → そこから雑魚ウイルスが跳び出し、Dock のアプリに1匹ずつ乗って紫に染める → 警告の窓が2つ出る → 最後の1匹がゲームのアイコンに跳びつくが、**はじかれて消える** → ゲームのアイコンだけ白く光って待つ。
- 「やばい」＝自分のアプリが順番に染まる。「倒さなきゃ」＝ゲームのアイコンだけがウイルスをはじいた。
- 飛ばせる（Enter・Z・Space・A・START・クリック）。飛ばすと「感染し終わったデスクトップ」になる。起動まではしない。
- **短い版は作らない。毎回同じ長い版**（発表で必ず出る。保存する旗も要らない）。
- 起動のあと：タイトルの後ろのデスクトップは **感染したまま**（Dock の紫・うすいかけら・メニューバーの「感染 N」だけ）。警告の窓は出さない。
- **新しい SE は作らない**。今あるキーで足りる（5章）。
- 新しい絵・シーン・プレハブは無し。新しいファイルは `Assets/Scripts/Dev/MacDesktopInfection.cs` の1つ。

| | 入ってくるウイルス | ゲームのアイコン |
|---|---|---|
| 形 | 台なしの雑魚の絵（16×16） | 青い角丸の台（30×30）の上の雑魚の絵（今のまま） |

## 3. 各部品の絵の決め

### 3-0. 共通の位置

- Dock：`c = 2 + Dock のアプリの数`。`dock = (round((W − (c×42+12)) / 2), H − 54, c×42+12, 48)`。
- Dock のアイコン i：`(dock.x + 9 + i×42, dock.y + 6, 30, 30)`。i=0 Finder、**i=1 ゲーム**、i=2〜 アプリ。
- フォルダ i（0＝書類、1＝ダウンロード）：絵の四角 `(W − 63, 43 + i×64, 32, 26)`。
- **Dock のアイコンは、マウスが乗ると 3ドット上がる**（`MacDesktopGui.Dock` の中）。上に重ねる絵も同じ条件（`r.Contains(Event.current.mousePosition) && GUI.enabled`）で 3ドット上げる。
- 色：紫 `PixelGui.LabelPurple`（#6A2A8C）・濃い紫 `PixelGui.Ink`（#1E0830）・マゼンタ `PixelGui.Magenta`（#ED38FF）・うす紫 `PixelGui.Lilac`（#B376E9）。染める色 `InfectTint = (1, 0.55, 1)`（DesktopScreen と同じ値を新しいファイルに書く）。**赤・DarkRed は使わない**。

### 3-1. 壁紙のかけら（DrawBack。フォルダ・Dock より先に描く）

DesktopScreen.DrawWallpaper と同じ描き方。数とこさだけ変える。

| 場面 | かけらの数 | マゼンタのこさ | 切りかえ |
|---|---|---|---|
| 感染中 | 4 × 感染の数（0〜20） | 0.25 + 0.03 × 感染の数 | 1秒に 8回 |
| 待ち・起動中 | 20 | 0.40 | 1秒に 8回 |
| 起動後（のこり） | 6 | 0.20 | 1秒に 4回 |

- かけら：幅 6〜60、高さ 2〜6。y は 26 〜 H−8。3つに1つは黒（こさ 0.45）。
- 横の線：W いっぱい、高さ 4、マゼンタ（こさ 0.5）、0.12 秒。T=0.9（y = H×0.35）と T=3.7（y = H×0.6）の2回だけ。起動後は出さない。

### 3-2. フォルダ（上から重ねて描く）

- 染まった絵：タブ `Fill(x, y, 14, 6)` 紫。体 `Fill(x, y+4, 32, 22)` 紫。面 `Fill(x+1, y+8, 30, 17)` うす紫。光の線なし。
- 中を走る線：`Fill(x+5, y+11 + ((step+i) % 3)×4, 22, 2)` マゼンタ（step＝1秒に 6回）。
- 染まり方：上から下へ 0.4 秒（描く高さを 0→26 に。むずかしければ一瞬で切りかえてよい）。ダウンロード＝T 0.9〜1.3、書類＝T 2.6〜3.0。
- 名前の字は今のまま（重ねない）。

### 3-3. 雑魚（跳ぶ・乗る）

- 絵：`GameArt.Instance.ZakoWalk`、16×16、1秒に 6コマ。
- 出る所：ダウンロードのフォルダのまん中 `F = (W − 47, 120)`。
- 着く所：的のアイコンの右上。四角 `(icon.xMax − 12, icon.y − 9, 16, 16)`（DesktopScreen.DrawVirusOn と同じ）。
- 跳び方：0.6 秒。p=0→1 で、x と y はまっすぐ、そこへ `y −= sin(p×π) × 36`。ドットに丸める。
- 残像：0.06 秒前の位置に、同じ絵をマゼンタ（こさ 0.45）で1枚。
- 的の順：①〜④＝アプリを右から（i = c−1, c−2, …, 2）。出る時刻 = 1.3 + 0.45×k（k=0〜アプリの数−1。4つまで）。Finder（i=0）へ跳ぶ雑魚は、いつも T=3.1 に出る。
- 雑魚の絵は黒っぽい小さな玉（`Zako_Walker.png`）。壁紙の上で見えるように、残像のマゼンタは必ず描く。
- 乗ったあと：そのまま歩く絵で動き続ける。

### 3-4. 染まった Dock のアイコン（上から重ねて描く）

- アプリ（i≥2）：`Rounded(icon, Lilac, 5)` → `DrawSprite(Inset(icon, 2), 本物のアイコン, InfectTint)`。
  - チラつき：step＝1秒に 10回 + i×3。`step%7==0` か `step%11==0` のとき、絵を横に ±2 ずらし、反対側にマゼンタ（こさ 0.45）の残像（DesktopScreen.DrawAppIcon と同じ）。
- Finder（i=0）：絵を描き直せないので、`Rounded(icon, 紫でこさ 0.55, 5)` を重ね、マゼンタの線 `Fill(x+3, y+6 + (step%3)×8, 24, 2)`。
- 乗った瞬間：0.15 秒だけ、アイコンのまわりにマゼンタと濃い紫のかけら 10個（DesktopScreen.DrawArrival と同じ）。
- **ゲームのアイコン（i=1）には何も重ねない**。

### 3-5. 警告の窓（`MacDesktopGui.Window`。ボタンなし・押せない）

- 大きさ 216×76。位置は、タイトルの窓の四角 `tw = CenteredWindow(W, H, 420, 298)` のまん中 `(cx, cy)` から。タイトルの窓が開くと全部かくれる。

| 窓 | 出る T | 左上 | 題名 | 絵（24×24） | 一言（12、`MacDesktopGui.Ink`） |
|---|---|---|---|---|---|
| ① | 4.0 | (cx−160, cy−104) | 警告 | うす紫（Lilac）の角丸の台＋歩く雑魚（雑魚が黒っぽいので、台は明るくする） | ウイルスを検出しました |
| ② | 4.3 | (cx−115, cy−42) | 警告 | 同じ | アプリが感染しています |
| ③ | 5.4 | (cx−70, cy+20) | Virus Desktop | **青い角丸の台**＋雑魚の1コマ目（Dock のゲームのアイコンと同じ） | Virus Desktop で駆除 |

- 実装で変えた所（2026-11-20、撮影のあと）：最初の位置（①(cx−150, cy−84)・②(cx−110, cy−50)・③(cx−70, cy−16)）では、② が ① の一言を隠した。縦に 62 ドットずつずらして、3つの一言が全部読めるようにした。

- 中身：`inner = Window(...)` の返す四角。絵 `(inner.x, inner.y+2, 24, 24)`、字 `(inner.x+32, inner.y+4, inner.width−32, 20)`、`PixelGui.TextFit`。
- 出方：出た 0.15 秒だけ横に ±2 ゆれる。
- ①②はそのあとも、ときどき（1秒に 10回の step で `step%9==0`）横に 2ずれ、窓の中にマゼンタの線（高さ 2）が1本。
- **③はゆれない**（味方の窓）。
- 字の帯・説明の字はこの3つの一言とメニューバーの「感染 N」だけ。

### 3-6. はじく（T=5.2）と、ゲームのアイコンの合図

- ⑥は T=4.6 に F から跳び、T=5.2 にゲームのアイコンの右上に着く。着いた瞬間に消える。
- はじける絵（DesktopScreen.DrawRestore と同じ。新しいファイルに写す）：
  - 白い光 `Inset(icon, −2)`、0.25 秒で消える。
  - マゼンタのかけら 3×3 を 8個、外へ（1秒に 70ドット）、0.6 秒で消える。
  - `GameArt.Instance.Sparkle` を 2倍で、0.7 秒（T=5.9 までに終わらせる。下の「1回だけの絵」の決まり）。
- T=5.2 からあと（待ちの間ずっと）：
  - 白い枠 `PixelGui.Border(Inset(icon, −2), 白, 1)`。こさは 0.55〜1.0 を 1秒に 1.5往復。
  - 1.6 秒ごとに、右上にきらめき（Sparkle、等倍、0.4 秒）。
  - 枠ときらめきは、跳ね（`hop>=0` のとき `y −= |sin(hop×2π)| × 7`）とマウスの 3ドットに合わせて動かす。
- 光を後ろに敷くことはできない（Dock の板が後から上に描かれる）。枠ときらめきだけにする。
- 押したあと（Bouncing・Launching）：枠ときらめきは消す。ほかは残す。

### 3-7. メニューバー

- `MacDesktopGui.MenuBar(width, app, status)` の status に「感染 N」（N＝乗った数）。今ある DesktopScreen と同じ言葉。0 のときは null。

## 4. 操作・飛ばし方

| 場面 | 押せる物 |
|---|---|
| 感染の間（T 0〜6.0） | 何も押せない（今のコードのまま、マウスの出来事は全部食べる）。**飛ばすだけ** |
| 待ち | ゲームのアイコンだけ（今のまま）。Enter・Z・Space・A・START でも開く（今のまま） |

- 飛ばす入力：`MenuInput.Confirm()`（Enter・Z・Space・A・START）か、マウスの左ボタンを押した瞬間。
- 入力ガード：T < 0.4 は飛ばない。押した「瞬間」だけ見るので、解除の Enter の押しっぱなしでは飛ばない（その前に Unlocking 0.65 秒もある）。
- 飛ばした先：**感染し終わったデスクトップの待ち**（T=6.0 の絵）。起動はしない。もう1回押すと起動（今ある `Launch` の 0.3 秒ガードが効く）。
- 飛ばしたとき、まだ鳴らしていない SE は鳴らさない（まとめて鳴らない）。
- 短い版：作らない。保存もしない。
- **発表で長い版を出す方法**：何もしなくてよい。ロック解除のあと 6 秒、キーとマウスにさわらない。
- 切り戻し：`MacDesktopInfection.Enabled = false` で、感染のステップは 0 秒・何も描かない（今の流れに戻る）。

## 5. 起動後・ランから戻ったとき

| 場面 | 後ろのデスクトップ |
|---|---|
| アイコンが跳ねる・窓が広がる（Bouncing・Launching） | 感染し終わった絵のまま。警告の窓はタイトルの窓の後ろにかくれる |
| タイトル・はじめかた・スキャン（Ready からあと） | **のこり**だけ：Dock のアプリと Finder が紫＋雑魚、フォルダ2つが紫、壁紙のかけら 6個、メニューバー「感染 N」。警告の窓・白い枠・横の線は出さない |
| 能力えらび（RunLoadoutMenu） | **何も足さない**（ファイルにさわらない） |
| ランから戻ったタイトル（起動演出なし） | 同じ「のこり」を最初から出す（Q3）。音は鳴らさない |

- のこりの N＝Dock のアプリの数 + 1（Finder）。
- のこりの Dock の重ね絵は、**絵のある項目（`Icon != null` で `Window == null`）と Finder だけ**。最小化した窓の項目（後ろに足される）には重ねない。Dock の位置は、その時の項目の数で毎回計算する。
- スキャンの窓の中身・メニュー・はじめかたは変えない。
- むずかしいとき：のこりは B（あと回し）。そのときは、タイトルが開いた瞬間にデスクトップがきれいになる。

## 7. 実装の分け方

### 7-1. 新しいファイル `Assets/Scripts/Dev/MacDesktopInfection.cs`

MonoBehaviour でない static のクラス。状態は「鳴らした音のビット」だけ。

- **1回だけの絵**（横の線・染まる・跳ぶ・乗った瞬間のかけら・窓が出るゆれ・はじける）は t で決める。**全部 T=6.0 より前に終わらせる**（待ちからあとは t が 6.0 で止まるので、終わっていない絵は止まって残る）。
- **くり返す絵**（歩くコマ・チラつき・白い枠・1.6 秒ごとのきらめき・壁紙のかけら）は `Time.unscaledTime` で動かす。

```csharp
public static class MacDesktopInfection
{
    public static bool Enabled = true;      // false＝今までの流れ
    public const float Duration = 6f;       // 感染のステップの長さ
    public const float InputGuard = 0.4f;

    // Update から。t＝MacDesktopBoot.InfectionTime(now)。時刻を過ぎた SE を1回ずつ鳴らす
    public static void Tick(float t, int appCount);   // appCount＝Dock のアプリの数。いる雑魚の音だけ鳴らす
    // 飛ばしたとき。残りの SE を「鳴らした」にする
    public static void MuteRest();

    // 起動演出の中（DrawBoot）。t<0 なら何も描かない
    public static void DrawBack(float t, float W, float H);                       // 壁紙のかけら・横の線
    public static void DrawFront(float t, float W, float H,
        IReadOnlyList<MacDesktopGui.DockItem> apps, float hop, bool launched);    // フォルダ・Dock・雑魚・警告の窓・はじく・白い枠
    public static string Status(float t, int appCount);                           // 「感染 N」か null

    // 起動後（ふつうの OnGUI）。のこり
    public static void DrawLingerBack(float W, float H);
    public static void DrawLingerFront(float W, float H, IReadOnlyList<MacDesktopGui.DockItem> items);
    public static string LingerStatus(int appCount);
}
```

- ビットは `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` で 0 に戻す（`_bootPlayed` と同じ）。
- `Enabled == false` のとき、全部の関数は何もしない（Status は null）。
- DesktopScreen の private の描き方（かけら・染め・乗る雑魚・はじける）は、**写して持つ**（DesktopScreen は変えない）。

### 7-2. `MacDesktopBoot.cs`（足すだけ）

1. `enum Step { Locked, Unlocking, Infecting, Desktop, Bouncing, Launching, Ready }`（**Desktop の前**に足す）。
2. `Tick` の長さの式に足す：`Current==Step.Infecting ? (MacDesktopInfection.Enabled ? MacDesktopInfection.Duration : 0f) :`。書かないと 0.65 秒になる。
3. `public float InfectionTime(float now) => Current<Step.Infecting ? -1f : Current==Step.Infecting ? now-_started : MacDesktopInfection.Duration;`
4. `public bool SkipInfection(float now)`：`Current==Step.Infecting && now-_started>=InputGuard` のとき、`Current=Step.Desktop; _started=now;` して true。
5. `IdleHopDelay` 1.5 → 0.4（Q7。待ちは感染の後に始まるので、今のままだと最初の跳ねが T=7.5 になる）。

- 今ある比べ方（`!=Locked`・`>=Bouncing`・`==Desktop`）は、足しても意味が変わらない。

### 7-3. `RunTitleMenu.cs`（足すだけ。7行くらい）

| 所 | 足す物 |
|---|---|
| `Update`、`_boot.Tick(now)` の後 | `MacDesktopInfection.Tick(_boot.InfectionTime(now), _dockApps.Count);` |
| `Update`、`Step.Desktop` の `else if` の前 | `Step.Infecting` のとき：`MenuInput.Confirm()` かマウスの左を押した瞬間に `_boot.SkipInfection(now)`、true なら `MuteRest()` |
| `DrawBoot`、`Folders(width)` の前 | `DrawBack(t, width, height)`（t＝`_boot.InfectionTime(now)`） |
| `DrawBoot`、`MenuBar` | 3つ目の引数に `Status(t, _dockApps.Count)` |
| `DrawBoot`、`if(waiting&&mouse…) Use()` の後、`if(_boot.ShowApp)` の前 | `DrawFront(t, width, height, _dockApps, hop, launched)` |
| `OnGUI`（ふつうの道）、`MenuBar` | 3つ目の引数に `LingerStatus(_dockApps.Count)` |
| `OnGUI`、`Folders(w)` の前 | `DrawLingerBack(w, h)` |
| `OnGUI`、`Dock(w,h,items)` のすぐ後 | `DrawLingerFront(w, h, items)` |

- DrawFront の中の順：フォルダ → Dock の重ね絵 → 乗った雑魚 → 警告の窓 → **跳んでいる雑魚**（窓②の角の前を通るので、窓より後）→ はじける絵・白い枠。
- DrawFront を `ShowApp` の前に置くので、タイトルの窓が警告の窓の上に開く。警告の窓にはクリックが届かない。
- `MacDesktopGui.cs`・`RunLoadoutMenu.cs`・`DesktopScreen.cs`・音のファイルは **変えない**。
- ほかに起動のステップを見ているコードは無い（`BossSelectDebug`・`AchievementScanScreen` は `IsBootPlaying` だけ。感染の間も true のままなので、そのままでよい）。

## 8. 確かめ方

Roslyn でコンパイル → プレイヤーをビルドして撮る（OnGUI はバッチでは写らない）。T は解除を押してから +0.65 秒。

| 見る所 | 見る物 |
|---|---|
| T=0.5 | きれいなデスクトップ。紫が1つも無い。無音 |
| T=1.1 | ダウンロードのフォルダが半分紫。横の線は消えている |
| T=1.6 | 雑魚①が空中。後ろにマゼンタの残像 |
| T=2.5 | 右の2つが紫＋雑魚。「感染 2」。ゲームのアイコンは青いまま |
| T=3.8 | アプリ全部と Finder が紫。「感染 5」。フォルダ2つとも紫 |
| T=4.5 | 警告の窓①②。Dock とフォルダにかぶっていない |
| T=5.25 | ゲームのアイコンに白い光とかけら |
| T=5.8 | 窓③（青）。ゲームのアイコンに白い枠。**赤い物は窓の左上の丸だけ** |
| T=6.4 | ゲームのアイコンが跳ね、白い枠もいっしょに上がる |
| T=6.5 と、飛ばした直後 | ゲームのアイコンの上に、止まったきらめき・白い光が残っていない |
| マウスを Dock に乗せる | 上がったアイコンと、紫の重ね絵・雑魚がずれない |

| 音 | 感染の間 BGM なし。窓が開き始めて `bgm_title` |
