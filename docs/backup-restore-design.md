## 0. まとめ

### 【確定】（まさぴ〜の言葉。これだけ）

> 「GameOver画面の部分リトライを押したらそのステージが始まる時のバックアップデータで復元みたいな演出が欲しい。なのでステージに入るごとにバックアップとってるふうな演出もしたいね。でGameOver画面でタイトルに戻る機能も欲しいからそれはそれで演出を考えて実装してみて。」

1. ゲームオーバーの画面でリトライすると、「そのステージが始まるときのバックアップから復元」に見える演出が出る。
2. ステージに入るたびに、「バックアップを取っている」ように見える演出が出る。
3. ゲームオーバーの画面からタイトルに戻れる。その演出も付ける。

### 前提（依頼のときに決まっていたこと）

- 待ち時間を増やさない（バックアップ）。R は「すぐにリトライ」なので復元は 1.5〜2.2 秒。タイトルへは 1.5〜2.5 秒。
- 復元の演出は `FailStage` → `Transition` の中、シーンを読む前。R キーもボタンも同じ道を通る。
- バックアップの演出は `LoadCurrentStage` に結びつける（リトライでは出ない）。シーンを読んだ後にゲームを止めて待たない。
- タイトルに戻る演出は、ゲームオーバーから戻るときだけ（一時停止・リザルト・能力えらびからは今のまま）。
- ゲームオーバーの選ぶ板（「このステージから再開しますか？」［リトライ］［タイトルへ］）は、今の作業ツリーでもう出るように戻っている（`GameOverScreen.Update` の `_choices` の所）。この文書では触らない。
- 新しい SE は 3 つまで。曲は増やさない。

### 【提案】（ここから下は全部）

3つの演出を、**同じ1つの印「バックアップのドライブ」** でつなぐ（1章）。

### 2-1. どこに重ねるか【提案：ステージが明るくなった最初の 1.9 秒・画面の右下】

| 案 | 中身 | 良い所 | 悪い所 |

## 3. B. 復元（ゲームオーバーでリトライ／R キー）

【確定】リトライすると、そのステージが始まるときのバックアップから復元しているように見せる。

### 3-1. 【提案】入り方と時間の流れ

- `FailStage` が呼ばれた **そのフレームから**、`BackupFx` が画面全体を真っ黒（`Color.black`、不透明）に塗り、その上に窓を描く。
  - ゲームオーバーの画面は `IsGameOver` が下りた瞬間に描かれなくなるので、黒で塗らないと倒れたステージが見えてしまう。必ずこのフレームから塗る。
  - 再起動の黒い画面からなら、黒のまま字と電源の印だけが消えて窓が出る（つながって見える）。
  - 増殖の途中（まだ黒くない）で R を押したときは、**すぐ真っ黒に切り替わる**（クラッシュの「ブツッ」と同じ見え方。暗くする 0.4 秒は入れない）。
- この間 `Time.timeScale = 0`（後ろのステージは止めたまま）。
- `Transition` の最初の「0.4 秒で暗く」は **飛ばす**（もう黒いので）。`_fade` は 0 のまま演出を見せ、終わったら今までどおり 0.4 秒で暗く → シーンを読む → 0.4 秒で明るく。
- 描く深さ：`GUI.depth = -900`（ゲームオーバー −300・能力の入れ替え −400・デスクトップ −500 より手前、暗転 −1000 より奥。最後の暗転が窓の上にかかる）。
