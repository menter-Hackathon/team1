# ギミックの SE（グループD：Steam・ミュージック・Spotify・Firefox・Figma・Photoshop・Illustrator・Arc）

2026-11-19。アプリごとのステージの決まり（`*Rule.cs`）に付ける専用の音。全部で 28個。

- レシピ：`Tools/audio/se/gimmick_d.json`（id は `se_gm_<アプリ>_<何>`）
- 割り当て：`Assets/Resources/Audio/Maps/44_gimmick_d.json`（キーは `gm_<アプリ>_<瞬間>`）
- 鳴らす所の指示書：`Tools/audio/hooks/gimmick_d.tsv`（`GameAudio.Event("キー")` を入れる場所）
- 本物のアプリの音（Steam の実績の音・Spotify の広告の音など）はまねしていない。音色だけ寄せて、メロディは自作。
- 技の音（`kit2.json`）と同じ色にそろえた：Steam＝パルスと三角波、Spotify＝澄んだパルス、Firefox＝炎のノイズ、Figma＝丸い三角波とクリック、Photoshop＝こもったノイズと刻み、Illustrator＝クリックとなめらかな sine、Arc＝角のない sine。
- 危ない方（ボスが強くなる・プレイヤーが不利になる）は低くて濁った音、得な方は高くて明るい音。
