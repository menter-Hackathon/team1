# メニューまわりの BGM・ジングル（8曲）

2026-11-19。楽譜は `Tools/audio/bgm/<id>.json`（形式は `Tools/audio/FORMAT.md` §2）。全部オリジナルで、実在の曲・アプリの音は使っていない。
まだ音にして聞いていない（音を作るプログラムを並行で作っているため）。紙の上で、調・和音・小節のマス数を調べてある。

## 共通の「ウイルスのモチーフ」

Aマイナーの2小節（ラ・ド・ミ・レ#ミ・シ ／ ド・シ・ラ・ソ#・ラ）。レ#とソ#の「半音のにごり」がウイルスらしさ。
ボス戦の曲（別の担当）と共通。治ったときは Aメジャー（ラ・ド#・ミ…）に変えて「治ったモチーフ」として使う。

| 曲 | モチーフの使い方 |
|---|---|
| `bgm_title` | Aメロの頭で、そのまま歌う |
| `bgm_desktop` | かけらだけ（音を抜いて、とぎれとぎれ） |
| `bgm_result` | イントロで、治ったモチーフをそのまま。ループの中でも少しだけ |
| `jingle_boss_appear` | 16分音符で速くかけ上がる |
| `jingle_stage_clear` | 治ったモチーフを速く |
| `jingle_gameover` | 音がだんだん長くなって、半音ずつ落ちる |

## 曲ごとのメモ

### bgm_title — タイトル（メニュー・モード選び）
- 雰囲気：「きみの Mac、感染してるよ」。ちょっと不思議で、でもかわいい。覚えやすさを一番に。
- Aマイナー / BPM 120 / イントロ 2小節（4秒）＋ループ 16小節（32秒）
- 作り：イントロ（高い音のピコピコと、タムのフィル）→ A 8小節（モチーフ → 答え → もう一度高く。Am・Am・F・E・Am・C・Dm・E）→ B 8小節（のびる音で明るく広がる。F・G・Em・Am・F・G・E・E）→ E の和音で下がって A の頭へ戻る。
- 寄せた感じ：ファミコンのタイトル画面の、短いフレーズをくり返す感じ。跳ねるベース（三角波）と速いアルペジオ。

### bgm_dex — アプリ図鑑（ずかん）
- 雰囲気：静かな博物館・カタログをながめる。好奇心。軽い。
- Cメジャー / BPM 92 / ループ 12小節（約31秒）
- 作り：A 8小節（C・Am・F・G・C・Am・Dm・G。ゆっくりしたメロディ、2回目は高く）→ B 4小節（F・Em・Dm・G。下からのぼる分散の形、ドラムはハイハットとベルだけ）。
- 寄せた感じ：オルゴール風の8分音符の分散和音。メロディはやわらかい矩形波（50%）にエコー。ドラムは全部弱く。

### bgm_loadout — 能力のカードを選ぶ画面
- 雰囲気：設定アプリをいじりながら考えごと。後半で「さあ行くぞ」と少し盛り上がる。
- Dマイナー（ドリアン）/ BPM 104 / スウィング 0.1 / ループ 16小節（約37秒）
- 作り：A 8小節（スタッカートの短いフレーズと裏打ちの和音。Dm・Dm・G・G・Bb・C・Dm・A）→ B 8小節（のびるメロディ、クラップ入り。F・C・Dm・Bb・F・C・A・A）→ 最後の2小節は A の和音でスネアが増えて、頭へ戻る。
- 寄せた感じ：ショップ・装備画面の、軽く跳ねるファンク風。

### bgm_desktop — 感染したデスクトップ（ステージの間の数秒）
- 雰囲気：不安、グリッチ、音がまばら、静か。どこで切れてもよい。
- Aマイナー / BPM 84 / ループ 6小節（約17秒）。この曲だけ、数秒しか流れないので FORMAT の目安（24〜48秒）より短くしてある。
- 作り：低い三角波の長い音（A・A・Bb・A・F・E）と、少しずらした sine のうすい和音。その上にモチーフのかけらと、高い「ピッ」（エコーつき）がぽつぽつ。3小節目の Bb（半音上）で不安にする。
- `master.gain` 0.55 で小さめにしてある。音量をそろえる処理で大きくなってしまうなら、Unity 側でこの曲だけ下げてほしい（0.6 倍くらい）。
- 寄せた感じ：調子の悪いパソコンの、ときどき鳴る小さな電子音。ホラーゲームのセーブ部屋のような、音の少なさ。

### bgm_result — リザルト
- 雰囲気：最初は「治った！」の晴れやかさ、そのあとはほっとして明るい。
- Aメジャー / BPM 120 / イントロ 4小節（8秒）＋ループ 16小節（32秒）
- 作り：イントロ＝ファンファーレ（治ったモチーフ → D の和音で1段高く → E でのばす）。ループ＝A 8小節（A・F#m・D・E・A・F#m・Bm・E）→ B 8小節（D・A・Bm・E・D・C#m・Bm・E。ゆったり）→ 最後はモチーフのしっぽの形で頭へ。
- ファンファーレをループに入れると30秒ごとにくり返してうるさいので、イントロ（1回だけ）に入れた。
- 寄せた感じ：昔の RPG の「勝利のファンファーレ → 結果画面のゆったりした曲」の流れ。

### jingle_boss_appear — ボスが現れる瞬間
- Aマイナー / BPM 165 / 2小節（約2.9秒）
- 作り：モチーフが16分音符でかけ上がる（Am → F）→ 高い E をのばす → E の連打とスネア・タム。**E（ドミナント）で止めて解決しない** ので、続けて `bgm_boss`（Aマイナー）の頭が鳴ると「来た！」になる。
- 寄せた感じ：警報のようにかけ上がって止まる、ボス前の「溜め」。頭の拍から2小節（約2.9秒）でボス曲の頭を鳴らすと、ちょうどつながる（音のファイルは余韻のぶん少し長い）。

### jingle_stage_clear — ステージクリア
- Aメジャー / BPM 150 / 2小節（3.2秒）
- 作り：治ったモチーフが速くかけ上がる → 高い E → A で明るく終わる（E7 → A）。
- 寄せた感じ：アクションゲームの「面クリア」の短いファンファーレ。ウイルスのにごりが取れた明るさ。

### jingle_gameover — ゲームオーバー
- Aマイナー / BPM 100 / 2小節（4.8秒）
- 作り：モチーフが 16分 → 8分 → 付点8分 → 4分 と音がだんだん長くなって（遅くなったように聞こえる）、ラ → ソ# → ソ → ファ → ミ と落ちていく。メロディは2本を少しずらして重ね、にごらせてある。
- 寄せた感じ：電池が切れかけたおもちゃのように、音が遅く・低くなって止まる感じ。

## 調べ方

楽譜は、作業用のプログラムで書き出して、チェック用のプログラムで調べた（小節ごとのマス数、音名・ドラムの記号、区間が使うパターンと楽器、メロディと和音のぶつかり、ループの秒数）。エラーは 0。
残っている注意は、わざとのもの：モチーフの「シ」（Am の上の9度）、図鑑の Fmaj7 のミ、デスクトップの高い「ピッ」。
