# ギミックの SE（グループ B：ChatGPT・Claude・Gemini・Notion・メモ・Excel・PowerPoint・Word・Keynote）

2026-11-19。アプリごとのステージのギミック（`StageRule`）の、その瞬間だけの音。技の音（`20_kit1.json`）とは別。

- レシピ：`Tools/audio/se/gimmick_b.json`（32 個）
- 割り当て：`Assets/Resources/Audio/Maps/42_gimmick_b.json`（`events` に 32 行）
- 鳴らす所の指示書：`Tools/audio/hooks/gimmick_b.tsv`（`GameAudio.Event("gm_…")` を入れる場所。全部そのアプリのフォルダの中。共通ファイルは無し）
- 本物のアプリ・OS の音はまねしていない（音色の雰囲気だけ。メロディは自作）。耳では確かめていない（波形の長さと大きさだけ調べた）。
- 大きさは割り当ての `vol` で決める。よく鳴る物（Claude の1目盛り・Keynote の拍手1回）は 0.25〜0.35、不利が起きた音（上限・鍵・#DIV/0!・長い答え）は 0.85〜0.95。

## 付けなかった所

- Gemini の紫の星・メモのボス戦のごほうびの「10秒 ゲージ×1.3」の終わり：時間切れは `StatMods`（共通ファイル）の中で起きるので、付けていない。
- PowerPoint のスライドが落ちる音・着地：今ある `popup_open` と技の音が鳴るので、足したのは直前のクリッカーの「カチッ」だけ。
- ChatGPT の長い答えの柱・Gemini のピンクの柱の発動：今ある `zone_fire` が鳴る。
- Claude のメーターが時間で1目盛り戻る・Keynote のメーターが減り始める・Excel の途中の数え：小さい変化で、音が多くなりすぎるので付けていない。
