# ギミックの音（担当A：固定の5アプリ＋会話・予定のキット8つ）

2026-11-19。技の音とは別に、アプリごとのギミック（ステージの決まり・場面③の出来事・ラスボスの仕掛け）の瞬間に付ける専用の SE。13アプリ・51個。

- レシピ：`Tools/audio/se/gimmick_a.json`（id は `se_gm_<アプリ>_<何>`）
- 割り当て：`Assets/Resources/Audio/Maps/41_gimmick_a.json`（`events`。キーは `gm_<アプリ>_<瞬間>`）
- 鳴らす所：`Tools/audio/hooks/gimmick_a.tsv`（コードのどの文の直後に `GameAudio.Event("gm_…")` を入れるか）
- 本物のアプリ・OS の音はまねしていない（音色とリズムの雰囲気だけ。節は全部自作）

## 考え方

- **不利なギミックは「来る前」と「来た時」を分ける**：Zoom（warning → cut）、Discord（disconnect_warn → disconnect_cut）、メール（spam_open → spam_boom）、LINE（read → boom）、カレンダー（soon → missed）。予告の音は「だんだん速くなる刻み」でそろえた。
- **予告の長さに合わせて作った音**（倍率を付けない・秒数を変えたら音も直す）：discord_disconnect_warn 1.5秒、line_read（0.4秒から点滅・1.9秒で爆発）、mail_spam_open 0.8秒、vscode_line 1.0秒で「ビタッ」、premiere_dip 0.25秒で柱、finder_trash_full 0.8秒、teams_breakout_mark 1.0秒、terminal_rm_floor（0.2秒から点滅・1.4秒でくずれる）、terminal_reboot（0.6秒から起動の音。形態変化 3.5秒のとき）。
- **数が増える物は、コードから倍率を渡してだんだん高く**：slack_unread_add（未読の数）、finder_trash_add（ゴミ箱の数）、messages_pop（割った数）、chrome_obstacle（翼竜だけ高く）。
- **何度も鳴る物は小さく短く**（vol 0.25〜0.45）：discord_vc_join、chrome_obstacle、finder_trash_add、premiere_marker、premiere_pass、terminal_cmd、terminal_ls、terminal_rm_restore、slack_read。
- **前からある音と重なる所**：右上の通知（toast）、場面の切り替え（pace_phase）、置物が壊れる音（prop_break）、ラスボスの形態変化（boss_phase2）。どれも短い音なので、重ねて「そのアプリの色」を足す作り。重なりは tsv の note に書いた。
- 新しい bool が要る所が2つ：`gm_zoom_warning`（残り10になった瞬間）と `gm_discord_disconnect_cut`（判定が出た瞬間）。どちらも毎フレーム通る所なので、1回だけ鳴らす見張りを足す。
