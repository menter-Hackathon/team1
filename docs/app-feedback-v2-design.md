## 1. 全体の方針：アプリごとの「看板の決まり」

- 今は、アプリが変わっても「弾・柱・落ちる物」の見た目が変わるだけ。**そのアプリでしか起きない遊びの決まり**を、1つずつ持たせる。
- 同じ決まりを、**ステージ（雑魚の時間）で先に見せ、ボスが使い、倒すと自分の能力になる**、の順で出す。

| アプリ | 看板の決まり | ステージ | ボスの技 | 能力 |
|---|---|---|---|---|
| Chrome | **オフラインの恐竜ゲーム**（床を走ってくるサボテンを跳ぶ） | オフライン区間（2-5） | オフライン（2-3） | 恐竜ラン（2-4） |
| VS Code | **行（横の列）**。赤丸の付いた行が、黄色く止まる | デバッグ実行（3-4） | ブレークポイント（3-1） | ブレークポイント（3-3） |
| Finder | **まとめて片づける**（選ぶ・圧縮・ゴミ箱） | ゴミ箱（4-3） | （今のまま） | zip圧縮（4-2） |
| Premiere Pro | **時間の線（タイムライン）**。再生ヘッドがマーカーに着くと起きる。切ると消える | タイムラインのステージ（5-6） | 再生ヘッド・レーザーツール・キーフレーム | リップル削除（5-5） |
| Terminal | **コマンド**。打たれたコマンドのとおりに、ステージがこわれる | コマンドで進むステージ（6-4） | rm -rf・chmod など | rm -rf（6-3） |

### 1-1. 変える範囲（だいじ：代用ボスは Chrome・VS Code の技を借りている）

- 今の作り：対応表に無いアプリ（Safari・Excel・Slack・Steam など）の代用ボスは、`Boss_Chrome` か `Boss_VSCode` の技をそのまま使う。能力「新しいタブ」「ブレークポイント」は、ブラウザ・開発のカテゴリ全部の能力。
- だから、変え方を2つに分ける。

| 変え方 | 範囲 | この文書での例 |
|---|---|---|
| **スキンの絵を直す**（`BrowserSkin`・`DevSkin`） | ブラウザ・開発の代用ボスにも効く。動き・判定・数値は変えない | タブを回さない（2-1）、広告6種類（2-2 の A）、ログの行の束（3-2）、能力のブレークポイントの見せ方（3-3） |
| **専用の技（`AttackKind.Custom`）を足す** | **本物の Chrome・VS Code だけ**。代用ボスは今の技のまま | オフライン（2-3）、横の行のブレークポイント（3-1） |

- 専用の技は、スキンの枠が付かない（`SkinTables.FrameOf` が Custom を外す）。代用ボスに渡すと、Excel が恐竜を出すことになる。だから渡さない。
- **入口（共通担当＝担当3 が最初に作る）**：対応アプリの表の行（`AppEntry`）に、「本物のアプリのときだけ使うボスの設定」の欄 `OwnProfile`【仮の名前】を足す。
  - 本物（対応表の行に当たったアプリ）：`OwnProfile` があればそれ、無ければ今の `Profile`。
  - 代用ボス：今までどおり `Profile`（＝今の `Boss_Chrome`・`Boss_VSCode`。**この2つのアセットは変えない**）。
  - 新しいボスの設定：`Boss_Chrome_App`・`Boss_VSCode_App`（今の設定の複製に、技を入れ替えた物）。
  - テスト用のシーン（BossTest）は今の `Boss_Chrome`・`Boss_VSCode` のまま。
- 能力：
  - Chrome は**専用の能力**を足す（`Skill_App_Chrome`。Zoom・Finder・Premiere Pro と同じ「アプリ専用の能力」の欄）。「新しいタブ」は、ほかのブラウザ（Safari・Arc など）の能力として残す。
  - VS Code は、カテゴリの能力「ブレークポイント」のまま、見せ方だけ直す（Xcode・Cursor なども同じ見せ方になる。ブレークポイントはどれにもある）。
  - Terminal は専用の能力を足す（`Skill_App_Terminal`）。

### 1-2. ステージのギミックの作り方（シーンを作り直さない）

- Finder・Premiere Pro・Terminal は、同じ1画面のシーン（`Stage_Desktop`）を使う。シーンと、シーンを作るツールは変えない（Unity で作り直すと、3人がぶつかる）。
- アプリごとに「キット」のファイルを1つ足す：`Assets/Scripts/Run/AppKits/<アプリ>Kit.cs`（新しいファイル。持ち主は 8章）。
  - 場面③の出来事：`AppStageEvents.Register(...)`（今ある入口。`StagePacer` が、スキンの出来事より先に見る）。
  - ステージ全体の決まり・飾りつけ：`StagePacer.Started` を購読し、`pacer.AppName`／`BundleId` を見て、自分で部品を付ける。`PacePhase.Done`（ボスの登場）で片づける。
  - 危ない物は、出来事用の `AttackRunner`（`PaceAssets.RunnerPrefab()`）を自分で1つ作って、ボスの技と同じ `CustomAttack` を呼ぶ（絵と判定を二重に作らない）【要確認：出来事の外で、キットが自分用の AttackRunner を持てるか】。
- `StageEventTable`・`StagePacer`・`ZakoSpawner` は変えない。
- **どのギミックも、ボスの登場で全部消す。ボス部屋の形（床・足場2枚）は変えない**（ボスの技が部屋の形を前提にしている）。

## 2. Chrome

- 何をまねるか：タブ、広告、**オフラインの恐竜**（No internet）。色は今のまま（青 `#4285F4`・赤 `#EA4335`・黄 `#FBBC05`・緑 `#34A853`、タブの灰色 `#DEE1E6`）。恐竜ゲームは灰色 `#535353` と白っぽい地 `#F7F7F7`。

### 2-0. 技の並び【仮】

| | 本物の Chrome（`Boss_Chrome_App`） | ブラウザの代用ボス（今の `Boss_Chrome`） |
|---|---|---|
| 第1形態 | タブ飛ばし ⇄ ポップアップ広告（2枚）。交互 | 同じ（絵だけ変わる） |
| 第2形態 | タブ飛ばし（5発×2回）、ポップアップ広告（4枚）、タブ増殖、**オフライン** | タブ飛ばし、ポップアップ広告、タブ増殖 |
| 手に入る能力 | **恐竜ラン** | 今のまま（新しいタブ など） |

- 動き（浮いて3か所を移動）・ゲージ・待ち時間は変えない。

### 2-1. タブ手裏剣 →「タブ飛ばし」（見た目だけ。A。スキン）

- 直す理由：今は 14×9ドットの小さいタブが1秒に2回転していて、丸い手裏剣に見える。
- 変えること（`BrowserSkin` の小弾の枠。判定 0.6×0.4・速さ・数は変えない）
  - **回さない。** タブは水平のまま飛ぶ。上下に 1ドットだけゆれる。
  - 大きくする：22×12ドット。形は Chrome のタブ（上の角が丸く、下が少し広い台形）。
    - 地は白 `#FFFFFF`。左に丸いファビコン（4ドット。4色を弾ごとに順番に）。まん中に灰色の題名の棒（`#5F6368`、8×2ドット）。右に ×（3ドット）。
    - ふちは赤 `#EA4335` 1ドット（敵の弾の印）。芯（判定）はタブのまん中 11×7ドット。
  - 尾：タブの下のふちから、タブの列の灰色 `#DEE1E6` の細い線（高さ 2ドット）が後ろへ 1マス。「タブの列から引きちぎられて飛んできた」絵にする。
  - 予告（0.8秒。今のまま）：ボスのウィンドウの上に、撃つ数だけタブが横1列に並ぶ（扇に並べない。タブの列に見せる）。最後の 0.3秒は赤いふちが点滅。
  - 消えるとき：× が赤く光り、横にしぼむ（今のまま）。
- 名前は「タブ飛ばし」に変えてよい（攻撃データの名前 `TabShuriken` は変えない。枠の表が名前で決まるので）。
- OK の条件：止め絵で見て、だれが見てもブラウザのタブ。回っていない。判定は今と同じ。

  - どれも、左上に Mac の信号機、判定のある 0.1秒は全体が赤く光る、足場のあいだは灰色のふち（今の決まりのまま）。

  | 1 | 当せん | 黄 `#FBBC05` | 星と `WINNER!`、赤いボタン（今ある） |
  | 2 | にせのダウンロード | 白 `#FFFFFF` | 緑 `#34A853` の大きいボタン `DOWNLOAD`（今ある） |
  | 3 | にせのウイルス警告 | 赤 `#EA4335` | 白い「！」の三角と `WARNING`（今ある） |
  | 4 | 動画広告 | 黒 `#202124` | 白い ▶、下に黄色 `#FBBC05` の進みの線、右下に小さい箱 `Skip Ad` |

  - 形4種類：四角 3×2（今の形）、横長のバナー 4×1.2、たて長 1.6×3、小さい四角 2×1.6。デザイン（上の表）と形は別々に引く。

### 2-3. オフライン（新しい技。第2形態。A。本物の Chrome だけ）

- 何をまねるか：ネットが切れたときの恐竜ゲーム。**プレイヤーが恐竜の役**になり、床を走ってくるサボテンを跳ぶ。
- 専用の技 `ChromeOffline`（`Combat/Custom/Chrome/`）。ステージの出来事（2-5）でも同じ物を使う。

**流れ（合わせて 約5.5秒）**
1. **予告**（1.0秒）：ボスのウィンドウの中身が、灰色の恐竜の顔に変わる。画面全体に、白っぽい幕 `#F7F7F7`（3割）が 0.3秒でかかる（色がうすくなる＝オフライン）。
   - 床の上に、恐竜ゲームの地面の線（灰色 `#535353`、1ドット。所どころに小石の点）が、出てくる側の壁から反対の壁へ伸びる。
   - 出てくる側の壁ぎわの床に、赤い「！」が点滅（どちらから来るかの印）。
2. **サボテンと翼竜が走ってくる**（4.0秒）：出てくる側の壁から、反対の壁へ、床の上を毎秒 8マスで進む。壁に着いたら消える。
3. **終わり**（0.5秒）：幕が消え、地面の線が消える。ボスは次の技へ。
- 出てくる側：技が始まった瞬間に、プレイヤーから遠い方の壁。
- 技の間、ボスはいつもの場所に浮いたまま、ほかの技を出さない（跳びながら殴れる、プレイヤーの攻め時）。「場に残る技」にして、ほかの場に残る技と重ねない。

**数値【仮】**

| 物 | 大きさ（見た目） | 判定 | どこを通る | 避け方 |
|---|---|---|---|---|
| サボテン（小） | 0.6×1.0マス | 0.4×0.8 | 床の上 | 跳ぶ |
| サボテン（大。3本ならび） | 1.4×1.3マス | 1.2×1.1 | 床の上 | 跳ぶ（ジャンプ 3.2マスなので、余裕がある） |
| 翼竜（低い） | 1.2×0.8マス | 1.0×0.5 | 床から 1.5〜2.0マス | **跳ばない**（立っていれば頭の上を通る） |
| 翼竜（高い） | 同じ | 同じ | 床から 3.2〜3.7マス | 足場の上にいたら下りる（足場に立つと当たる） |

- 並び（第2形態）：サボテン小 → 大 → 翼竜（低）→ サボテン小 → 翼竜（高）→ サボテン大。間は 0.7秒（進む速さ 8 なので、5.6マスあく）。
  - **サボテンの次が低い翼竜のとき**（跳んだあと、着地していないと当たる）だけ、間を「ジャンプして着地するまでの時間＋0.3秒」にする【要確認：ジャンプの滞空時間。分かるまでは 1.2秒】。その分、技が長くなってよい。
- 1つずつ、壁から出る 0.8秒前に、出る高さの壁ぎわに赤い「！」（高さで、跳ぶか・跳ばないかが分かる）。
- 足場の上は、サボテンと低い翼竜には当たらない。高い翼竜だけが足場の高さを通る（足場に乗りっぱなしを答えにしない）。
- 当たったとき：ライフ -1。当たった物は消えない（貫通）。被弾後の無敵 1.0秒の間に通りすぎる。

**見た目**
- サボテン・翼竜：恐竜ゲームのドット絵。灰色 `#535353` の1色に、赤 `#EA4335` のふち 1ドット（危ない物の印）。翼竜は羽を 0.15秒ごとに上下。
- プレイヤーが当たったとき：いつものエラーの絵（Aw, Snap!）。
- 技の終わりに、右上の隅に小さく数字（`HI 00042` のような飾り。跳んだ数）を出してよい（C）。

**OK の条件**
- 予告の「！」を見てから動いて、6つとも避けられる。床に立ったままジャンプだけで、サボテンは全部越えられる。
- 低い翼竜は、床に立っていれば当たらず、跳ぶと当たる。高い翼竜は、足場の上にいると当たる。
- 50%・100% で、幕・地面の線・サボテン・翼竜が全部消える。
- 代用ボス（Safari・Excel など）は、この技を出さない。

### 2-4. 能力：恐竜ラン（新しい。Chrome 専用。A）

### 3-1. ブレークポイント（ボスの技。たての柱 → 横の「行」。A。本物の VS Code だけ）

**行の決め方**

- 第1形態：技が始まった瞬間にプレイヤーがいる行（床に立っている・跳んでいる → 床の行。足場の上 → 足場の行）。

**流れ（第1形態。約1.5秒）**
1. **予告**（1.0秒）：部屋の壁ぎわ（**ボスがいない側**。ボスの体にかくれないように。左なら本物どおり、右なら左右を逆にした絵）に、**赤丸**（14ドット、`#F14C4C`、白いふち 1ドット）が、その行の高さに「ポン」と付く。

   - **黄色い矢印 ▶**（`#FFCC00`、10ドット）が、行の反対の端から赤丸へ、1.0秒かけて進む。**矢印が赤丸に着いた瞬間が、判定の瞬間**（残り時間の目印）。
   - 最後の 0.3秒は、帯が点滅。
2. **判定**（0.2秒）：行の全部が、止まった行の黄色 `#FFCC00`（6割）に光る。上下のふちは赤。部屋の上のまん中に、デバッグの操作バー（今ある絵）が 0.3秒。
3. **終わり**（0.3秒）：帯が左右から閉じる。赤丸が消える。

**避け方**
- 床の行：判定の瞬間に、床から 1.0マスより上にいる。**跳ぶ**（矢印が赤丸に着く少し前に）か、**足場に乗る**。

**第2形態（3行。約2.9秒）**

**当たったとき**：ライフ -1。いつものエラーの絵。頭の上に ⏸（今ある）。

**OK の条件**

### 5-1. キーフレーム（新しい技。エフェクトアイコンの雨と入れ替え。A）

- 何をまねるか：キーフレーム（◆）を打つと、クリップが ◆ から ◆ へ動く。
- 専用の技 `PremiereKeyframe`。

**流れ（第1形態。約2.4秒）**
1. **予告**（1.0秒）：◆ が3つ、0.1秒ずつ順に空中に打たれる（「カチ・カチ・カチ」）。◆ と ◆ の間を、赤い点線（動きの道すじ）がつなぐ。
   - ◆1：ボスの体の下。◆2：技が始まった瞬間のプレイヤーの体の位置。◆3：◆2 から、ボスと反対の側へ 6マス・床から 3マスの高さ（部屋の中に収める）。
   - 道すじは、打たれたあと動かない。最後の 0.3秒は点滅。
2. **本体**（約1.1秒）：ボスの体から、クリップ（紫の四角）が出て、道すじの上を ◆1 → ◆2 → ◆3 と動く。◆ の手前でゆっくり、間で速く（イーズ。平均で毎秒 12マス）。
3. **終わり**（0.3秒）：◆3 でクリップがはじけて消える。◆ は、クリップが通るたびに消える。

**避け方**：赤い点線から 1マス離れる。◆2 は自分のいた所なので、歩いて離れる。◆3 へ向かう線の下をくぐってもよい（線は斜め上へ上がる）。

**数値【仮】**

| 項目 | 第1形態 | 第2形態 |
|---|---|---|
| ◆ の数 | 3 | 5（◆4：◆3 の真下の床。◆5：◆2 の所へ戻る） |
| クリップの数 | 1 | 2（0.35秒あけて、同じ道すじ） |
| クリップの判定 | 円、直径 1.0マス | 同じ |
| 予告 | 1.0秒 | 1.0秒（◆ を打つ間隔だけ 0.06秒にする。短くしない） |

**見た目**
- ◆：白 `#FFFFFF` のひし形（9ドット）、赤いふち 1ドット。打たれた瞬間に 150% → 100%。
- 道すじ：赤 `#FF453A` の点線（太さ 2ドット）。
- クリップ：紫 `#9A8CF0` の角の丸い四角（22×14ドット）。左にサムネイル（暗い四角）、上に白い細い棒（クリップの名前）。赤いふち。後ろに残像2枚。
- 当たったとき：いつものエラーの絵。B：エラーの絵を「メディアオフライン」（赤い `#D93A2F` の四角に白い字 `MEDIA OFFLINE`、24×14ドット）にする。

**OK の条件**
- 予告の間に点線から 1マス離れると、当たらない。その場に立っていると当たる。
- 道すじは、プレイヤーが動いても変わらない。
- 50%・100% で、◆・点線・クリップが消える。

### 5-2. 再生ヘッド（直す。A）

### 5-3. レーザーツール（直す。A。第2形態）

- まさぴ〜の感想：足場だけでなく、背景やステージごと消したい（消された感じ）。
- **変えること：区間（幅4マス）のたての列を、まるごと消して、閉じる。**

**流れ（約1.9秒。足場は 4秒後に戻る）**
1. **予告**（0.9秒）：画面の上にカミソリの刃が2つ。真下へ、**赤い点線**（切る線）が床まで。2本の間の区間に、赤むらさきの斜線（`#FF453A` と `#9A8CF0` のしま、3割）。
2. **切る**（0.15秒）：刃が上から下へ落ち、白い光の線が走る。
   - **判定は、区間の中の全部**（幅4マス×床から天井まで。今は線の所だけ）。区間の中にいたら、ライフ -1。
3. **削除**（0.25秒）：区間の列が、**背景・床の絵・足場・タイムラインの飾りごと、黒く抜ける**。中は、空のタイムラインの暗い市松（`#1D1D1D` と `#232323`、4ドット）。
4. **リップル（詰め）**（0.4秒）：黒い列が、左右からまん中へ閉じる（幅 4マス → 0）。画面が横に 1回ゆれる。ボスが、区間の幅だけプレイヤーのほうへ寄る（今のまま）。
5. **つなぎ目**：閉じた所に、白い たての線（1ドット）が 0.5秒残って消える。区間の中にあった足場は、4秒消えたまま（点線の枠だけ。今のまま）。

**避け方**：赤い斜線の区間から、歩いて出る（まん中にいても 2マス、0.3秒）。区間の中の足場の上も当たる（列ごと消えるので）。

**決まり・割り切り**
- 区間の置き方：ボスとプレイヤーの x のまん中が中心（今のまま）。**「線をプレイヤーから 1マス離す」の決まりは、なくす**（区間の中にいてもよい。出ればよいので）。
  - かわりの決まり：予告を出す瞬間、**プレイヤーから、出られる側の区間の端まで 2.5マス以下**にする（0.3秒おくれて歩き出して、0.36秒で出られる）。壁でふさがった側の端は数えない。越えるときは、越えなくなるまで区間をずらす。
- 床の当たり判定は消さない。穴はあけない（前の仕様の理由のまま）。黒く抜けている 0.65秒の間も、床には立てる。
- 絵は、区間の上に黒い列をかぶせて、幅をせばめるだけ。重ねる順番は、ステージの絵・足場より前、キャラクターと弾より後ろ。左右の絵を本当に動かすのは C。
- 黒い列が出ている間、区間の中の足場は絵も判定も消す（今の「足場を消す」と同じ仕組み）。

**OK の条件**
- 切る瞬間に、区間の背景・床の絵・足場が全部黒く抜け、左右から閉じる。
- 予告の間に区間から出ると当たらない。区間の中（足場の上をふくむ）にいると当たる。
- 閉じたあと、背景と床の絵は元どおり。足場だけ 4秒後に戻る。
- 50%・100% で、黒い列がすぐ消え、足場がすぐ戻る。

### 5-5. 能力：リップル削除（新しい。エフェクトアイコン投げと入れ替え。A）

- 専用の技は、今までの決まりのとおり（`CustomAttack`・`CustomEffect`。出した物は `CreateSpawnedObject`、状態を変えたら `Restore` で戻す、場に残る技は `Lingers`）。
- 途中のどの時点でも、ビルドが通って遊べること（新しい技のアセットがまだ無ければ、今の技のまま動く）。

### 8-4. 順番
