| 画面の広さ | 約21×12マス（カメラサイズ6） |

## 3. ボス戦の共通ルール【確定】

- **ボスの攻撃**
  - プレイヤーはライフ制なので、ダメージは1。
  - ノックバックは (6,5)、のけぞりは0.25秒。どちらも今の `Hitbox` の初期値。
- **予備動作**
  - 第1形態・第2形態とも、0.8秒を基本にする。
  - 第2形態でも予備動作は短くしない。難しくするときは、弾の数・密度・技を増やす。
- **攻撃と攻撃の間の待ち時間**
  - 第1形態は1.2秒、第2形態は0.8秒。
  - 同じ技は2回続けて出さない。
- **ウイルス解除ゲージ**（仕様書 4.3）
  - 最大値は100。プレイヤーの近接攻撃1回で+4（25回で正常化）。
- **形態変化**
  - ゲージが50%になったら第2形態にする。
  - 切り替わるときに、「アップデート中…」のプログレスバー演出を1.5秒入れる。演出の間、ボスは無敵。この演出は全ボスで共通。
  - 演出のときに、画面に残っているボスの弾は消す。
- **体当たり**：ボスの体に触れると、プレイヤーはダメージを受ける。

## 4. MVPボス：Chrome【確定】

- **見た目**：ウィンドウの姿。大きさは4×3マス。
- **位置**
  - 空中に浮く。下の端は床から2.5マスの高さで、ジャンプか足場からなら近接攻撃が届く。
  - 左・中央・右の3か所を、毎秒3マスで移動する。
- **行動の流れ**
  - 第1形態：タブ手裏剣とポップアップ落下を交互に出す。2回攻撃するごとに移動する。
  - 第2形態：3つの技から、同じ技が続かないように選ぶ。

| 技 | 種類（部品） | 第1形態 | 第2形態 | 重さ |
|---|---|---|---|---|
| タブ手裏剣 | Projectile（A） | 予備動作0.8秒。3発を扇状30°で撃つ。プレイヤーを狙い、毎秒7マス、重力なし。3秒で消える。判定の大きさは0.6×0.4 | 5発を扇状60°で、0.4秒間隔で2回 | 軽い |
| ポップアップ落下（ギミック） | Spawn（F） | 落ちる場所の床に影を0.8秒出してから、2枚落とす。1枚はプレイヤーの真上、もう1枚は3マス以上離れたランダムな位置。大きさは3×2で、毎秒12マスで等速に落ちる。判定は落下中だけ。**着地したら4秒間、すり抜け床として残る** | 4枚 | 普通 |
| タブ増殖 | Spawn（G＋F） | — | 画面の上端に、タブを0.3秒ごとに1枚ずつ並べる（最大6枚、3マス間隔）。並べ終えて0.5秒たったら、左から0.25秒おきに真下へ落とす（毎秒10マス）。床に着いたら消える | 普通 |

**撃破で手に入る能力「新しいタブ」**（役割：移動）

| 項目 | 値 |
|---|---|
| 効果 | 前方へ6マス瞬間移動する。移動先が壁や床にめり込むときは、手前の空いている位置に出る。空中でも使える |
| 無敵 | なし |
| クールタイム | 3秒 |
| 種類 | **新しい種類「Warp」**（5種類にはない） |
| 重さ | 普通 |

## 5. MVPボス：VS Code【確定】

- **見た目**：エディタの姿。大きさは4×3マス。
- **位置**
  - 床に立つ。
  - 2回攻撃するごとに、0.5秒かけて消え、反対側に現れる。この移動には、Chrome の能力と同じ Warp を使う。
  - 現れる場所には、0.5秒前から予告（点滅する縦棒のカーソル、またはウィンドウの薄い枠）を出す。完全に現れるまでは、体当たりの判定を無効にする（2026-11-15 に追加で合意）。
- **行動の流れ**
  - 第1形態：エラー弾とブレークポイントを交互に出す。
  - 第2形態：3つの技から、同じ技が続かないように選ぶ。

| 技 | 種類（部品） | 第1形態 | 第2形態 | 重さ |
|---|---|---|---|---|
| エラー弾 | Projectile（A） | 予備動作0.8秒。プレイヤーを狙って2連射する（間隔0.3秒）。毎秒8マス、重力なし。判定の大きさは1.0×0.3 | 3連射 | 軽い |
| 赤い波線（ギミック） | Area＋持続（H） | エラー弾が床や壁に当たった場所に、幅2マスの波線が2秒残る。0.5秒ごとに判定する | 3秒残る | 普通 |
| ブレークポイント | Area（E） | プレイヤーのいる位置の床に赤丸を1.0秒出してから、縦の柱で判定する。柱は幅1.5×画面の高さ、判定は0.3秒 | 3か所（プレイヤーの位置と、その左右4マス）に、0.3秒差で順番に出す | 軽い |
| エラーウィンドウ落下 | Spawn（F） | — | 3枚落とす。影の予告は0.8秒、大きさは3×2。着地したら残さずに消える。Chrome のポップアップと同じ部品を使う | 普通（部品は共通） |

**撃破で手に入る能力「ブレークポイント」**（役割：攻撃）

| 項目 | 値 |
|---|---|
| 効果 | 前方4マス先の床に赤丸を出し、0.3秒後に縦の柱で判定する。柱は幅1.5×高さ6、判定は0.2秒 |
| ゲージ増加 | +12（近接3回分） |
| 雑魚へのダメージ | 近接の3倍 |
| クールタイム | 3秒 |
| 種類 | Area |
| 重さ | 軽い |

### 避けられるかの確認
- **ブレークポイント（第2形態）**：予告は1.0秒あり、その間にプレイヤーは7マス動ける。幅1.5の柱が4マス間隔で並んでも、間に逃げられる。
- **タブ増殖**：タブは3マス間隔で並び、左から順に落ちてくる。タブの間に立つか、落ちる順番に合わせて動けば避けられる。
- **VS Code が反対側に現れる瞬間**：0.5秒前に予告が出るので、その間に離れられる。完全に現れるまでは体当たりの判定がないので、予告に気づかなくても、現れた瞬間に被弾することはない。

## 6. 攻撃基盤（M3）に必要な AttackData の項目【確定】

MVPの2体を作るために必要な項目です。

| 対象 | 項目 |
|---|---|
| 共通 | 種類、予備動作、判定時間、間隔（クールタイム）、ダメージ、ゲージ増加、ノックバック、のけぞり |
| 弾（Projectile） | 数、扇の角度、速さ、重力、寿命、判定の大きさ、狙い方（プレイヤー／正面）、**地形に当たったら消えるか**、**当たった位置に出す追撃**（別の AttackData を指定。赤い波線で使う） |
| 指定位置の判定（Area） | 出す場所（プレイヤーの位置／前方Nマス／弾が当たった位置）、形と大きさ、同時に出す数、ずらす時間 |
| 落下物・設置物（Spawn） | 予告時間、落下速度、着地後に残る秒数、足場になるかどうか、並べる間隔、落とす間隔 |
| 持続 | 持続時間、ヒット間隔 |
| Warp（新しい種類） | 行き先（前方Nマス／指定位置。VS Code は「反対側」）、消えてから現れるまでの時間、現れる前の予告、現れきるまで体当たりを無効にするか |

MVPでは、追尾・召喚・妨害ウィンドウといった重い部品は使いません。

### 使用時間で変えるつまみ【提案】

仕様書 4.5・5.5 では「未定」になっている部分です。ライフ制では攻撃力に意味がないので、かわりに次のものを使用時間で変える案です。

| 対象 | つまみ | 範囲 |
|---|---|---|
| ボス | ゲージの最大値 | 80〜140 |
| ボス | 第2形態の待ち時間 | 0.8〜0.6秒 |
| 能力「新しいタブ」 | ワープの距離 | 5〜8マス |
| 能力「ブレークポイント」 | ゲージ増加量 | 10〜16 |

- MVPの2体を含めると、能力の役割は次のように分かれる（仕様書 5.2）。

## 9. カテゴリと代表アプリ

ボスはアプリ単位になったので、カテゴリの役割は次の2つです。
- 部品をまとめる単位
- 対応表の整理

【確定】一覧は、ブラウザ／SNS・チャット／開発／AI／Office・仕事／ゲーム／クリエイティブ／音楽・動画、の8つで始めます。あとから増やせるようにしておきます。対応外のアプリは出さないので、Unknown は作りません。

【提案】あとから増やしやすくするための作り方：
- カテゴリと対応表は、コードに直接書かずにデータとして持つ（ScriptableObject または JSON）。
- カテゴリを enum にする場合は、番号ではなく名前で保存する。enum は番号で保存されるので、途中に追加すると既存のデータがずれる。

代表アプリとバンドルIDの表は【提案】です。

対応表のルール【提案】：
- **前方一致で照合する**：アプリによっては、年版ごとにIDの末尾が変わる（`com.adobe.PremierePro.26`）。JetBrains は無料版が `com.jetbrains.intellij.ce` で、有料版はIDが違う可能性がある。そのため、バンドルIDは前方一致で照合する。
- **除外リスト**：次の3つは常に起動しているので、ボスにしない。
  - Finder（`com.apple.finder`）
  - システム設定（`com.apple.systempreferences`）
  - このゲーム自身
- **SNSの名前**：Macでは X や Instagram をブラウザで使う人が多く、その時間はブラウザとして数えられる。SNSカテゴリに入るのは実質チャット系のアプリなので、名前を「SNS・チャット」にする。
