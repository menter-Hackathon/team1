## 2. 数値の基準

今のコード（`PlayerController`、`PlayerTestSceneBuilder`）の値です。

| 項目 | 値 |
|---|---|
| 長さの単位 | 1マス＝1unit |
| プレイヤーの移動速度 | 毎秒7マス |
| ジャンプの高さ | 3.2マス |
| プレイヤーの体の大きさ | 0.7×1.0マス |
| 画面の広さ | 約21×12マス（カメラサイズ6） |
| 被弾したあとの無敵 | 1.0秒（2026-11-16 のテストプレイを受けて 1.5秒から変更） |
| 雑魚ウイルスの HP | 5（近接5回、ブレークポイント2回。2026-11-16 に 3 から変更） |

ボス部屋は、次の形を前提にしています。【要確認】部屋の形はステージ担当と相談する。
- 1画面に床がある。
- 仕様書の「フォルダ」にあたる足場（すり抜け床）が、高さ3マスに2枚ある。

【提案】M3 のテストシーン（`BossTest`）では、次の形にしています。
- 部屋の内側は、横20マス（x=-10〜10）、床の上面から画面の上端まで11.5マス。カメラは固定。
- 足場は x=±3.5、幅2.4、上面の高さ3。
  - Chrome が止まる3か所（x=-7・0・7、幅4）の間に、0.3マスずつ離して置いている。
  - こうすると、足場の端に立っても Chrome の体に触れず、近接は届く。足場の幅を3にすると、端に立ったときに Chrome の体に触れてしまう。

## 3. ボス戦の共通ルール【確定】

- **ボスの攻撃**
  - プレイヤーはライフ制なので、ダメージは1。
  - ノックバックは (6,5)、のけぞりは0.25秒。どちらも今の `Hitbox` の初期値。
- **予備動作**
  - 第1形態・第2形態とも、0.8秒を基本にする。
  - 第2形態でも予備動作は短くしない。難しくするときは、弾の数・密度・技を増やす。
  - 場所に予告を出す技（ブレークポイントの赤丸、ポップアップの枠、エラーウィンドウの影）は、予告の時間を予備動作として扱う。0.8秒を別に足さない（2026-11-15 に追加で合意）。
- **攻撃と攻撃の間の待ち時間**
  - 第1形態は1.2秒、第2形態は0.8秒。
  - 同じ技は2回続けて出さない。
- **ウイルス解除ゲージ**（仕様書 4.3）
  - 最大値は100。プレイヤーの近接攻撃1回で+4（25回で正常化）。
  - ボスの HP ではなく、プレイヤーの攻撃ごとの「ゲージ増加」の分だけ増える。プレイヤーや雑魚の体力（ライフ・HP）とは別の仕組みにする（2026-11-15 に追加で合意）。
- **形態変化**
  - ゲージが50%になったら第2形態にする。
  - 切り替わるときに、「アップデート中…」のプログレスバー演出を1.5秒入れる。演出の間、ボスは無敵。この演出は全ボスで共通。
  - 演出のときに、画面に残っているボスの弾は消す。
  - 消すのは弾だけ。落下物・赤い波線・足場として残ったポップアップは残す。出している途中の技は止める（2026-11-15 に追加で合意）。
- **正常化**（ゲージ100%）（2026-11-15 に追加で合意）
  - ボスは攻撃をやめる。画面に出ているボスの攻撃は、弾以外もすべて消す。体当たりもなくなる。
  - そのアプリの能力を、その場で直接渡す。空き枠があればそこに入り、3つ持っていれば入れ替え待ち（1/2/3 で枠を選ぶ、X 長押しで拾わない）になる。
- **体当たり**：ボスの体に触れると、プレイヤーはダメージを受ける。

## 4. MVPボス：Chrome【確定】

- **見た目**：ウィンドウの姿。大きさは4×3マス。
- **位置**
  - 空中に浮く。下の端は床から2.5マスの高さで、ジャンプか足場からなら近接攻撃が届く。
  - 左・中央・右の3か所を、毎秒3マスで移動する。【提案】3か所は、部屋の中央から x=-7・0・7。
  - 移動先は、今いる場所以外の2か所から、ランダムに選ぶ（2026-11-15 に追加で合意）。
- **行動の流れ**
  - 第1形態：タブ手裏剣とポップアップ出現を交互に出す。2回攻撃するごとに移動する。
  - 第2形態：3つの技から、同じ技が続かないように選ぶ。2回攻撃するごとに移動するのは、第1形態と同じ（2026-11-15 に追加で合意）。

| 技 | 種類（部品） | 第1形態 | 第2形態 | 重さ |
|---|---|---|---|---|
| タブ手裏剣 | Projectile（A） | 予備動作0.8秒。3発を扇状30°で撃つ。プレイヤーを狙い、毎秒7マス、重力なし。3秒で消える。判定の大きさは0.6×0.4 | 5発を扇状60°で、0.4秒間隔で2回 | 軽い |
| ポップアップ出現（ギミック）（2026-11-16 に「落下」から変更） | Spawn（F） | 出る場所に、ウィンドウの薄い枠（3×2）を0.8秒出してから、空中にパッと2枚出す。1枚はプレイヤーの体に重なる位置、もう1枚はプレイヤーから3マス以上離れた空中のランダムな位置。判定は出た瞬間だけ（【仮】0.1秒）。**出たあと4秒間、すり抜け床として残り、最後の1秒は点滅して消える予告にする** | 4枚 | 普通 |
| タブ増殖 | Spawn（G＋F） | — | 画面の上端に、タブを0.3秒ごとに1枚ずつ並べる（最大6枚、3マス間隔）。並べ終えて0.5秒たったら、左から0.25秒おきに真下へ落とす（毎秒10マス）。床に着いたら消える | 普通 |

技の補足（2026-11-15 に追加で合意）：
- **ポップアップ出現**（2026-11-16 のテストプレイを受けて、落とす形から変更）
  - 「上から落ちてくるより、空中にパッと出てくる方がポップアップらしい」「消えるときの予告がほしい」というまさぴ〜の意見から。
  - 「3マス以上離れた」は、プレイヤーからの距離。第2形態の4枚も同じ。
  - ポップアップどうしは重なってもよい（2026-11-16 にまさぴ〜が決定。実装には重ならない所を先に選ぶ処理が残っているが、決定とは矛盾しない）。
  - 【仮】高さは、床か足場からジャンプして上の端に乗れる範囲にする。部屋の外・天井・ボスの体には重ねない。1枚目が床にめり込むときは、床の上まで上げる。
    - 実装で置いた値：上の端は床から2.5〜6.0マス。左右2.5マス以内の床・足場から、上の端まで3.0マス以下（ジャンプは3.2マス）。
    - 2枚目以降は、プレイヤーの体の中心から直線距離で3マス以上離す（空中に置くので、横の距離ではなく直線距離）。
    - 1枚目がボスの体に重なるときは、プレイヤーに重なったまま横へ最大1.8マスずらす。予告の枠は、最後の0.3秒だけ点滅する。
  - VS Code のエラーウィンドウは、今までどおり上から落とす（5章）。
- **足場の上に落ちたとき**：タブとエラーウィンドウは、足場（フォルダ）の真上に落ちたら、足場の上に着地して消える。影も足場の上に出る。
- **タブ増殖のタブの大きさ**：1.5×0.6マス。
  - 3マス間隔なので、タブの間に1.5マスの隙間がある（プレイヤーの体は0.7マス）。

**撃破で手に入る能力「新しいタブ」**（役割：移動）

| 項目 | 値 |
|---|---|
| 効果 | 前方へ6マス瞬間移動する。移動先が壁や床にめり込むときは、手前の空いている位置に出る。空中でも使える。途中に壁があれば、その手前で止まり、壁の向こうへはすり抜けない（2026-11-15 に追加で合意） |
| 無敵 | なし |
| クールタイム | 3秒。能力ごとに続く。捨てて拾い直しても、別の枠に入れ直しても、残り時間はそのまま（2026-11-15 に追加で合意。ブレークポイントも同じ） |
| 種類 | **新しい種類「Warp」**（5種類にはない） |
| 重さ | 普通 |

## 5. MVPボス：VS Code【確定】

- **見た目**：エディタの姿。大きさは4×3マス。
- **位置**
  - 床に立つ。
  - 2回攻撃するごとに、0.5秒かけて消え、反対側に現れる。この移動には、Chrome の能力と同じ Warp を使う。
  - 現れる場所には、0.5秒前から予告（点滅する縦棒のカーソル、またはウィンドウの薄い枠）を出す。完全に現れるまでは、体当たりの判定を無効にする（2026-11-15 に追加で合意）。
- **行動の流れ**
  - 第1形態：エラー弾とブレークポイントを交互に出す。
  - 第2形態：3つの技から、同じ技が続かないように選ぶ。

| 技 | 種類（部品） | 第1形態 | 第2形態 | 重さ |
|---|---|---|---|---|
| エラー弾 | Projectile（A） | 予備動作0.8秒。プレイヤーを狙って2連射する（間隔0.3秒）。毎秒8マス、重力なし。判定の大きさは1.0×0.3 | 3連射 | 軽い |
| 赤い波線（ギミック） | Area＋持続（H） | エラー弾が床や壁に当たった場所に、幅2マスの波線が2秒残る。0.5秒ごとに判定する | 3秒残る | 普通 |
| ブレークポイント | Area（E） | プレイヤーのいる位置の床に赤丸を1.0秒出してから、縦の柱で判定する。柱は幅1.5×画面の高さ、判定は0.3秒 | 3か所（プレイヤーの位置と、その左右4マス）に、0.3秒差で順番に出す | 軽い |
| エラーウィンドウ落下 | Spawn（F） | — | 3枚落とす。影の予告は0.8秒、大きさは3×2。着地したら残さずに消える。Chrome のポップアップと同じ部品（`FallingObject`）を使う。ポップアップは空中に出し、エラーウィンドウは落とす | 普通（部品は共通） |

技の補足（2026-11-15 に追加で合意）：
- **赤い波線**：弾が当たった面に沿って出す。床なら横に2マス、壁なら縦に2マス。
- **エラーウィンドウ落下**：1枚はプレイヤーの真上、残りはプレイヤーから横に3マス以上離す。足場の上に落ちたら、足場に着いて消える。
  - 2026-11-15 の時点では、ポップアップと同じ置き方だった。2026-11-16 にポップアップは空中に出す形に変わったので、今は置き方が違う（4章）。
- **ブレークポイント**：赤丸の1.0秒が予備動作の代わり（3章）。「画面の高さ」の柱は、部屋の床から画面の上端までを覆う。

**撃破で手に入る能力「ブレークポイント」**（役割：攻撃）

| 項目 | 値 |
|---|---|
| 効果 | 前方4マス先の床に赤丸を出し、0.3秒後に縦の柱で判定する。柱は幅1.5×高さ6、判定は0.2秒 |
| ゲージ増加 | +12（近接3回分） |
| 雑魚へのダメージ | 近接の3倍 |
| クールタイム | 3秒（能力ごとに続く。4章の「新しいタブ」と同じ） |
| 種類 | Area |
| 重さ | 軽い |

### 避けられるかの確認
- **ブレークポイント（第2形態）**：予告は1.0秒あり、その間にプレイヤーは7マス動ける。幅1.5の柱が4マス間隔で並んでも、間に逃げられる。
- **タブ増殖**：タブは3マス間隔で並び、左から順に落ちてくる。タブの間に立つか、落ちる順番に合わせて動けば避けられる。
- **VS Code が反対側に現れる瞬間**：0.5秒前に予告が出るので、その間に離れられる。完全に現れるまでは体当たりの判定がないので、予告に気づかなくても、現れた瞬間に被弾することはない。

## 6. 攻撃基盤（M3）に必要な AttackData の項目【確定】

MVPの2体を作るために必要な項目です。

| 対象 | 項目 |
|---|---|
| 共通 | 種類、予備動作、判定時間、間隔（クールタイム）、ダメージ、ゲージ増加、ノックバック、のけぞり |
| 弾（Projectile） | 数、扇の角度、速さ、重力、寿命、判定の大きさ、狙い方（プレイヤー／正面）、**地形に当たったら消えるか**、**当たった位置に出す追撃**（別の AttackData を指定。赤い波線で使う） |
| 指定位置の判定（Area） | 出す場所（プレイヤーの位置／前方Nマス／弾が当たった位置）、形と大きさ、同時に出す数、ずらす時間 |
| 落下物・設置物（Spawn） | 予告時間、落下速度、着地後に残る秒数、足場になるかどうか、並べる間隔、落とす間隔 |
| 持続 | 持続時間、ヒット間隔 |
| Warp（新しい種類） | 行き先（前方Nマス／指定位置。VS Code は「反対側」）、消えてから現れるまでの時間、現れる前の予告、現れきるまで体当たりを無効にするか |

M3 の実装で足した項目です（2026-11-15）。4〜5章の数値を表すのに必要なもので、仕様を新しく決めたものではありません。

| 対象 | 足した項目 | 使う所 |
|---|---|---|
| 共通 | 1回の攻撃で繰り返す回数と、その間隔 | エラー弾の2連射（0.3秒間隔）、タブ手裏剣を0.4秒間隔で2回 |
| 弾 | 相手に当たったら消えるか | すべての弾 |
| 指定位置の判定 | 2つ目以降をずらす距離（左→右→さらに左…の順）、真下の床の上に出すか、当たった面に沿わせるか | ブレークポイントの3か所（4マス間隔）、赤い波線 |
| 落下物・設置物 | 置き方（1枚は狙う相手の真上で残りは離す／画面の上端に左から並べる）、狙う相手から離す距離、大きさ、並べる距離の間隔、並べ終えてから落とし始めるまでの時間 | エラーウィンドウ（3マス以上）、タブ増殖（3マス間隔、0.5秒） |
| 落下物・設置物（2026-11-16 に追加） | 置き方「空中に出す」（1枚は狙う相手の体に重ね、残りは離す）、出す高さの範囲（上の端の高さ）、床や足場から乗れる高さ | ポップアップ（上の端は床から2.5〜6.0マス、乗れる高さは3.0マス。どちらも【仮】） |
| Warp | 消えるのにかける時間、現れるのにかける時間 | VS Code（0.5秒で消える） |

- 近接（種類 Melee）も同じ `AttackData` で表す。今は仮の近接で、J キー、判定0.12秒、間隔0.3秒、ダメージ1、ゲージ+4。
- ボス1体分の設定（形態ごとの技、待ち時間、何回攻撃するごとに移動するか、移動のしかた、手に入る能力）は、`BossProfile` にまとめている。

### M3 の実装で仮に置いた値【提案】

docs に書いていなかったため、仮の値で作ってあります。どれもアセットかコードの値で変えられます。

| 項目 | 仮の値 |
|---|---|
| 戦闘開始から最初の攻撃まで | 1.0秒。最初の技は一覧の先頭（Chrome はタブ手裏剣、VS Code はエラー弾） |
| 行動の順番 | 攻撃 →（2回ごとに）移動 → 待ち時間 → 次の攻撃 |
| エラー弾の寿命 | 3秒（タブ手裏剣と同じ）。実際は、その前に床か壁に当たって消える |
| 赤い波線の太さ | 0.4マス |
| エラーウィンドウの落下速度 | 毎秒12マス（落としていたころのポップアップと同じ） |
| VS Code が現れるのにかける時間 | 0.25秒。消え始めてから現れきるまでは、体当たりだけでなく、攻撃も当たらない |
| 形態変化の演出中の体当たり | 残す（ボスは無敵だが、触れるとダメージを受ける） |

## 11. マウス操作【確定】

- 2026-11-16 にまさぴ〜が決めた。数値と細かい動きは【提案】。
- 仕様書には無い操作なので、チームの合意はまだ（10章 #8）。
- 元になったアイデア
  - コンテナ案：ウィンドウをマウスで動かせる。
  - まさぴ〜案：別のウィンドウをマウスで動かして、敵の弾を防ぐ壁にする。敵が出したウィンドウや通知をマウスで消して、動ける場所を作る。

### 範囲の決め方

| 項目 | 決定 |
|---|---|
| マウスの位置づけ | **マウスが無くてもクリアできる**難しさにする。マウスがあると楽になる。ゲームパッドや Mac のトラックパッドでも遊べるので、デモでマウスが使えなくても困らない |
| 動かせるものと足場 | 動かせるウィンドウは**足場にしない**（プレイヤー・雑魚・ボスはすり抜ける）。逆に、足場になるものは動かせない。出たあとのポップアップ（4秒間すり抜け床として残る。4章）も動かせない |
| キー | 右手でマウスを持つので、左手だけで遊べるようにする。**近接に F キーを足す**（J も残す）。ほかのキー（移動 WASD、ジャンプ Space、ダッシュ 左Shift、能力 1/2/3、選択 Q/E、捨てる X）は、もう左手で届く |
| 見送ったもの | プレイヤーがウィンドウの中だけを動く形と、動くウィンドウにプレイヤーを乗せて運ぶ形。理由は2つ：ボスの数値は2章の部屋の広さを前提にしているので、動ける範囲が狭いと使えなくなる。また、自前の移動処理（`KinematicBody2D`）に、押す・乗せて運ぶ・挟む処理を新しく作る必要がある |

### 盾ウィンドウ

| 項目 | 決定 |
|---|---|
| 出どころ | 部屋に最初から1枚ある |
| 動かし方 | マウスでつかんで動かす |
| 止めるもの | **敵の弾（Projectile）だけ**：タブ手裏剣、エラー弾、雑魚の弾 |
| 止めないもの | 体当たり、ポップアップ、落下物（タブ・エラーウィンドウ）、指定位置の判定（ブレークポイントの柱、赤い波線）、プレイヤーの「新しいタブ」 |
| 止めた弾 | 消すだけ。当たった位置に出す追撃（VS Code の赤い波線）は**出さない**。出すと、動くウィンドウの上に波線が浮いたままになるため |
| 制限 | 1枚だけ。弾が当たると割れて、少したつと元の位置に戻る |

細かい動きと数値【提案】

| 項目 | 仮の値 |
|---|---|
| 割れるまで | 弾5発 |
| 戻るまで | 割れてから5秒。最初に置いた位置に戻る |
| つかむ場所と操作 | マウスの左ボタンで、ウィンドウのどこをつかんでも動かせる |
| 動かせる範囲 | 部屋（`BattleArena`）の中だけ |
| ドラッグ中に割れたとき | つかみが外れる |

- 実装の注意：「新しいタブ」が壁で止まる判定と、弾が地形に当たる判定は、同じ設定（`AttackRunner._solidMask`）を使っている。盾のレイヤーはそこに足さず、弾の判定にだけ別の設定を足す。

### タブ増殖のタブをクリックで消す

- Chrome 第2形態の「タブ増殖」（4章）。タブが画面の上端に並んでから落ち始めるまでの間に、クリックすると消える。
- 技の数値と流れは4章のまま変えない。足すのは「クリックで消せる」ことだけ。
- 新しい部品は足さない。新しい「通知」の部品（7章の J「妨害ウィンドウ」など）は、MVPでは作らない。
