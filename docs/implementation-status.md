## 2. 全体の流れ（通し）

```
RunTitle（読み込み方を選ぶ）→ RunLoadout（能力を3つ選ぶ）→ ステージ1 → ステージ2 → … → RunResult →（Enter／ボタン）→ RunTitle
```

- **能力えらび**：使用時間の長いアプリから作った5枚のカードから、3つ選ぶ（16章）。

- **シーンの切り替え**：画面を0.4秒で暗くしてから切り替え、0.4秒で明るくする。文字は出さない。
- **ステージ**
  - 1画面（Stage_Desktop）：雑魚を全員倒すとボスが出る。
  - 横スクロール・ウィンドウ移動：道中を進んでボス部屋に入ると、入口が閉じてボスが出る（道中の雑魚は倒さなくてよい）。
  - ボスにとどめを刺す（正常化する）とクリア。
  - 正常化してから2.5秒後に、次のステージかリザルトへ進む。
- **ライフ0**：1.5秒後に、同じステージを最初からやり直す。やり直すと次のものが戻る。
  - ライフ：全快
  - 能力：そのステージを始めたときの状態
  - クールタイム：リセット
  - 雑魚：全員復活
  - ボス：ゲージ0、第1形態
- **リザルト**：正常化したアプリ・使用時間・手に入れた能力の一覧と、リトライ回数を出す。
- **開発用**：ステージのシーンを直接再生すると、サンプルデータでランを作って始まる。能力えらびの画面は出さず、カードの上から3つを持つ。

ゲームの進行は `GameSession` が持つ（シーンをまたいで残る）。各ステージの進行は `StageDirector` が担当する。

## 3. 使用データとステージの決め方（通し）

### 読み込み方（タイトルで選ぶ）

| ボタン | 中身 |
|---|---|
| スキャン | スクリーンタイムの記録を読む（れっきーの `MacScreenTime`。読めるときだけ出る） |
| 訓練モード | ゲームに同梱のサンプル（`Resources/SampleUsage.json`）。Chrome 8時間、VS Code 25時間、Finder 10時間、Slack 15時間、Figma 12時間、Excel 6時間、Steam 4時間。ボスになるのは Chrome と VS Code だけ。Figma・Excel・Steam は能力えらびのカードにだけ出る（16章） |

- 手入力は、main の #14（れっきー）でなくなった。
- 対応アプリが1つも無いときは、タイトルに理由を出す。プレイヤーはスキャンをやり直すか、訓練モードを選ぶ。
- **スキャンが失敗するとき**（2026-11-17、まさぴ〜の Mac）：ウィンドウの共有で「システム設定」は選べるが、撮影で「ユーザがアプリケーション、ウインドウ、ディスプレイ取り込みのTCCを拒否しました」になる（Unity の Console に出る）。撮影ツールは Unity から起動するので、macOS は Unity に「画面収録」の許可があるかを見ているらしい。【要確認】システム設定 ＞ プライバシーとセキュリティ ＞ 画面収録とシステムオーディオ録音 で Unity を許可して、Unity を開き直すと直るか。
- usage.json の形式
  - 一番外側は配列。
  - 1つのアプリは `{ "id": バンドルID, "displayName": 表示名, "usageSeconds": 過去7日間の合計秒数, "iconPath": アイコンのパス }`。
  - `usageSeconds` が null なら0として扱う。

### ステージの並べ方

**2026-11-17 から（17章）**：使用時間の上位10アプリ（除外を除く）から、ランダムに3つをボスにする。対応表に無いアプリは代用ボス。下の1〜3は、能力の表が無いときの、前からの決め方。

1. 対応表（`AppCatalog`）に無いアプリは捨てる。照合はバンドルIDの前方一致で、大文字と小文字は区別しない。
2. 同じ対応アプリに当たるデータが複数あれば、使用時間を足す。
3. 1アプリ＝1ステージ。使用時間が短い順に並べる。一番使ったアプリが最後のボスになる。

- **今の対応アプリは2つだけ**：Chrome（`com.google.Chrome`）と VS Code（`com.microsoft.VSCode`）。

### 強さ

- 強さ t ＝ 使用時間 ÷ 20時間（0〜1 に収める）。20時間は【仮】。
- t に応じて、下の値を最小から最大の間で決める。
- 元のアセットは書き換えず、ランの間だけ使う複製を作る。テストシーンは元のアセットの値（設計メモの基本値）のまま。

| 対象 | 値（t＝0 → t＝1） | 基本値（テストシーン） |
|---|---|---|
| ボスのゲージの最大値 | 80 → 140 | 100 |
| 第2形態の待ち時間 | 0.8秒 → 0.6秒 | 0.8秒 |

- 能力の値は、使用時間では変えない（2026-11-17 決定。能力の強さはレベルで決める。レベルはまだ作っていない）。対応アプリ表の「能力の数値」の欄は残っているが、使っていない。

例：サンプルデータの場合

| ステージ | アプリ | 使用時間 | 強さ t | ゲージ最大値 | 第2形態の待ち時間 |
|---|---|---|---|---|---|
| 1 | Chrome | 8時間 | 0.4 | 104 | 0.72秒 |
| 2 | VS Code | 25時間 | 1.0 | 140 | 0.6秒 |

## 6. 能力（通し）

### 持ち方と操作

- 3枠まで持てる。新しい能力は、一番前の空き枠に入る。
- 3枠とも埋まっているときに新しい能力を手に入れると、入れ替え待ちになる。
  - 1／2／3：入れ替える枠を選ぶ。
  - X 長押し：拾わない。
  - 入れ替え待ちの間も、ゲームは止まらない。
- 捨てた枠は空きのまま残る。ほかの枠は詰めないので、キーと能力の対応は変わらない。
- 同じ能力は2つ持てない。
- のけぞり中と入れ替え待ちの間は、能力を使えない。

### ランの中での扱い

- ランの最初に、能力えらびで1つ選んで持つ（17章。前は3つ）。1の枠に入る。
- そのあとは、ボスを正常化したときにだけ手に入る（拾うアイテムは PlayerTest だけ）。
  - すでに持っている能力のボスを正常化しても、今は何も起きない（レベルアップにするのは次の段階）。
- 能力は次のステージに持ち越す。
- やり直したときは、そのステージを始めたときの能力に戻る。

### クールタイム

- 能力ごとに数える。捨てて拾い直しても、別の枠に入れ直しても、残り時間はそのまま。
- ステージが変わるときと、やり直すときは、リセットされる（シーンを読み込み直すため）。

### 能力の中身

| 能力 | 手に入るボス | 効果 | クールタイム |
|---|---|---|---|
| 新しいタブ | Chrome（ブラウザ） | 前方へ6マス瞬間移動する。壁は通り抜けず、その手前で止まる。空中でも使える。無敵はない | 3秒 |

## 7. ボスの共通ルール（通し）

- **ウイルス解除ゲージ**
  - HP の代わりに、ゲージを持つ。基本の最大値は100（ランでは80〜140）。
  - 攻撃の「ゲージ増加」の分だけ増える。ダメージの量は見ない。
- **行動**
  - 戦闘が始まってから1秒後に、最初の攻撃をする。
  - 第1形態は2つの技を交互に出す。第2形態は、同じ技が続かないようにランダムに選ぶ。
  - 攻撃のあとの待ち時間：第1形態は1.2秒、第2形態は0.8秒（ランでは0.8〜0.6秒）。
  - 2回攻撃するごとに移動する。
- **形態変化**（ゲージ50%）
  - 攻撃をやめ、画面に出ているボスの弾だけを消す。落下物・赤い波線・足場として残ったポップアップは残る。
  - 1.5秒の間、無敵で点滅する。この間も体当たりの判定はある。
  - 1.5秒たったら第2形態になる。
- **ゲージ100%：ウイルス本体の追い出し**（State＝Ejected）
  - 攻撃をやめ、出ている攻撃をすべて消す。体当たりの判定もなくなる。
  - ウイルスが押し出され（大きい煙）、きれいになったウィンドウがきらめいて上へ消える。
  - 小さくなったウイルス本体が、プレイヤーと反対の向きへ逃げる。ボスの子に置いた「追い出されるウイルス」で、歩く雑魚と同じ動き、毎秒4.5マス。攻撃してこない。触れてもダメージを受けない。時間切れはない。
  - ゲージは白になる。
- **正常化**（ウイルス本体にとどめを刺したとき）
  - 1回当てると大きい煙ではじけて消える。そこで能力をプレイヤーに渡す。空き枠があればそこに入り、満杯なら入れ替え待ちになる。
  - 2.5秒後に次のステージかリザルトへ進む（今までと同じ）。
- **プレイヤーへのダメージ**：ボスの攻撃も体当たりも、ライフが1減る。

## 16. ゲームの流れ（2026-11-17 まさぴ〜決定。数値・見た目は【仮】。PR #15 で main に入った）

2つの段階に分けて作る。今入っているのは第1段階だけ。

### 第1段階：能力えらび（通し）

- **流れ**：タイトルでランを始めると、能力えらびの画面（`RunLoadout`）に進む。選んで ▶ を押すと、最初のステージへ（選ぶ数は17章で1つに変わった）。
- **カード**：使用データのアプリを使用時間の長い順に見て、カテゴリの能力を1枚ずつ出す（`AbilityCatalog`）。
  - 同じカテゴリのアプリが複数あっても、カードは1枚（一番長いアプリの名前と時間を出す）。
  - カテゴリが分からないアプリ、能力の無いカテゴリ（SNS・チャット／AI／音楽・動画）は飛ばす。
  - 5枚に足りないときは、まだ出ていないカテゴリの能力で埋める（アプリ名と時間は出さない）。いつも5枚から選べる。
  - 例：Chrome と VS Code だけが見つかったときは、ブレークポイント・新しいタブ＋棒グラフ・バケツ塗り・ボム（埋めたカード）。
- **カテゴリと能力**
  - ブラウザ → 新しいタブ
  - 開発 → ブレークポイント
  - Office・仕事 → 棒グラフ（新しく作った）
  - クリエイティブ → バケツ塗り（新しく作った）
  - ゲーム → ボム（新しく作った）
- **アプリの見分け方**：バンドルIDの前方一致、または名前（単語ごとに合わせる。「Adobe Photoshop 2025」は「Photoshop」に当たる。日本語の名前「メール」「メモ」「カレンダー」「ターミナル」「シミュレーター」も入れた）。表は設計メモ9章から作った。
  - スクリーンタイムでスキャンしたときは、今は対応アプリ（Chrome・VS Code）のデータしかゲームに渡ってこない。そのため、ほかのカテゴリは埋めたカードになる。全部のアプリを渡すには、れっきーの `MacScreenTime` 側の変更が必要（相談がいる）。
- **画面**（`RunLoadoutMenu`、OnGUI の仮の画面）
  - カード：アプリの色の帯・キーの番号・能力のアイコン（3倍）・能力の名前・元のアプリと使用時間。
  - 選んだカードは、少し持ち上がり、アプリの色で縁どられ、選んだ順の番号が付く。
  - 下に3つの枠。選んだ順に能力が入る（ステージでの 1・2・3 の枠になる）。3つそろうと ▶ が押せる。

    - `GameAudio` には、割り当てから音を読む `TryGetEventClip` を足しただけ（ほかは変えていない）。
  - AIアシスタント：レーザーが敵をとらえた瞬間に `se_ai_drone_beam`（ビュイッ）。ダメージが入る「ジジッ」は、判定を出した時から本当に当たった時（OnBeamHit）へ移し、少し大きくした。
    - 共通の当たりの音 `enemy_hit` は、とどめでない一撃のときだけ鳴る（とどめは `enemy_die`）。HP1 の雑魚では、レーザーが当たっても倒れる音だけだったので、専用の音を足した。
