## 0. 全体の決まり

### 0-1. 「キット」とは

- アプリ1つ＝キット1つ。キットの中身は4つ。
  1. **ボスの技**：第1形態 2つ、第2形態 +1つ（第2形態は、第1形態の強い版も使う）。
  2. **プレイヤーの能力** 1つ（そのボスを倒すと手に入る。能力えらびのカードにも出る）。
  3. **ステージのギミック** 1つ（そのアプリのステージだけの決まり）。
  4. このアプリといえば（元ネタ）。
- キットが無いアプリは、今までどおり（代用ボス＋カテゴリの能力＋スキンの出来事）。
- キットの一部が間に合わなければ、その枠は今の物（Chrome・VS Code の技の複製、カテゴリの能力）を残す。**ボスとして遊べる状態を、いつも保つ。**

### 0-2. 今ある決まり（変えない。docs/app-boss-skills-design.md の前提と同じ）

- 長さはマス（1マス＝18ドット）、時間は秒。プレイヤーは毎秒7マス、ジャンプ 3.2マス、体は 0.7×1.0。
- 部屋は横20マス（x＝-10〜10）、床から天井まで 11.5マス。足場は x＝±3.5、幅 2.4、高さ 3。
- ボスの攻撃は、どれもライフが1減る。ノックバック (6,5)、のけぞり 0.25秒、無敵 1.0秒。下に書いていなければ、これ。
- **予告は 0.8秒が基本。第2形態でも短くしない。** 難しくするときは、数と密度を増やす。
- **危ない物は、赤い予告**（赤いふち・赤い線・赤い「！」・影）。当たらない物に赤は使わない。
- 攻撃のあとの待ち時間：第1形態 1.2秒、第2形態 0.8秒。
- 場に残る技は重ねない（`AttackData` の「場に残る技」）。変えた地形・速さ・封印は `CustomEffect.Restore` で戻す。50％で `CustomEffect` を消し、100％で全部消す。
- 説明の帯は出さない。出す文字は、UI をまねた**英語の短い言葉**（`@channel`・`Regenerate` など）と飾りの数字だけ。
- 見た目は Mac（`MacUi` のウィンドウ・通知・ダイアログ）。スキンのファイル（`Visual/Skins/`）は**読むだけで、変えない。**

### 0-3. この文書で足す決まり【仮】

- **個人の情報は読まない・出さない。** 本物のメッセージ・予定・連絡先・チャンネル名・アカウント名は使わない。出す文字は、決まった作り物だけ（`#general`・`Meeting`・`PLAYER`）。Spotlight の `PLAYER` と同じ理由（発表のスクリーンに映る）。
- **絵文字・スタンプは自作のドット絵**（親指・ハート・星・顔。12〜16ドット）。実在のキャラクター（LINE のキャラクターなど）は使わない。
- **ギミックの公平さ**
  - ギミックがボス戦で出す危ない物は、**小さくて、逃げ場をふさがない物だけ**（直径4マスまで・足場1つぶんまで）。床の全部を使う物は、雑魚の時間だけ。
  - ボスの「場に残る技」が出ている間（`CustomEffect.AnyLingering`）と、形態変化の間は、ギミックは新しい危ない物を出さない。
  - **罰は「ライフが減る」にしない。** 守れなかったときは、ボスか雑魚が 8〜10秒だけ少し強くなる（待ち時間 ×0.8 など）。ごほうびは、クールタイムの回復・ゲージの倍率。
  - プレイヤーへの不利は「場所」か「短い時間」（4秒まで）にする。操作がずっと重くなる物は作らない。
- **ギミックがかかる範囲**：そのアプリのステージの、雑魚の時間とボス戦。ウイルスの追い出し（100％）で終わる。Terminal のステージには、ギミックは無い。
- **能力**：どれも、使えばボスのゲージが増える（移動だけ・強化だけの能力は作らない）。クールタイムは「1回のゲージの目安 ÷ 4」が基本（2.5〜8秒）。
- **同じスキンのアプリ**（Slack と LINE など）が同じランに並んでも別物に感じるように、キットごとに「軸」を変えた（20章の表）。
- **「足場の上だけ安全」の技とギミックは、予告を 2.5秒にする**（Terminal の再起動の予告と同じ。部屋の端から足場の上までは、走って跳んで 約1.2秒かかる）。
- **データの技の絵は 2段階**（20-4 の表）
  - **そのまま**：攻撃データの名前に枠の語を入れる（例：`Attack_Slack_Mention_Breakpoint_P1`）。今のスキン（Chat・AI・Office）の枠の絵が付く。コードは書かない。枠の語は `SkinTables.FrameOf` を見る【要確認】。
  - **差し替え**：スキンの枠の絵では合わない技（予定のブロック・メモの紙・紙飛行機など）。名前に枠の語を入れず、E6 の `KitDressed`（包み）に攻撃データと絵を渡す。絵は `〇〇Art.cs` に 1枚かくだけ（15〜30分）。**先に「そのまま」で動かし、あとで差し替える。**
  - キットの章の「見た目」に書いた絵は、差し替えたあとの絵。
- **データで作れる形**（`AttackEnums.cs` で確かめた）
  - 指定位置の判定：出す場所は「狙う相手の位置」「持ち主の前方 Nマス」（N＝0 で自分の位置）。床に付ける・付けないを選べる。数とずらす距離、前へ順に並べる、がある。**高さをずらす欄は無い。**
  - 落下物：「狙う相手の真上＋離れたランダムな位置」「上の列」「出現（狙う相手に重なる位置＋離れた空中）」の 3つだけ。**「プレイヤーの位置に、0.4秒おきに N個」は、出す数 1・くり返し N で作る。**
  - 弾：狙い方は「狙う相手」「正面」。数と扇の角度。弾の通り道の赤い線の予告は、今の部品には無い（`KitDressed` の「予告の線」を使う）。
  - これに入らない動き（壁から出す・高さを決めて出す・プレイヤーの能力で物を置く）は、Custom 小。
- **専用の技（Custom）**の絵は、キットのフォルダの `〇〇Art.cs` に、コードの中のドット絵（`RuntimeSprites.FromAscii`）と `WorldText`・`MacUi` で作る。絵のファイルは足さない。

### 0-4. キットの章の書き方

- 題名の行：優先度（A・B・C）／作る量（小・中・大）／ボスの元（**浮く**＝Chrome 型。x＝-7・0・7 を移動。**ワープ**＝VS Code 型。床に立ち、瞬間移動）。
- 技の「作り」
  - **データ**：今ある攻撃データの種類（弾・指定位置の判定・落下物・瞬間移動・ロックオン）の数値だけで作る。コードは書かない。
  - **Custom 小**：1〜2時間。今ある部品を呼ぶだけの `CustomAttack`。
  - **Custom 中**：2〜3時間。自分で進む部品（`CustomEffect`）がいる。
- Custom 中は、1キットに 1つまで。Custom 小が 3つ以上あるキットは、量を「中〜大」と書いた。
- **どのキットも、作る順番は同じ**：①第1形態の技2つ → ②能力 → ③ギミック → ④第2形態の技。①だけでも「そのアプリのボス」になる。

## 1. 共通の入口（担当0 が最初の 60〜90分で作る。ほかの担当は、自分のアプリのファイルだけをさわる）

- 名前はすべて【仮】の提案。キット2 の文書（docs/app-kits-2-design.md）は、ここの名前に揃えてある。**名前を変えるときは、2つの文書の担当の全員に知らせる。**
- 倍率の向きと幅は、キット2 の 1-2 と揃える：クールタイムは「進み方の倍率」（1.5 ＝ 1.5倍の速さで進む）。幅は、与えるゲージ 〜1.6、クールタイムの進み 0.6〜1.7、ボスの待ち時間 0.7〜。
- 置き場所：`Assets/Scripts/Kits/Common/`。

### E1. キットを登録する所（アプリ → ボスの技・能力・ギミック）

- 困ること：今は `AppCatalog`（代用ボスの専用の技）と `AbilityCatalog`（アプリ専用の能力）の**同じアセット**に行を足す形。数人が同時に足すと、ぶつかる。
- 作る物
  - `AppKit`（ScriptableObject）：アプリの名前・バンドルIDの前方一致・ボスの設定（`BossProfile`）・ボスのプレハブ（浮く／ワープ）・ゲージとの第2形態の待ち時間の範囲・能力（`SkillDefinition`）・ギミックの名前（文字列）。
  - 置き場所は `Assets/Resources/Kits/Kit_〇〇.asset`。**1キット＝1アセット。** 実行時に `Resources.LoadAll` で集める（`AppKits.Find(AppUsageRow)`）。
  - `AppCatalog.FindAppBoss`・`AbilityCatalog` のアプリ専用の能力の探し方・図鑑：**先に `AppKits` を見て、無ければ今の表**【要確認：呼んでいる所】。
  - アセットを作るメニュー「Tools/Team1/アプリのキットを用意」：`KitAssetBuilder` を継いだクラスを全部集めて呼ぶ（`AppSkins` がスキンを集めるのと同じやり方）。担当は `Assets/Scripts/Editor/Kits/〇〇KitAssets.cs` を1つ足すだけ。作り方は `Editor/BossSkills/FinderSkillAssets.cs` が見本（「無ければ作る」）。
  - `SkillTexts`（カードの説明とタグ）も、キットのアセットに欄を持たせて、そちらを先に見る。
- 安全のスイッチ：`AppKits.Enabled = false` で、全部が今までどおり。キットごとに「ボスの技を使う」「能力を使う」「ギミックを使う」を切れる。
- 別名（19章）：`AppKit` の名前の欄に足すだけで、ほかのアプリにも同じキットが当たる。

### E2. 強さの倍率（プレイヤーとボス）

- 今ある物：プレイヤーの横の速さ（`PlayerController.MoveSpeedMultiplier`）、ボスの移動と待ち時間（`BossController.MoveSpeedMultiplier`・`WaitMultiplier`）、ジャンプと近接の封印【要確認：名前】。
- 足す物：`StatMods`（1つの入口。**名前を付けて足し、名前で外す。** 同じ種類は掛け算。外し忘れても、ステージの終わりと 100％で全部外れる）。

  | 相手 | 種類 | 使うキット |
  |---|---|---|
  | プレイヤー | 与えるゲージ（と雑魚へのダメージ）の倍率 | Slack・Excel・Word・Keynote |
  | プレイヤー | クールタイムの進み方の倍率 | Discord・カレンダー・Claude |
  | プレイヤー | 横の速さの倍率（今の物をこの入口に通す） | — |
  | ボス | 待ち時間の倍率・移動の速さの倍率（今の物をこの入口に通す） | Slack・カレンダー・Discord・メモ |
  | ボス | ゲージの増え方の倍率（受ける側） | （予備） |
  | 雑魚 | 移動の速さの倍率 | カレンダー |

- **重なったときの幅は `StatMods` が切る**（能力は次のステージへ持ち越すので、Excel の +40％・リアクション ×1.5・太字 ×1.5 が同時にかかることがある）。掛け算の結果を、最後に幅の中へ収める：与えるゲージ 0.5〜1.6、クールタイムの進み 0.6〜1.7、ボスの待ち時間 0.7〜1.5、ボスの移動 〜1.6。**ボスの予告の長さと弾の速さは、どの倍率でも変えない。**
- 例：`StatMods.Player.GaugeGain.Set("slack.reaction", 1.5f)` → `StatMods.Player.GaugeGain.Clear("slack.reaction")`。
- 見た目：倍率がかかっている間、HUD のライフの下に小さい印（アプリのアイコン 8ドット＋上向き・下向きの矢印）。文字は出さない（E6 の `KitPips`）。
- 今ある技（Premiere のスピードデュレーション・Terminal の封印）は、そのままでよい。あとで通す。

### E3. ステージのギミックを登録する所（`StageRule`）

- 困ること：今の出来事（`StageEvent`）は、場面③だけ。ボスの登場（`Done`）で片づく。**ボス戦にもかかる決まりは作れない。**
- 作る物：`StageRule`（ステージの最初から、100％まで生きる）。`StagePacer` と同じやり方で、`StageDirector` があるシーンに実行時に付く（`StageRuleHost`）。テスト用のシーンには付かない。

  ```csharp
  public abstract class StageRule
  {
      public virtual void Begin(StageRuleContext ctx) { }       // ステージの最初
      public virtual void Tick(float dt) { }                    // 毎フレーム（形態変化・登場の演出の間は呼ばれない）
      public virtual void OnPhase(PacePhase phase) { }          // 場面が変わった（Done ＝ ボスの登場）
      public virtual void OnBossAppeared(BossController boss) { } // ボス戦が始まった
      public virtual void End() { }                             // 100％・ステージの終わり・やり直し。出した物と倍率を全部片づける
  }
  // ctx：Pacer・Player・PlayArea・Hazard（出来事用の AttackRunner と同じ物）・Strength（1〜3）・
  //      Boss（ボス戦の前は null）・InBossFight・CanSpawnHazard（0-3 の公平さの決まりをまとめた物）
  ```

- 登録：`StageRules.Register("slack", () => new SlackRule())` を、キットのファイルの中で（`[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)]`）。`AppKit` の「ギミックの名前」で引く。
- 片づけ：`End` は何回呼ばれてもよいように作る。`StageRuleHost` が、`VirusGauge.AnyFilled`（100％）とシーンの切り替えで呼ぶ。

### E4. アプリごとの出来事（場面③）

- 困ること：`StageEventTable.For` は**スキン**で引く。Slack・Discord・LINE は全部 Chat、Notion・カレンダー・メールは全部 Office で、同じ出来事になる。
- 作る物：`StageEventTable.For` の最初に1行。「キットに専用の出来事があれば、それを返す。無ければ今の表」。`AppKit` に `Func<int, StageEvent>` は持てないので、`StageRules` と同じ形の `StageEvents.Register("teams", stage => new TeamsBreakoutEvent())`。
- 専用の出来事を持つのは Teams だけ（17章）。ほかは、今のスキンの出来事（通知の嵐・Generating…・Calculating…）のまま。**ギミックは E3 の `StageRule` で足す。**

### E5. プレイヤー・ボスに足す小さい入口

| 入口 | 中身 | 使うキット |
|---|---|---|
| 能力の封印 | 全部の枠、または選んでいる枠1つを、N秒使えなくする（HUD の枠に鍵・斜線）。`PlayerSkillExecutor` | Claude・メモ |
| クールタイムを進める | 全部の枠のクールタイムを N秒進める／全部を回復する | LINE・カレンダー・メール・メッセージ・Word |
| 回復 | ライフを 1 回復（`Health`【要確認】） | メモ【要相談】 |
| ボスをひるませる | N秒、次の技を始めない・移動しない（技の途中は止めない） | Discord・メモ・Notion |
| ゲージを戻す | `VirusGauge` を N 減らす（0 より下にしない。50％を下回っても第2形態のまま）【要確認】 | Zoom |
| 敵の弾を消す | 円の中の、敵の `Projectile` を消す | Discord |

### E6. 小さい共通の部品

| 部品 | 中身 | 使うキット |
|---|---|---|
| `KitProp`（叩ける置物） | 場に置く物。近接か能力が1回当たると壊れて、呼び出し元に知らせる。体当たりのダメージは無い。ロックオンの相手には数えない。雑魚の数にも数えない | Slack・LINE・Notion・メール・メッセージ |

| `KitToast` | 右上の通知（`CornerToast`／`MacUi.Banner` を呼ぶだけ） | ほぼ全部 |
| `KitDressed`（包み。`CustomAttack` 1つ） | 中に入れた攻撃データを今の部品で出し、返ってきた物の絵を差し替える（キット2 の X3 `KitDress.Swap` を呼ぶ）。オプション：**弾の通り道に、予告の間だけ赤い細い線**。キットは絵を 1枚かいて渡すだけ。`Visual/Skins/` は変えない | 20-4 の「差し替え」の技の全部 |

## 2. Slack（優先度 A／量 中／浮く／スキン Chat）

  - 第2形態のボイスは 3連（全部 低。間 0.6秒）、サーバー一覧は 4つ。

### ステージのギミック：ボイスチャンネル（`StageRule`。量 小〜中）

### 部品・OK の条件

- 使い回す：`Projectile`・`FallingObject`・Chat のスキン・`WallShot`・`StatMods`・`AreaStrike`。
- 新しく作る：`DiscordServerListAttack`（Custom 小）・`DiscordMuteAttack`（Custom 小）・`DiscordRule`。
- OK：低はジャンプで、中と高は床でジャンプしなければ、3回中3回当たらない／ミュートで目の前の弾が消える／足場の上でクールタイムが速く進む／切断の点滅を見て降りれば当たらない。

  - 避け方：欄から 1.9マス動く。足場の上でも当たる。
- **P1-2　ハルシネーション**（Custom 中。Terminal の fork の分身が見本）
  - 流れ：ボスが 2体の「ウソ」を出す（ボスの左右 5マス。0.6秒で、1行ずつ書かれて現れる）→ 3体が同時に言葉の弾（小弾）を 3発ずつ扇状に撃つ（予告 0.8秒）→ ウソは消える。

  - ウソは 1回当てると消える（ゲージは増えない）。触っても痛くない。
  - 避け方：赤い予告の弾だけを見て、ジャンプか間に入る。
- **P2　Regenerate**（データ：長文回答を 3回くり返す）
  - 流れ：回る矢印の印 → 長文の柱が、そのときのプレイヤーの位置に 3回（0.9秒おき。毎回、予告 0.8秒）。
  - 避け方：1回ごとに 2マス動く。同じ向きに歩き続ければよい。壁ぎわでは折り返す。
  - 第2形態のハルシネーションは、ウソが 3体。
- 見た目：ウソは、ボスと同じ絵を 7割の濃さで。文字化けは赤と白の小さい四角。

### 能力：プロンプト（データ：指定位置の判定。予告つき）

- 押すと、プレイヤーの頭の上に「考え中」の点 3つ（0.5秒。動ける）→ 正面 3マス先に、長文の柱（幅 2×高さ 6、0.4秒）。

### ステージのギミック：考え中…（`StageRule`。量 中）

- **ボス戦**：18秒おきに、ボスが「考え中…」になる（頭の上に点 3つが順に光る。3秒。動かない・攻撃しない）。
  - 3秒の間にゲージを 10 以上増やすと、**`Stop generating`**：■ が出て、ボスが 1.5秒ひるむ（E5）。大技は出ない。
  - 増やせなかったら、考え終わって「長い答え」：長文の柱が、左の端から右へ順に 5本（幅 3、間 0.35秒。予告は 5本とも先に出る 1.0秒）。通り過ぎた所へ戻れば当たらない。足場の上は当たる。
  - 攻める時間であり、止める目標でもある。「場に残る技」が出ている間は、考え始めない。
  - **「長い答え」は 0-3 の「ボス戦の危ない物は小さい物だけ」の例外**：床の全部を順に使う。そのかわり、考え中と長い答えの間、ボスはほかの技を出さない（ボスの技と同じ扱い。`StageRule` がボスをひるませたままにする）。予告は 5本とも先に見え、通り過ぎた所は安全。
- **雑魚の時間**：雑魚が出る 1.0秒前に、出る場所に「考え中」の点 3つ。雑魚は 1行ずつ書かれて現れる（`ZakoSpawner` は変えず、出る場所に絵を重ねるだけ。量 小）【要確認：出る場所を先に知る方法。難しければ、雑魚の時間は無し】。

### 部品・OK の条件

- 使い回す：`AreaStrike`・AI のスキン・`TerminalForkEffect`／`TerminalGhost` の作り方（読むだけ）・`Projectile`・E5 のひるみ。
- 新しく作る：`ChatGptHallucinationAttack`＋`ChatGptFake`（Custom 中）・`ChatGptRule`。
- OK：ウソの弾に重なっても当たらない。本物の弾は当たる／考え中に近接を当て続けると ■ が出て、大技が出ない／何もしないと 5本の柱が出て、戻れば当たらない／50％でウソが消える。

### 能力：花火（Custom 小：高さを決めて円を出す）

## 17. Microsoft Teams（優先度 C／量 中／浮く／スキン Chat）

- **このアプリといえば**：紫の「会議に参加」、画面共有の赤い枠、手を挙げる（✋）、ブレイクアウトルーム、「聞こえますか？」「ミュートになってます」、「〇〇さんが参加しました」、起動が重い。

### ボスの技

- **P1-1　画面共有**（データ：指定位置の判定・四角。床に付けない）

### 能力：挙手（データ：指定位置の判定・柱）

- 自分の位置から真上へ、大きい手（幅 1.5×高さ 6、0.3秒）。ゲージ +10。雑魚は倒れる。
- クールタイム 2.5秒。**真上に強い**（浮いているボスの真下・足場の下から使う）。

### ステージのギミック：ブレイクアウトルーム（専用の出来事。`StageEvent`。E4。量 中）

### 部品・OK の条件

- 使い回す：`AreaStrike`・`FallingObject`（上の列）・Chat のスキン・`SwarmEvent` の雑魚の出し方・`PaceEvent`。

## 18. Zoom（ボスだけ。優先度 C／量 中／ワープ／スキン Chat）

- 能力は、今ある「ギャラリービュー」（implementation-status.md 22章）のまま。**足すのは、ボスの技とギミックだけ。**
- **このアプリといえば**：ギャラリービュー（タイルに分かれた画面）、話している人の緑の枠、赤い「退出」のボタン、「You are muted」、バーチャル背景、無料だと 40分で切れる会議。
- 色：青 `#2D8CFF`、暗い地 `#1A1A1A`、緑の枠 `#23D959`、退出の赤 `#E02828`。
- 軸：**タイルを読む**と、**時間切れ**。

### ボスの技

- **P1-1　ギャラリービュー**（Custom 小〜中：`ZoneStrike`）
  - 流れ：部屋が 横3×縦2 の 6つのタイルに分かれる（黒い線。下の段＝床から 0〜2.8、上の段＝2.8〜8。足場の上は上の段）→ 緑の枠が、0.5秒おきに 3つのタイルに順に付く → 付いた順に、タイルが赤くなって（予告 0.8秒）、判定 0.4秒。
  - 選び方：1つ目はプレイヤーのいるタイル。下の段の 3つが、同時に赤くならないようにする。
  - 避け方：枠の付いていないタイルへ。下の段が赤なら、となりのタイルか、足場に乗って上の段へ。
- **P1-2　退出ボタン**（データ：落下物 2個・狙う相手のまわり。枠＝落下物）
  - 流れ：赤い「退出」のボタンの板（3×1.5マス）が、プレイヤーの位置に 0.5秒おきに 2個（影の予告 0.8秒）。
- **P2　リアクションの嵐**（データ：落下物 5個・狙う相手のまわり。絵は差し替え）
  - 流れ：ボスの上に 👏 が 5つ並ぶ（0.8秒。落ちる所に影）→ 1つ目はプレイヤーの真上、残りは部屋に散らばって落ちる（毎秒 9マス）。
  - 避け方：影の無い所に立つ。
  - 第2形態のギャラリービューは 4タイル。ワープのあとに、すぐ撃つ。
- 見た目：タイルの左下に名札の帯、右上にマイクの印（能力のギャラリービューと同じ絵を使う）。

### ステージのギミック：40分で切れる（`StageRule`。量 小）【要相談：不利になる「あるある」を入れてよいか】

- **ボス戦**：右上（ボスのゲージの下）に、小さい時計 `40:00`。本当は 40秒で 0 になる（1秒で 1分ぶん減る。飾りの数字）。
  - 残り 10 で、時計が赤く点滅。
  - 0 になると `Meeting ended`：画面が一瞬暗くなり、ボスが会議を開き直す。**ボスのゲージが 8 戻る**（E5。0 より下にはならない。第2形態から第1形態には戻らない）。時計は `40:00` に戻る。
  - **40秒の間にゲージを 25 以上増やしていれば、戻らない**（時計が緑になって、そのまま次の 40秒へ）。攻め続ければ、罰は無い。
- **雑魚の時間**：時計は出すが、0 になっても何も戻らない。参加者のタイルが 4枚落ちてくるだけ（`Attack_Pace_ErrorWindowFall`。影の予告つき）。
- 形態変化と、追い出しの演出の間は、時計が止まる。

### 部品・OK の条件

- 使い回す：`ZoneStrike`・`FallingObject`・`Projectile`・Chat のスキン・ギャラリービューの絵（`LockOnStrike` のタイル。読むだけ）・`KitMeter`。

- OK：緑の枠の付いていないタイルにいれば当たらない／40秒で 25 増やせば、ゲージが戻らない／戻っても、第2形態のまま／100％で時計が消える。

## 21. 作る順番と、実装担当の分け方

### 21-1. 優先度

| 優先度 | アプリ | 理由 |
|---|---|---|
| **A（必ず）** | Slack・Excel | 訓練モードのサンプルに出る（発表で必ず見える） |
| **A（必ず）** | Discord・LINE・ChatGPT・Claude | まさぴ〜の並びの先頭。みんなが知っている |
| B | Gemini・Notion・カレンダー・PowerPoint・Word | |
| C | Keynote・メモ・メール・メッセージ・Teams・Zoom（ボス）・19章の別名 | |

- **キットの中の順番**（0-4）：①第1形態の技2つ → ②能力 → ③ギミック → ④第2形態の技。
- **全体の順番**：全員が、自分の A のアプリの ①②③ を先に終える → 1回合わせて遊ぶ → A の ④ と、B の ①②③ → C。
- ④（第2形態の技）が無い間は、第2形態は「第1形態の技の強い版 2つ＋今の複製の技 1つ」で動かす。

## 22. 確かめること（実装担当）

- Mac 用にビルドして撮る（OnGUI はバッチで写らない。reference の撮り方）。本物の `app_dex.json` は退避して戻す。
- キットごとに
  - そのアプリだけのランを作って（`BossSelectDebug` のやり方）、雑魚の時間 → ボス戦 → 能力が手に入る、まで通す。エラー 0件。
  - それぞれの章の「OK の条件」を 1つずつ。
  - 50％で、場に残る物（`CustomEffect`）が消える。100％で、置物・壁・足場・倍率・封印・メーターが全部戻る。やり直しでも残らない。
  - ギミックの危ない物が、ボスの「場に残る技」の間に出ない。
- 全体で
  - `AppKits.Enabled = false` で、今までどおり（代用ボス・カテゴリの能力・スキンの出来事）。
  - キットの無いアプリ（Steam・Figma・ミュージック）と、Chrome・VS Code・Finder・Premiere Pro・Terminal が、今までどおり。
  - 手に入れた能力を、次のステージ（別のアプリ）と Terminal で使える。倍率の印が正しく消える。
  - 図鑑と能力えらびのカードに、キットの能力の名前とアイコンが出る。
- 手で遊んで見る所（自動では分からない）：予告を見てから避けられるか、ギミックがうるさくないか、強化系の能力が強すぎないか。

## 23. 【要相談】まさぴ〜・チームに聞くこと

かっこの中は、決まるまでの扱い。

1. **LINE の「既読」**を日本語の字で出すか、`Read` にするか。ほかの UI の文字は英語に揃えている（日本語で出す。LINE は「既読」でないと伝わらない）。
2. **不利になる「あるある」**を入れてよいか：Claude の使用上限（能力が 6秒使えなくなる）、Zoom の 40分で切れる（ボスのゲージが 8 戻る）、メモの鍵（枠が 4秒使えない）。発表で、そのアプリを悪く言っているように見えないか（入れる。どれも、うまく遊べば罰は無い形にした）。
3. **足場を変えるギミック**：Notion のトグルの足場（片方ずつ閉じる）、Teams のブレイクアウトルーム（まん中に壁）。stage-pacing の【要相談⑩】では「部屋の形は変えない」（Notion・Teams のステージだけ変える。必ず元に戻す）。
4. **回復のごほうび**：メモのチェックリストで、ライフが 1 戻る（1ステージに 1回）。今は回復の手段がほとんど無い（入れる。強すぎたら、クールタイムの回復に変える）。
5. **Excel の能力**を、今の「棒グラフ」から「オートフィル」に変えてよいか。見本の動画の Office は棒グラフ（Excel はオートフィルにし、棒グラフは Office のほかのアプリの代わりに残す）。
6. **実在の UI の言葉のパロディを足す**：`@channel`・`Stop generating`・`Regenerate`・`One more thing...`・`Breakout rooms`・`Rooms closing`・`Meeting ended`・`in 10 min`・`Missed`・`Re:`・`3 corrections`・`Table`／`Board`。前に OK をもらった物（Aw, Snap! など）と同じ扱いでよいか（出す）。
7. **ChatGPT の「ウソ」**：当たらない弾と分身を出す。赤は使わず灰色にして見分けられるようにしたが、「見て反応すれば避けられる」に反しないか（入れる。分かりにくければ、ウソの弾をやめて分身だけにする）。
8. **19章の別名**（Outlook にメールのキット、Numbers に Excel のキット など）を使ってよいか（元のキットができたら入れる）。
9. **担当0 の量**：共通の入口（E1〜E6）は、キット2 の文書（docs/app-kits-2-design.md）も同じ物を使う。担当0 は 1人で、2つの文書の土台を持つ。Notion・メモまで持たせてよいか（手が足りなければ、Notion・メモは C に回す）。
10. **Zoom**：能力もボスの技も「ギャラリービュー」になる。ボスの技は、タイルが赤くなる別の動きにした（そのまま）。
11. **絵文字とスタンプ**は自作のドット絵にする。LINE のキャラクターや、本物の絵文字の絵は使わない（そのまま）。
12. **カード**：キットの能力が 16個増える。能力えらびのカードの「カテゴリ 5枚」の決まりとの関係は、今の「アプリ専用の能力は、カテゴリとは別に数える」のまま（そのまま）。
