# ウイルスの種類を増やす・巣を作る（2026-11-20）

まさぴ〜の依頼：「次はウイルスの見た目を増やしていこう。これ（12 タイプのコンセプト画）を追加で実装していきたい。特にワームは足場の周りを這い回ったり壁や天井を這い回っている。ワームやルートキットなどがウィンドウの中に巣を作ってるイメージ（巣は実際のコンピューターウイルスがどういうところに住み着いているかを考えてデザインして欲しい。）」

- 印：**【確定】**＝まさぴ〜が言ったこと・もう決まっていること／**【提案】**＝デザイナーの案（今日は作らない）／**【仮】**＝数値（すべて仮。あとで直す）。
- 締め切りは今日。**3 つに切って、上から順に作る**：① ワーム＋巣 → ② ルートキット＋巣 → ③ のこり 10 種は今ある動きの「着せかえ」。
- 実装担当（Opus）は Unity を動かさない。シーン・ビルダーは変えない（`ZakoVariants` と同じく、実行時に作る）。

## 1. 全体の形

```
Tools/art/virus/build_virus.py ──→ Assets/Resources/Virus/Virus_<Type>.png, Nest_<Type>.png
                                        │（実行時に Resources.Load。切り分けは VirusArt）
VirusArt（絵・ひな形の道具）【A】
   ├─ ZakoWorm + VirusNest（巣ぜんぶ）【B】   … StagePacer.Started で「Template_Worm」を足す
   ├─ ZakoRootkit【C】                        … StagePacer.Started で「Template_Rootkit」を足す
```

- ひな形は名前で探す（`Template_<Type>`）。番号を static に持ち合わない（担当どうしがコンパイルで待たなくてよい）。無ければ今の雑魚で代わりに出す。
- 名前に `Small`・`Elite` を入れない（`IllustratorRule` が名前で見ている）。
- `ZakoWalker` の部品は、止めても **外さない**（`RewardKit.IsZako`・`IllustratorRule` が部品で雑魚と見分ける。`ZakoSpawner.SpawnAt` が向きを入れる）。

## 2. ワーム（1 つ目に作る）【確定】

### 2-1. 考え方：当たり判定をたどらず、「四角のふち」を歩く

アプリの足場（`AppStagePlatforms.Spawn`）の当たり判定は、**上の端 0.3 マスだけ**。横と下は絵しか無い。だから物理でたどらない。
ワームは「レール＝四角形のふち」の上の、道のり `s` で場所を決める。

| レール | 四角 | 向き | 使う所 |
|---|---|---|---|
| 足場レール | 足場の絵（子 `Art` の `SpriteRenderer.bounds`）。**毎 FixedUpdate 読み直す** | 外側を回る（上・右横・下・左横） | 1 画面のステージの `AppPlatform` |
| 部屋レール | 床・左右の壁・天井の内側 | 内側を回る（床 → 壁 → 天井 → 壁） | 1 画面のステージ |
| 上だけレール | 足元の当たり判定（`BoxCollider2D.bounds`）の上の辺だけ。端で折り返す | — | 横スクロール（Chrome）・ウィンドウ移動（VS Code）の小さい足場 |

- 足場レールは bounds を毎回読むので、**動く足場（move・scroll・fall）にそのまま付いていく**（`KinematicBody2D.Carry` は使わない）。
- 部屋の四角：床＝`KitMotion.FloorY()`、左右＝床の 1.5 マス上から左右へ `Ground` を Raycast（30 マス。当たらなければ `pacer.PlayArea` の端）、天井＝`min(PlayArea.yMax, ScreenUi.ViewRect().yMax) − 1.6`【仮】（上の HUD の帯の下）。`Start` で 1 回だけ作る。
- 四角の道のり：左下から **反時計回り**。下の辺（+x）→ 右の辺（+y）→ 上の辺（−x）→ 左の辺（−y）。`s` は `0 〜 2(w+h)` でくり返す。進む向き `dir`（+1／−1）で `s += dir × 速さ × dt`。
- 面の法線 `n`：部屋レールは内向き（下の辺＝上向き）、足場レールは外向き（上の辺＝上向き、下の辺＝下向き）。

### 2-2. 絵の向きと当たり判定

- ルート（足元）の位置＝ふちの上の点。ルートは回さない。
- 子 `Visual` を回す：`Visual.localRotation = Quaternion.FromToRotation(Vector3.up, n)`（0／90／180／270 度。角ではパッと切り替える【仮】）。
- 左右：`right = (n.y, −n.x)`、`Visual.localScale.x = sign(dot(進む方向, right))`。
- 体当たり・被弾の箱（`Visual/Body`）は `Visual` の子なので、いっしょに回る。大きさは 6 章の表（ワーム 1.1×0.45）。
- ルートの `Rigidbody2D`：`_rb.position` を直接書く（足場に付いている間は `interpolation = None`。動く足場とずれない）。部屋レールの間は `MovePosition` でよい。

### 2-3. どのレールに乗るか（`Start` と、着地したとき）

1. 巣が `AttachPlatform`／`AttachRoom`（7 章 B）で入れていたら、それを使う。
2. 足元から下へ 0.5 マス Raycast（`Ground`＋`OneWayPlatform`）。
   - `AppPlatform` で `IsSolidNow` → **足場レール**（`s`＝上の辺の、今の x の所）。
   - 1 画面のステージ（`spawner.Quota > 0`）の床 → **部屋レール**（下の辺）。
   - ほか（Chrome・VS Code）：当たった箱の幅が 10 マス以下 → **上だけレール**。それより大きい床 → レールなし＝**歩く雑魚にもどす**（`ZakoWalker.enabled = true`。見た目だけワーム）。
3. 最初の向き：`ZakoWalker.Direction`（出すときにプレイヤーの方を向けてある）。

### 2-4. 落ちる（手が届く所へもどる）

「落ちる」＝`Visual` の回転を 0 にして `ZakoWalker.enabled = true`（重力と歩きは `ZakoWalker` にまかせる。向き `Direction` は出たときの値が残っている）。0.3 秒たって `KinematicBody2D.IsGrounded` になったら、2-3 をもう一度やる（レールが見つかれば `ZakoWalker.enabled = false`）。

- **はなす前に、面から体を離す**（大事）：`KinematicBody2D.CastAxis` は、箱が `Ground` に重なったまま始めると「当たり」と数える。壁に付いたままだと、宙で「着地した」ことになって動けなくなる。はなす時に `KinematicBody2D.Warp(今の位置 + n × d)`。`d`＝横の辺 0.5、上の辺・下の面 0.9【仮】（ルートの箱は足元から上へ約 0.8）。すり抜け床（足場）は重なっても数えないので、足場の下の面からはそのまま落ちる。
- **歩く雑魚にもどっている間も 5 秒の決まりを守る**（1 画面だけ）：床から 3.0 マスより上に 5 秒いたら、真下の床（`AppStagePlatforms.RaycastSteady`）へ `Warp` して煙を出す。

| いつ落ちるか | 予告 | 印 |
|---|---|---|
| 足場が乗れなくなった（`!IsSolidNow`）・足場が 1 コマで 1 マス以上とんだ | なし（すぐ） | 【仮】 |
| 天井（上の辺）にいて、プレイヤーが真下に来た（横の差 0.8 マス以内） | 0.6 秒止まって、ぶるぶるふるえる（±1px）＋ほこりが 2 つ落ちる | 【仮】 |
| 床から 3.0 マスより上に、つづけて 5 秒いた（**どのレールでも**。高い足場のまわりも入る） | 同じ 0.6 秒 | 【仮】 |
| 1 画面で残り 3 体以下（`StagePacer.Current.Remaining` が 1〜3） | 同じ 0.6 秒。そのあとは部屋レールの下の辺だけ（角で折り返す）。足場に落ちたら、レールに乗らず歩く雑魚のまま | 【仮】 |

- 落ちている間も体当たりは当たる（だから予告を出す）。
- 速さ 2.5 マス/秒【仮】×`GameBuffs.ZakoSpeed`。HP1。ノックバックは受けない（1 回で倒れるので要らない）。
- すり抜け床（フォルダなど `AppPlatform` でない物）の下の面は這わない。
- 同時にいられるワームは 3 体まで【仮】（割り当て係が数える。5-3）。

## 3. ルートキット（2 つ目に作る）【確定：床の下にかくれて出てくる】

### 3-1. 動き（もぐらたたき）

`ZakoWalker` は止める（`enabled = false`）。歩かない。床（または動かない足場の上）から出たり入ったりする。

| 状態 | 秒【仮】 | 絵 | 当たり | 動き |
|---|---|---|---|---|
| もぐる | 1.2〜2.0（**上限 2.0**） | コマ 0（割れ目から赤い目だけ） | 体当たりなし・攻撃も当たらない | 割れ目ごと、プレイヤーの x の方へ 3.5 マス/秒ですべる。横の差 0.3 で止まる |
| 予告 | 0.7 | コマ 0。±1px でふるえる＋灰色のかけらが 3 つはねる | まだなし | 場所はここで決まる（もう動かない） |
| 出る | 0.15 | コマ 1（半分） | **ここから** 体当たり・被弾あり | — |
| 出ている | 2.2（残り 3 体以下なら 4.4） | コマ 2（全身。茎の上でゆれる。±1px） | あり | 動かない |
| しずむ | 0.25 | コマ 1 → コマ 0 | しずみ切ったらなし | — |

- 当たりの入り切り：`Visual/Body`（Hurtbox と Hitbox が付いている物）を `SetActive` で切りかえる。入れ直したときに Hitbox がまた当たるかは、`Hitbox` の作りを読んで確かめる。
- 立つ面：`Start` で `AppStagePlatforms.RaycastSteady(足元+上0.3, 下, 20, spawner.GroundMask)`。その当たり判定の左右の端から 0.5 マス内側までを動ける。動く・消える足場には乗らない。
- 絵の原点は「床の線」（6 章）。割れ目の黒は床の線の下 2px に出る（床の絵の上に重なる）。
- 同時にいられるのは 2 体まで【仮】。

### 3-2. 公平さ

- 出てくる前に、かならず 0.7 秒の予告（赤い目が見えている）。予告の間は当たらない。
- もぐっている間は倒せない。そのかわり 2 秒より長くもぐらない。出ている 2.2 秒は動かないので、たたきやすい。

|---|---|---|
| 1 画面・1〜2 ステージ目 | 1 | ② の始まり |

**ノルマとの合わせ方（1 画面）**

- `StagePacer.Started` の中で、巣の分を先に足す：`spawner.AddQuota(巣の数 × 3)`。右上のゲージは最初からこの数で割るので、途中で伸びない。
- **`Started` でやるのは「数を決める」と `AddQuota` だけ**。ひな形（`Template_Worm`・`Template_Rootkit`）は、ほかの担当も `Started` で足すので、順番が決まっていない。巣を作るとき・出すときに `VirusArt.IndexOf` で名前から探す。最初から見えるルートキットの巣は、`Started` の次の `Update` で作る。
- 巣を早くこわした・巣を置けなかったとき：あまったノルマは、⑤ で流れの係が歩く雑魚の組にして出し切る（`TickOneScreen` の「表より多く残っていたら」が今もやっている）。ボスが出なくなることは無い。
- 巣が出す前にノルマが無くなったとき：`SpawnNow` が null を返す → 巣はしぼんで消える。
- つまり倒す数は「表の数＋巣の数×3」でいつも同じ。巣をこわす得は、**ワームやルートキットが歩く雑魚に変わる**ことと、拾える物。
- 横スクロール・ウィンドウ移動はノルマが無いので、足さない（`SpawnNow` は数えずに出す）。画面の左へ 6 マスより離れた巣は消す。

**置く場所**（共通：プレイヤーから 5 マス以上／ほかの巣から 2.5 マス以上／`spawner.AvoidBossRoom` ならボス部屋の外）

- ワームの巣：上から順に探す。

### 5-3. `StagePacer` につなぐ所（変えるのは `TemplateOf` だけ）

```csharp
int TemplateOf(Kind kind, out bool flying)
{
```

## 7. 実装の分け方（ファイルがぶつからない）

順番：**A を先に**（小さい）。A が終わったら **B・C・D を並行**。B・C・D は A の入口（下の署名）だけにたよる。

### A：絵の書き出しと、絵の道具

- 作る：`Tools/art/virus/build_virus.py`／`Assets/Resources/Virus/*.png`（`Virus_<Type>.png` 12 枚＋`Nest_Worm.png`・`Nest_Rootkit.png`）／`Assets/Scripts/Enemy/Virus/VirusArt.cs`／`Assets/Scripts/Editor/Art/VirusImport.cs`
- 直す：`Tools/art/virus/virus_art.py`（`t_worm(bud=...)`・`t_rootkit(slab=..., roots=...)` の引数だけ）
- `VirusImport`：`AppBackgroundImport` と同じ作りで、`Assets/Resources/Virus/` の PNG を 18px/マス・点フィルタ・圧縮なしにする。
- `VirusArt` の入口：

```csharp
public static class VirusArt
{
    public static bool Enabled = true;                       // 安全のためのスイッチ
    public const int FrameW = 26, FrameH = 24;
    public static Sprite[] Frames(string type);              // "Virus/Virus_<type>" を切り分ける（原点は 6 章の表）。無ければ null
    public static Sprite[] NestFrames(string type);          // "Virus/Nest_<type>"（Worm 30×20、Rootkit 44×16）。無ければ null
    public static GameObject Clone(ZakoSpawner spawner, int baseIndex, string type);
        // spawner.Template(baseIndex) を spawner の子に複製（止めたまま）。名前 "Template_<type>"。Visual/Art の色だけ白に（強い雑魚の HP の赤い点は変えない）
    public static bool Dress(GameObject template, string type, float fps);
        // 子 Visual/Art の SpriteFrameAnimation.Setup(sr, Frames(type), fps, true, false, true)（fps が 0 以下なら止めて、コマ 0 を入れる）。
        // Visual/Body の大きさ・位置を 6 章の表に。絵が無ければ false（呼んだ側はひな形を捨てる）
    public static int IndexOf(ZakoSpawner spawner, string type);   // 名前 "Template_<type>" の番号。無ければ -1（TemplateCount まで調べる）
    public static int AliveOf(ZakoSpawner spawner, string type);   // spawner.AliveList の中で、名前が "<type>_" で始まる数
}
```

### B：ワームと、巣ぜんぶ（切り分け 1）

- 作る：`Assets/Scripts/Enemy/Virus/ZakoWorm.cs`／`Assets/Scripts/Enemy/Virus/VirusNest.cs`（巣 1 つ分の部品と、置く係 `VirusNests` を同じファイルに）
- 入口：

```csharp
public class ZakoWorm : MonoBehaviour

    public void AttachPlatform(AppPlatform platform, float worldX, bool underside, int dir); // 足場レール（下の面なら underside）
    public void AttachRoom(Vector2 worldPoint, int dir);                                      // 部屋レール（いちばん近い辺）
```

- 見た目が出ない間は、ひな形を足さない（`Dress` が false）。`VirusArt.Enabled` が false なら何もしない。
- **1 時間で作る順（ここまでで切り分け 1 は出せる）**：① 部屋レール ② 足場レール（動く足場に付く）③ 足場が消えたら落ちる ④ 5 秒で落ちる ⑤ 巣（壁か床）＋`AddQuota`＋ボスで消える。

- 確かめること（ビルドして撮る。Unity を動かすのはメインの係）：
  1. Slack など 1 画面のステージで、ワームが **床 → 壁 → 天井** と這い、絵が面に合わせて回る。
  2. **動かない足場のまわり**を 1 周する（上・横・下）。**動く足場（move）**の下の面にいるワームが、足場に付いて動く。

  4. 天井のワームの真下に立つと、0.6 秒ふるえてから落ちてくる。5 秒ほうっておいても落ちてくる。
  5. 巣が ② で育って出てきて、0.6 秒の予告のあとワームが口から出る。3 回たたくとこわれて、拾える物が出る。
