- 書いた人：企画・デザイン（Fable）。作る人：Opus（今日中）。
- この文書は設計だけ。コード・絵・Unity・git は、この文書では変えていない。
- 数値は全部【仮】。座標は、ことわりが無ければ背景の絵の座標（320×180 ドット。左上が 0,0。1マス＝15ドット）。
- ワールド座標への直し方：x =（px − 160）÷ 15、y =（172.5 − py）÷ 15。

## 0. まとめ

### 【確定】（まさぴ〜の言葉。これだけ）

> 「編集画面全体にしてみて上の方の実際に作った動画が流れてる部分も実装してみてほしい。ボスはその動画が流れている部分から攻撃してくるみたいな」

1. ステージを、タイムラインだけでなく **編集画面全体** にする。
2. 上の方に、**作った動画が流れている所（プレビュー）** を作る。
3. ボスは、**その動画が流れている所から攻撃してくる** ように見せる。

### 【提案】（ここから下は全部）

- 画面を上下2段にする。上の段＝素材の一覧・**プログラムモニター（まん中）**・エフェクトの一覧。下の段＝タイムライン（ルーラー・V2・V1・A1・A2）。
- モニターの映像は、実行時に描く 1つの部品（`PremiereMonitor`【名前は仮】）。絵は「再生位置 k（0〜1）」だけで決まる。止める・巻き戻す・速くする、が全部 k の動かし方だけで済む。
- **ボスの体は動かさない。判定も変えない。** 「プレビューから攻撃」は、技の **予告と出どころ** をモニターに置く、と読む。
  - 理由：能力リップル削除は高さ 3.5マスまで。ボスをモニターの中へ上げると、倒せなくなる。
- タイムラインのルーラーは、py 31 → **py 78** へ下げる。再生ヘッドの白い柱は今も床から天井までなので、**予告（赤い点線・うすい赤の帯）を床から部屋の上の端まで伸ばす**（上の段にいても予告が見える）。

### A＝今日必ず作る

### 4-2. 大きさとコマ

- 絵は **k だけで決まる**（時計を持たない）。k が止まれば絵も止まる。k が戻れば絵も戻る。
- 動く物は、ます目 1つずつ動く（なめらかにしない）。場面の中の進み u（0〜1）で場所を決める。
  - 動きは、ふつうの速さで 1秒に 2〜4回くらい（少ないコマ・ゆっくり）。
- 作り方：**面は四角**（`PremiereArt.Box`）、**小さい物だけ ASCII**（`RuntimeSprites.FromAscii`。1文字＝1ドットの絵を 3倍で出す）。全面の ASCII のコマは作らない。

## 5. 再生位置の連動

### 5-1. モニターの時計

- モニターは k（0〜1）を持つ。だれも合図を出していないときは、自分で進む（8秒で 1周。右の端で 0 に戻る）。
- 合図は、**必ず秒数つき**。秒数が過ぎたら、モニターが自分で元に戻す。技が途中で消されても、映像が止まったままにならない。

| 合図【名前は仮】 | 何 | 戻り方 |
|---|---|---|
| `Follow(k)` | k をこの値にする（外の再生ヘッドに合わせる） | 0.2秒 呼ばれなければ、自分の時計に戻る |
| `Hold(秒)` | k を止める（映像が止まる。つまみが点滅） | 秒数で戻る |
| `Rewind(秒)` | k を、今の所から 0 へ、この秒数で戻す | 着いたら、そこから進む |
| `Speed(倍率, 秒)` | 自分の時計の速さを変える | 秒数で 1倍に戻る |
| `Skip(Δk)` | k を、今の所から Δk だけ先へ飛ばす（1 を越えたら頭から。ジャンプカット） | 1回きり。そこから進む |
| `Flash(秒)` | 映像の上に白い幕（8割 → 0。ディップ トゥ ホワイト） | 秒数で消える |
| `Blank(秒)` | 映像を「抜けた絵」にする（灰色の市松 `#5a5966`／`#63626f`、4ますごと） | 秒数で戻る |
| `Ticks(k のならび, 秒)` | スクラブバーに赤い印を出す | 秒数で消える |

- 自分の時計に戻るときは、**今の k から続ける**（`Follow` で飛ばした先から進む）。
- 強い順：`Follow` ＞ `Rewind` ＞ `Hold` ＞ `Speed`。`Flash`・`Blank`・`Ticks` は重ねて出せる。
- モニターは、技の中をのぞかない。技の方から合図を呼ぶ。モニターが無ければ（スイッチがオフ）、合図は何もしない。
- 技が使う場所：`PremiereMonitor.Current`（無ければ null）と、映像の四角・下のまん中の座標（1-3）。

### 5-2. 雑魚の時間

- ステージの再生ヘッド（青い線）が、毎フレーム `Follow(（線の x − 左の壁）÷ 部屋の幅)` を呼ぶ。
  - `PremiereTimelineStage` に、線の位置を 0〜1 で返す読み口を足す（今は中だけの値）。
- だから、青い線が `CLIP_01` の上に来ると、モニターに歩く人が映る。
- 書き出しの出来事の間は、線が 2倍の速さ → 映像も 2倍（何も足さなくてよい）。
- ステージのマーカーに線が着いたとき：`Flash(0.55)`（白く光る 0.25 ＋ 柱 0.3）。モニターの中でも「白く飛ぶ」。
- B2：マーカーが打たれたとき、`Ticks` でスクラブバーにも印。

### 5-3. ボスが出てから

- ボスの登場（`PacePhase.Done`）で、ステージの再生ヘッドは消える（今のまま）。`Follow` が止まるので、モニターは 0.2秒後に **自分の時計** で進む。
- 登場の瞬間に 1回だけ：`Rewind(0.6)`（映像が頭まで巻き戻る＝「ここからボスの番」）。
- ボス戦の間は、技の合図（6章）が k を動かす。再生ヘッドの技の間は、技の青い線に `Follow` で合わせる。
- 正常化（ボスの `Normalized`）：`Flash(0.3)`。あとは自分の時計のループ（B4：場面3 のウイルスが消える）。
- 能力を拾う流れには、さわらない（モニターは飾りだけ。判定・入力なし）。
